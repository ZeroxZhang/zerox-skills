# 信息密度与内容改写指南

本文件定义了三种信息密度模式下的通用缩放规则，以及各类型的密度特殊处理。
密度改写前，务必遵循 SKILL.md Phase 3.1 的内容改写核心原则。

---

## 通用密度缩放规则

三种密度的核心差异是**信息保留程度**与**视觉空间分配**，与内容类型正交。

### C1: 低密度 (Low Density)

**核心策略**：大幅精简，金句提炼，视觉优先。

- 每个内容模块只保留 1 个核心金句或关键词组
- 删除所有详细解释、案例、数据佐证
- 将段落压缩为一句话
- 如果原文有 5 个以上模块，合并或删减至 3-4 个

**排版规则**：
- 大面积留白：内容区域占画布面积不超过 50%
- 字号偏大：标题 40-56px，正文 18-20px
- 图表简化：仅保留最核心的一个图表
- 模块间距加大：48-64px
- 优先使用图标/数字大卡片替代文字段落
- BigNumber：2 个超大数字（占页面视觉焦点），极简标签

**视觉比例**：
```
留白 : 文字 : 图表 = 5 : 3 : 2
```

### C2: 中密度 (Medium Density)

**核心策略**：结构化优化，图文均衡，重点突出。

- 为每个模块提炼 4-6 字的小标题
- 每个模块保留 2-3 句核心说明
- 保留关键数据和论据，删除冗余表述
- 可使用项目符号列表提升信息扫描效率
- 原文模块数量可保持不变

**排版规则**：
- 均衡布局：内容区域占画布面积约 65-75%
- 标准字号：标题 28-36px，正文 15-16px
- 图文配合：保留 1-2 个图表，与文字交替排列
- 模块间距：32-40px
- 可使用小标题 + 分隔线组织信息
- BigNumber：3 个数据，数字+标签+简短趋势说明

**视觉比例**：
```
留白 : 文字 : 图表 = 3 : 4 : 3
```

### C3: 高密度 (High Density)

**核心策略**：完整保留，多栏消化，干货满满。

- 完整保留原文的有效信息，可补充不引入新事实的解释和逻辑连接
- 如果原文信息不够丰富，不得补造数据、案例、认证或效果；应降低密度、增加留白，或标注待补充字段
- 使用小标题、编号列表、加粗关键词提升结构化程度
- 不删减任何有价值的信息

**排版规则**：
- 信息密集：内容区域占画布面积 80-90%
- 多栏布局：纵向长图使用双栏，横向宽图使用三栏
- 字号紧凑：标题 24-30px，正文 14-15px
- 卡片式布局：每个模块用卡片包裹，减少视觉混乱
- 可使用 2-3 个图表
- 模块间距收紧：20-28px
- 纵向长图高度会更长
- BigNumber：3-4 个数据，数字+标签+趋势+简短上下文

**视觉比例**：
```
留白 : 文字 : 图表 = 1.5 : 5 : 3.5
```

## 类型特殊密度处理

以下规则是**真正因类型而异**的密度调整，不同于通用的缩放逻辑。

### T1 商业说服

- **C1**：CTA 独立成区，不可压缩到只剩一个按钮——即使低密度下也要保留 CTA 的视觉分量。`focus=solution` 时保留 1 个最强案例数据
- **C2**：`focus=product` 功能点压缩为关键词+1 句话说明；`focus=solution` 保留方法论框架和 1-2 个关键案例数据
- **C3**：`focus=product` 可适度扩写痛点描述+使用场景；`focus=solution` 完整保留方法论+多案例数据+团队背书

### T2 使用指南

- **C1**：`focus=steps` 仅保留关键步骤编号+动作短语；`focus=spec` 参数合并为简洁规格表
- **C2**：`focus=steps` 保留步骤编号+简短说明，关键提示用强调色标注；`focus=spec` 保留完整参数+注意事项合并为要点列表
- **C3**：`focus=steps` 完整保留编号步骤+关键提示+FAQ，使用卡片分区；`focus=spec` 完整保留技术参数+配置要求+注意事项，多栏/卡片消化密集参数

### T3 信息图

- **C1**：保留最核心的 1 组数据对比，图表简化为关键数字
- **C2**：保留 2 组核心数据对比，配 1-2 个图表
- **C3**：完整保留数据叙事线+多组对比+来源标注，2-3 个图表。**来源标注在任何密度下都不可删减**

### T4 宣传海报

- **所有密度下**：BigNumber 与正文字号比 ≥ 8:1，此规则不可因密度变化而妥协
- **C1**：主视觉焦点保留为独立超大金句或 BigNumber，2-3 个模块压缩为 1 个核心关键词。CTA 独立成区
- **C2**：主视觉焦点+2-4 个极简模块（每模块 1-2 句话），BigNumber 2-3 个核心冲击数据。时空锚点用强调色标注
- **C3**：完整保留核心信息但必须维持极端字号对比。信息密集时优先使用满铺色块区块分割（每个色块承载一个子主题，配合 P2 放大器）。若未使用 P2 满铺色块，可采用大留白分区或粗线分隔替代——避免传统边框卡片，因为卡片的内敛感与海报的外放冲击力冲突

## 跨密度通用规则

1. 无论哪种密度，都必须保留原文的**核心观点**，不可曲解
2. 改写时保持**专业性**，不降低语言质量
3. 如果用户的原文已经非常精炼，低密度模式下不要过度删减至失去意义
4. 如果用户的原文非常简短，高密度模式只能扩写结构性说明，不得引入未经用户确认的新事实
5. 每次改写后，务必核对：改写后的文案是否完整传达了原文意图？是否有任何信息被遗漏或错误理解？
