# 版式原型（Layout Archetypes）

本文件解决一个具体问题：**每次生成都在重新发明网格，而默认发明出来的网格是"几个横带 + space-between"，结果一定是内容挤在顶部、中间漏一个大洞。**

不要从零画。先选一个原型，按它给定的行预算填，再谈细节。

> 机器校验：`scripts/layout_check.py` 会测量空气占比、块间间隙、块内填充率、字号跨度与左右配重。原型只是手段，**通过校验才是目的**。

---

## 0. 先看失败长什么样

这三种形态是同一个病因（用百分比分行 + `justify-content: space-between`），遇到任意一种，直接换原型：

| 症状 | 现象 | 病因 |
|:--|:--|:--|
| **带状空洞** | 每个块都是"内容贴顶 + 下方一大片空" | 块高是百分比给的，内容没跟着长 |
| **单点大洞** | 块之间夹着一个明显大于其他间隙的空隙 | `space-between` 把剩余空间全塞进一个 gap |
| **字号悬崖** | 标题 150px，正文 12px，中间没有 30-60px 的过渡层 | 只规定了"最小对比比"，没规定层级数量 |

---

## 1. 原型选型表

| 原型 | 适用 | 天然能填满的原因 | 风险 |
|:--|:--|:--|:--|
| **A1 分带式** | T2 步骤、T3 叙事、内容有明确先后 | 每带高度由内容定，带内元素撑满带宽 | 最容易变成"带状空洞"——每带必须有 ≥2 个横向元素 |
| **A2 巨字 + 侧轨** | T1 产品介绍、T4 海报 | 左右分区天然填满宽度 | 侧轨内容太少会显空，需 ≥3 组 |
| **A3 编辑双栏** | T1 方案、C3 高密度 | 两栏各自纵向流，高度自动被内容撑满 | 栏宽比例失衡会显歪 |
| **A4 卡片矩阵** | T3 数据、T1 能力清单 | 单元格平铺，**由构造决定填满** | 卡片高度必须统一，否则参差 |
| **A5 色块节奏** | T4 海报、活动 | 满宽色块交替，**由构造决定填满** | 色块内文字不足会显空洞 |

> 判断口诀：**内容能平铺就选 A4/A5（由构造保证填满），内容有先后才选 A1**。T1/T4 优先 A2 或 A4。

---

## 2. A4 卡片矩阵（推荐默认）

A4 画布 1080×1440，左右留白 72px（内容宽 936）。行预算：

| # | 区块 | 高度 | 内容 |
|:--|:--|:--|:--|
| 1 | 报头 | 40 | kicker（左）+ 元信息（右） |
| 2 | 主标题区 | 340 | 引导句 + 巨字标题 + 一句补充 |
| 3 | 数据行 | 300 | 3 格：数字 88px + 标签 + 1-2 行说明 |
| 4 | 能力行 | 260 | 3 格：编号 + 标题 + 2 行说明 |
| 5 | 行动带 | 96 | 满宽色块：CTA + 说明 |
| 6 | 页脚 | 58 | 来源 + 署名 |
| — | 5 个间隙 | 5×38 | 统一间隙，不做差异化 |

合计 40+340+300+260+96+58+190 = 1284；加上下 padding 2×56 = 1396，余 44 由 `justify-content: space-between` 均分到 5 个间隙（每处 +9px）。

**CSS 骨架**

```css
.poster {
  width: 1080px; height: 1440px;
  display: flex; flex-direction: column; justify-content: space-between;
  padding: 56px 0;            /* 上下 padding 放在容器，左右交给每个区块 */
}
.pad { padding: 0 72px; }      /* 除满宽色块外，所有区块都加 .pad */
.matrix {                      /* 3 列矩阵：每格等高 */
  display: grid; grid-template-columns: repeat(3, 1fr); gap: 0 28px;
}
```

**为什么它能填满**：矩阵用 `1fr` 平分宽度、行高由最高的单元格决定，三个单元格会同时被撑到同一高度，不会出现"左边满、右边空"。

---

## 3. A2 巨字 + 侧轨

适合 T1/T4。左侧 0-660px 放字号层，右侧 700-1008px 放竖向信息轨（≥3 组），底部一条满宽色块。

| 区块 | 位置 | 内容 |
|:--|:--|:--|
| 报头 | 顶部通栏 | kicker + 元信息 |
| 巨字 | 左 660px | 2 行，字号 120-150px |
| 侧轨 | 右 300px | 3-4 组 mono 指标，竖排，组间用青/红 1px 线分隔 |
| 说明 | 巨字下 | 1-2 行 |
| 行动带 | 底部通栏 | 满宽色块 + CTA |

**关键**：侧轨必须有 3 组以上，否则右侧会变成一个竖着的洞。

---

## 4. A5 色块节奏

适合 T4。整页切成 4-6 个满宽色块，相邻块颜色必须不同（深 / 中 / 强调色交替），块内文字量决定块高。

```css
.poster { display: flex; flex-direction: column; }   /* 不要 space-between */
.band { padding: 44px 72px; }                        /* 块高由 padding + 内容决定 */
.band--accent { background: var(--red); color: var(--ink); }
.band--surface { background: var(--screen); }
```

**为什么它能填满**：色块背景本身就是墨，空的地方也是"有色"的，不存在视觉空洞。这是 T4 最稳的原型。

---

## 5. A3 编辑双栏

适合 C3 高密度。报头通栏，主体两栏（建议 5:7 或 7:5，不要 1:1），每栏内部是纵向 stack。

- 栏宽比例必须差异 ≥20%，1:1 会读成表格
- 两栏的**底部必须对齐**（各自最后一块加 `margin-top: auto`）
- 栏内模块间距统一，不允许某一块单独加大间距来"填满"

---

## 6. 填满之后的收尾

1. 跑 `python3 scripts/layout_check.py <file> --size A4 --density C2`
2. 空气占比不在目标区间 → 加内容或加大字号，**不要**用 `margin` / `justify-content` 去"调"
3. 出现"带状空洞" → 该块加横向的第二个元素（第二列文字、一条满宽细线、一个数字）
4. 字号种类 > 6 → 合并层级（把 13/15/17 收成 14/16）

> 记住：留白是**画出来的**，不是**剩出来的**。前者有位置和形状，后者就是没填满。
