# 维度交叉规则

本文件定义风格(B)、类型(T)、密度(C)、尺寸(A) 四个正交维度的交叉规则。
每个交叉规则只在这里定义一次，其他参考文件不再跨维度重复。
所有枚举、默认值与模式覆盖必须同时符合 [config-schema.json](config-schema.json)；若文字说明与 Schema 冲突，以 Schema 为准。

## 1. T × B 适配矩阵：类型与风格的组合指引

### 1.1 默认组合（无需子模式切换）

以下组合可以正常使用，风格的标准规范即可：

| 组合 | 说明 |
|------|------|
| T1+B1 | 暗夜编辑的专业可信感天然适配商业说服 |
| T1+B2 | 瑞士精密的理性权威感适配商业说服 |
| T1+B7 | 数据新闻的精确可信感适配商业说服 |
| T1+B9 | 谷歌原生的克制专业适配商业说服 |
| T2+B1 | 暗夜编辑适合技术文档 |
| T2+B7 | 数据新闻适合参数表格 |
| T2+B9 | 谷歌原生适合产品文档 |
| T3+B7 | 数据新闻是信息图的天然风格 |
| T3+B1 | 暗夜编辑适合数据密集场景 |

> 未在上表中列出的 T×B 组合使用风格的默认规范，无需特殊调整。上述列表仅标注"最优组合"和"需注意的组合"，其余均为可用组合。

### 1.2 需子模式切换的组合

当 T4 宣传海报与各风格组合时，自动触发 Poster 子模式。**子模式负责两件事**：(a) 字体和按钮等 UI 元素的强制适配（所有组合通用），(b) 推荐该风格在 T4 下的视觉冲击手段（P2-P8 放大器选择，非强制）。

以下组合需要自动切换到指定的子模式：

| 组合 | 切换到 | 强制适配（字体/按钮/布局） | 推荐的放大器组合 |
|------|--------|--------------------------|-----------------|
| **T4+B9** | B9-Poster | 字体 Tier C（Anton/Smiley Sans），字重 900，按钮胶囊/硬边框，不使用标准卡片 | **路径 A**：P2 G1 品牌四色满铺 + P6 贴纸（事件/活动海报）。**路径 B**：边框节奏 + P1+P3+P4（白底 1.5px ink 边框+Google 蓝点缀，编辑风克制海报）。B9 是唯一同时支持两种审美路径的风格——在 Phase 3.6 中声明选择。 |
| **T4+B2** | B2-Poster | 字体 Tier C，字重 900，零圆角+粗线分隔 | P2 正红满铺色块+白字 + P3 描边文字 |
| **T4+B4** | B4-Poster | 字体 Tier C，字重 900，硬阴影+错位+粗黑边框 | P2 安全橙满铺色块 + P5 非对称网格 |
| **T4+B5** | B5-Poster | 字体 Tier C，字重 900 | P2 粉/黄/蓝撞色满铺循环 + P6 贴纸标签 |
| **T4+B6** | B6-Poster | 字体 Tier C 衬线（Noto Serif SC 900），极端留白 | P2 墨黑满铺+朱红点睛（可选：仅用 P1+P4，以留白为冲击手段） |
| **T4+B8** | B8-Poster | 字体 Tier C，深黑底 | P2 霓虹色满铺段落交替 + P3 描边文字 |
| **T4+B1** | B1-Poster | 字体 Tier C | P2 琥珀色满铺+深灰底 + P4 超大编号 |
| **T4+B3** | B3-Poster | 字体 Tier C 衬线 | P2 陶土色满铺+米白底（可选：仅用 P1+P8 双色调，以温暖质感为冲击手段） |
| **T4+B7** | B7-Poster | 字体 Tier C 衬线 | P2 海军蓝满铺+报纸白底 + P4 超大编号 |

> **P2 不是强制的**：上表中 P2 满铺色块是各风格的**推荐首选**，因为它与 T4 的视觉冲击目标天然契合。但设计者可根据内容和场景选择不同的放大器组合。例如 B6+T4 可以用 P1+P4+P6（巨字+超大编号+贴纸）替代满铺色块，以留白作为冲击手段。

### 1.3 需微调的组合

以下组合可以正常使用，但建议做轻微调整：

| 组合 | 调整建议 |
|------|---------|
| T1+B3 | 有机自然的温暖感可能削弱商业说服的权威感，建议 `focus=solution` 场景使用 |
| T1+B6 | 极简东方的巨量留白与商业说服的信息密度冲突，建议仅 C1 低密度使用 |
| T2+B3 | 有机自然的柔和色调可能削弱步骤的清晰感，建议步骤编号使用强调色 |
| T2+B8 | 赛博街道的霓虹色可能分散对参数/步骤的注意力，建议数据区用冷静色调 |
| T3+B2 | 瑞士精密的纯红+纯黑可能限制数据可视化的色彩编码，建议放宽图表配色 |
| T3+B4 | 建筑粗野的错位布局可能干扰数据可读性，建议图表区域回归对齐 |
| T3+B6 | 极简东方的极低密度可能无法承载信息图的数据量，建议至少 C2 中密度 |

### 1.4 B9 子模式与类型的联动

| 类型 | B9 默认子模式 | 说明 |
|------|---------------|------|
| T1 | B9-Light | 克制专业，适合商业说服 |
| T2 | B9-Light | 清晰准确，适合技术文档 |
| T3 | B9-Light 或 B9-Dark | 数据密集时 Dark 更有沉浸感 |
| T4 | **B9-Poster** | G1 四色满铺，非 Light/Dark |

## 2. T × B 字体覆盖：类型对字体选择的影响

字体选择默认由风格(B)决定（参考 typography.md），但当特定类型与特定风格组合时，需要覆盖字体方案。

### 2.1 T4 宣传海报的字体强制覆盖

当类型为 T4 时，无论选择什么风格，**标题字体强制使用 Tier C**：

```css
/* T4 宣传海报 — 强制 Tier C */
.display, h1, h2 {
  font-family: 'Anton', 'Smiley Sans Oblique', 'Noto Sans SC', sans-serif;
  font-weight: 900;
  letter-spacing: -0.02em;
}
body, p, .body {
  font-family: 'Inter', 'Noto Sans SC', sans-serif;
  font-weight: 400;
}
```

可选网络字体加载（离线时使用系统 fallback，不得阻断渲染）：
```html
<link href="https://fonts.googleapis.com/css2?family=Anton&family=Inter:wght@400;500&family=Noto+Sans+SC:wght@400;500;900&display=swap" rel="stylesheet">
<!-- Smiley Sans (得意黑) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/cn-fontsource-smiley-sans-oblique/font.css">
```

### 2.2 T3 信息图的等宽字体覆盖

当类型为 T3 时，**所有风格下的数据标签和数字必须使用等宽字体**：

```css
/* T3 信息图 — 数据标签强制等宽 */
.data-label, .chart-label, .bignum-value, td, .spec-value {
  font-family: 'JetBrains Mono', 'Noto Sans SC', monospace;
}
```

### 2.3 T2 使用指南的等宽字体覆盖

当类型为 T2 且 `focus=spec` 时，**参数区域使用等宽字体**：

```css
/* T2 使用指南 spec — 参数区域强制等宽 */
.param-value, .spec-table td:last-child, .version-code {
  font-family: 'JetBrains Mono', 'Noto Sans SC', monospace;
}
```

## 3. T × A 布局变体：类型专属布局模板

默认布局参考 layout-specs.md。以下类型有专属布局变体，当选择该类型时优先使用专属布局。

### 3.1 T4 宣传海报的专属布局

T4 不使用通用黄金三段式 (15%/70%/15%)，而是使用以下专属布局。

#### A2 横向宽图 (1920×1080) — Split Hero 布局

```
┌──────────────────┬───────────────────────────────────────┐
│                  │  内容标题 + 简介                        │
│  满铺色块         │  ┌─────────┐ ┌─────────┐ ┌─────────┐ │
│  巨型标题         │  │ Feature  │ │ Feature  │ │ Feature  │ │
│  副标题           │  └─────────┘ └─────────┘ └─────────┤ │
│  BigNumber区      │  ┌───────────────────────────────────┐ │
│                  │  │ 风格/类型展示                       │ │
│                  │  └───────────────────────────────────┘ │
│  (40% 宽度)       │  CTA + 信息            (60% 宽度)     │
└──────────────────┴───────────────────────────────────────┘
```

Grid 定义：
```css
.main-grid {
  display: grid;
  grid-template-columns: 42% 1fr;
  grid-template-rows: 1080px;
}
.hero { /* 左侧满铺色块 */ padding: 72px 64px; }
.content { /* 右侧信息 */ padding: 56px 64px 48px 56px; }
```

Hero 区比例：Hero 占画布 40-45%，打破 Header 15% 的限制。

#### A2 横向宽图 — Stacked Blocks 布局

```
┌────────────────────────────────────────────────────────────┐
│  全宽 Hero：巨型标题 + BigNumber (高度 ~38%)               │
├────────────────────────────────────────────────────────────┤
│  满铺色块段落 1（品牌色1）                                   │
├────────────────────────────────────────────────────────────┤
│  满铺色块段落 2（品牌色2）                                   │
├────────────────────────────────────────────────────────────┤
│  CTA 色块底栏（深色/强调色）                                 │
└────────────────────────────────────────────────────────────┘
```

Grid 定义：
```css
.stacked {
  display: grid;
  grid-template-rows: 380px 1fr 1fr 100px;
  height: 1080px;
}
```

#### A4 竖版海报 (1080×1440) — Full-Bleed Stack 布局

T4 A4 有两种审美路径，在 Phase 3.6 设计意图声明中选择：

**路径 A：色块驱动**（适合 G1 四色/正红/安全橙等强色彩风格）
```
┌──────────────────────┐
│  Hero (满铺色块)       │  ~560px
│  巨型标题 + BigNumber  │
├──────────────────────┤
│  色块段落 1            │  ~340px
├──────────────────────┤
│  色块段落 2            │  ~340px
├──────────────────────┤
│  CTA + 时空锚点        │  ~200px
└──────────────────────┘
```

**路径 B：边框节奏**（适合白底/米底+点缀色+字体驱动的编辑风海报）
```
┌──────────────────────┐
│  Hero                 │  ~520px, 1.5px 底部边框
│  巨型标题 + BigNumber  │
├──────────────────────┤
│  内容段 1              │  ~360px, 1.5px 底部边框
│  (Feature Rows / 网格) │
├──────────────────────┤
│  内容段 2              │  ~340px
│  (Quote / 能力 / 数据)  │
├──────────────────────┤
│  CTA + 署名            │  ~220px, 粗顶边框(4-6px, accent色)
└──────────────────────┘
```
- 所有 section 间用 1.5-2px `border-bottom: solid` 分隔（而非色块背景）
- 强调色仅用于：边框线、CTA 按钮、kicker 数字、装饰圆点
- 主背景始终为白或极浅灰，文字始终为 ink 色

Grid 定义（两种路径共用骨架，高度可按实际内容微调 ±40px）：
```css
/* 路径 A — 色块驱动 */
.poster-a4-blocks {
  display: grid;
  grid-template-rows: 560px 340px 340px 200px;
  width: 1080px; height: 1440px;
}
/* 路径 B — 边框节奏 */
.poster-a4-borders {
  display: grid;
  grid-template-rows: 520px 360px 340px 220px;
  width: 1080px; height: 1440px;
}
```

#### A3 正方形 (1080×1080) — Center Impact 布局

```
┌──────────────────────┐
│                      │
│    巨型居中标题        │  ~40% (432px)
│    + BigNumber       │
│                      │
├──────────────────────┤
│  2-3 个极简信息点      │  ~40% (432px)
│  水平排列             │
├──────────────────────┤
│  CTA + 时空锚点        │  ~20% (216px)
└──────────────────────┘
```

#### A1 纵向长图 (800px) — Scroll Poster 布局

连续满铺色块段落，高度自适应。每个段落用不同品牌色背景，文字翻色。段落间无间距（色块首尾相连）。

#### T4 A2 布局选择规则

T4+A2 有两种布局，按以下规则自动选择：

- **Split Hero**：适用于有明确左右信息分工的场景——左侧 Hero 用 BigNumber 或核心金句建立第一印象，右侧展示 3-4 个功能/亮点。适合产品发布、品牌展示。
- **Stacked Blocks**：适用于信息按顺序推进的场景——从上到下分段叙述，每段一个子主题。适合活动预告、叙事型海报。

默认使用 **Split Hero**，除非内容包含 ≥3 个需顺序展开的子主题（此时使用 Stacked Blocks）。

#### T4 推荐的 Section 模式

以下 section 模式可与上述布局组合使用，每个 section 本身是一个满铺色块（若使用 P2）或白底+边框分隔（若使用边框节奏）：

**Feature List Rows（功能行列表）**：
```
┌──────────────────────────────────────────┐
│  A. 纯文本段落                        →  │
├──────────────────────────────────────────┤
│  B. Markdown 结构化大纲                →  │
├──────────────────────────────────────────┤
│  C. PDF 文档自动抽取                   →  │
└──────────────────────────────────────────┘
```
- 每行：全宽、上下 1.5px 边框分隔、display 字体、mono 编号前缀、箭头结尾
- hover 效果（web 版）：`padding-left: 16px` 微动
- 适合"功能列表""输入类型""能力清单"等内容

**Quote Spread（金句宣言）**：
```
         "                    ← 巨型引号 200-420px, accent 色, opacity 0.15
  不是把内容塞进模板，
  是先读懂内容，              ← display 字体 40-88px
  再决定它该长什么样。
   ──── onepager 设计理念     ← mono 署名 + 短横线前缀
```
- 巨型引号绝对定位（`top:60px; left:32px`），低透明度
- 正文用 display 字体 + 8px 粗下划线（`text-decoration-thickness: 8px; text-underline-offset: 8px`）强调关键词
- 署名行用 mono 字体 + `::before` 短横线（48px）作为前缀
- 适合"设计理念""品牌宣言""核心价值"等内容

**Eyebrow 横线装饰**：
```
  ────  ONEPAGER  ────
```
- 文字两侧 `::before` / `::after` 伪元素短横线（40-80px × 1.5px）
- mono 字体、letter-spacing 1.5px、uppercase
- 适合 hero 顶部或 section 开头的眉题

**非对称分栏推荐比例**：
- `5:7` — 左标签右内容（最常用，参考网页 01/02/03 区块）
- `3:2:7` — 左编号+中标签+右内容
- `8:4` — 左大内容+右小标注

## 4. T × C 字号调整：T4 宣传海报的字号修正

T1-T3 使用 typography.md 的标准字号阶梯，无需特殊修正。以下仅列出 T4 的专属字号规则。

字号默认由 typography.md 的尺寸-字号对照表决定，按密度的通用缩放规则调整。以下是 T4 的特殊修正：

### T4 宣传海报

T4 的字号阶梯不受 typography.md 的标准阶梯限制，使用以下专属阶梯：

| 层级 | A1 纵向长图 | A2 横向宽图 | A3 正方形 | A4 竖版海报 |
|------|-----------|-----------|----------|-----------|
| BigNumber | **84-120px** | **140-220px** | **120-180px** | **112-160px** |
| 主标题 | **48-64px** | **64-96px** | **48-72px** | **44-64px** |
| 副标题 | 24-30px | 32-48px | 26-36px | 22-30px |
| 正文 | 15-16px | 16-20px | 16-18px | 16-18px |
| 辅助说明 | 12-13px | 12-14px | 12-14px | 12-14px |

关键约束：**BigNumber 与正文的字号比 ≥ 8:1**，任何密度下不可妥协。

## 5. B × T 配色覆盖：T4 海报模式下的推荐配色方案

以下配色覆盖是各风格在 T4 海报模式下的**推荐方案**（非强制）。这些方案天然配合 P2 满铺色块放大器使用。若设计者选择不使用 P2（改用其他放大器组合），则可保持该风格的标准配色或在推荐方案基础上自由调整。

### B9 + T4 → G1 四色满铺（推荐）

当 B9 谷歌原生与 T4 宣传海报组合时，推荐使用 G1 Classic Four-Color 模式替代标准的"白底+蓝CTA+四色点缀"：

| 角色 | B9 标准 (Light) | B9-Poster 推荐 (G1) |
|------|----------------|---------------------|
| 主背景 | `#ffffff` 白 | 品牌四色满铺循环 |
| 辅助背景 | `#f8f9fa` 灰 | `#ffffff` 白（用于信息段落） |
| CTA | `#1a73e8` 蓝 | `#1a73e8` 蓝（保持一致） |
| 色块段落 | 仅点缀 | 红→黄→绿→蓝循环满铺 |
| 文字在色块上 | — | 白字（黄底用深炭 `#202124`） |

CSS：
```css
.color-block-blue  { background: #4285f4; color: #ffffff; }
.color-block-red   { background: #ea4335; color: #ffffff; }
.color-block-yellow { background: #fbbc04; color: #202124; }
.color-block-green { background: #34a853; color: #ffffff; }
```

### B2 + T4 → 正红满铺（推荐）

| 角色 | B2 标准 | B2-Poster 推荐 |
|------|---------|---------------|
| 主背景 | `#ffffff` | 正红 `#dc2626` / 纯黑 `#000000` 交替 |
| 色块段落 | 仅红色短竖线 | 红底白字 + 黑底白字交替 |

### B4 + T4 → 粗野高对比（推荐）

| 角色 | B4 标准 | B4-Poster 推荐 |
|------|---------|---------------|
| 主背景 | `#d4d4d4` 混凝土灰 | 安全橙 `#ea580c` / 纯黑 `#000000` 交替 |
| 色块段落 | 无 | 橙底黑字 + 黑底黄字交替 |

### B5 + T4 → 撞色色块（推荐）

| 角色 | B5 标准 | B5-Poster 推荐 |
|------|---------|---------------|
| 主背景 | `#fefce8` 奶油白 | 亮粉/明黄/宝蓝满铺循环 |

## 6. T × A 比例调整：类型对黄金三段式的修正

通用黄金三段式 (Header 15% + Body 70% + Footer 15%) 是默认建议。以下类型需要调整：

| 类型 | Header | Body | Footer | 说明 |
|------|--------|------|--------|------|
| T1 商业说服 | 15% | 70% | 15% | 使用默认比例 |
| T2 使用指南 | 10% | 78% | 12% | 压缩 Header 给步骤更多空间 |
| T3 信息图 | 12% | 76% | 12% | 给图表更多空间 |
| T4 宣传海报 | 35-50% | 35-45% | 10-20% | Hero 占绝对主导，CTA 精简 |

T4 的比例因布局而异：Split Hero 布局中 Hero 占 40-45%（非 Header 15%），CTA 仅占 10%（非 Footer 15%）。
