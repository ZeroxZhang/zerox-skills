# 一张图怎样讲完一件事

先挑出读者看完应记住的那句话，再圈出其中可以画出来的关系。「多份材料合成一页」可以画成散开的纸张收拢到同一条折痕。「某项指标逆势上涨」可以用一张有真实刻度和直接标注的折线图撑起整个画面。把图拿掉，读者应当少理解一件事。

## 先画两张小构图

拿同一段标题、同一件主图、同一条证据，画两张黑白小稿。第一张让图形的边缘把视线引到标题，第二张让标题压在图形前景，证据落在图形收束的位置。选出标题、主图和证据能连着读的一张，在 IR 中记下阅读顺序。复杂插画和标题可以合成一个焦点。

| 内容任务 | 主图与信息的位置 | 留白用在哪里 |
|---|---|---|
| T1 产品或方案 | 画输入怎样变成结果，把可核对的能力或实例放在结果旁 | 围住结果的轮廓，让读者一眼找到产品能交付什么 |
| T2 操作指南 | 用同一视角画出变化的物件，把动作文字紧贴对应部位 | 给操作之间的转折留间距，物件和它的注释靠近 |
| T3 数据洞察 | 让核心图表占据主位，在异常值旁直接写出结论 | 给轴标、单位、来源留完整位置，减少与数据竞争的纹理 |
| T4 海报 | 用字与图的一个接触点建立前后景，把入口放在动线末端 | 在主标题的一侧留出连续空场，把高频细节集中到另一侧 |

横竖版要重新安排阅读方向。A1 长图可让一条连续图形串起段落，每次转折带出一组新内容。A2 横版用斜向主图连接左右半幅，将两侧信息落在同一条基线上。A3 方版可绕主体拐一个弯，把短标题和出处放在对角。A4 竖版可从上方的大字进入中段的主图，沿图的边缘抵达下方事实。先调构图，再计算固定画布的行高。

判断空间时，同时看图的外轮廓、文字的行长和邻近笔画的黑度。若标题与插画粘连，先移动交叠点或让邻近线条变稀。若页面像三排功能卡，撤掉边框，让一个图占据几列，把解释移到它指向的位置。缩略图里仍显空洞时，放大有信息的主体；若加大后理解依旧毫无变化，换一种画法。

## 让字形参与画面

对标题中的一个词、大号数字或品牌字做处理。正文、图例、步骤与数值单位保留完整字面。根据汉字的部件和英文的字腔选择切口，密笔画字宜只处理外缘。下面的尺寸与位移仅用于举例，可随字号和最终阅读尺寸调整。

| 手法 | 静帧做法 | 适用及退出条件 |
|---|---|---|
| 镂空、反白 | 让粗字成为 SVG 裁切窗口，露出同一张主题插画。也可在深色轮廓内挖出纸色字 | B2、B6、B12 可从一个短词试起。字腔和填充图的亮度接近时，调整裁切位置或改实心 |
| 重叠、套印 | 将一个词沿同一方向偏移，露出一侧色边；两块大色面相交时，手画交叠区的第三种墨色 | B5、B10、B12 分别沿用各自色盘与错位预算。出现双重阅读时收短位移 |
| 切片、拼接 | 用两个互补的裁切区域显示同一字形，沿切线移动其中一片；让切线延续主图上的折痕 | B4、B11、B12 适合硬边处理。缩略时若部件读作两个字，减小错位或换字 |
| 立体字、光影 | 先定光源方向。用侧面窄色带或逐层收短的轮廓表示厚度，在同方向留出实体的投影 | B1、B8 可按本风格约束试用；B7 的数据标签用实心字。投影吞掉字间距时改硬边或撤去投影 |
| 异形、解构 | 从主题物件借一个构成单元，例如用一条折边替换一个笔画，其余关键笔画保持连续 | B11、B12 可选。陌生读者辨认需要依靠下方重复标题时，恢复被替换的笔画 |

B3 的纤维纹理应顺着自然物的轮廓，B9 的结构可借真实产品组件、品牌色块与字的负形。B7 也能有强烈的视觉中心，让有来源的数值和数据形状承担它。各风格原有的色彩、字体和特效限制见[风格目录](design-styles.md)。

例如，下面把同一标题在折痕处拼接。两侧引用同一文字节点，换词或换字体都会同时更新。先将偏移归零看完整字形，再拖动下半部，找到仍能一眼连读的位置。

## 原创 SVG 从轮廓画起

先为主题画一个外轮廓，再决定近处遮住远处的哪一段，最后按受光和曲率添细节。下面是一张纸张翻折的局部习作。上表面、折面和纸背共用折线端点，刻线只落在背光面。换题时先重画轮廓和折线，线纹会随裁切范围移动。

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 240 150"
     role="img" aria-labelledby="fold-title">
  <title id="fold-title">一张纸沿折痕翻起，露出带刻线的背面</title>
  <defs>
    <path id="fold-back" d="M14 96 L116 95
          Q160 82 181 57 Q158 110 89 133 Z"/>
    <pattern id="fold-hatch" width="7" height="7"
             patternUnits="userSpaceOnUse" patternTransform="rotate(24)">
      <path d="M1 0V7" stroke="#22334E" stroke-width="1.6"/>
    </pattern>
  </defs>
  <path fill="#F3EBDD" stroke="#22334E" stroke-width="2"
        d="M14 96 Q77 77 102 21 L218 16 Q183 70 116 95 Z"/>
  <use href="#fold-back" fill="#E46B45"/>
  <use href="#fold-back" fill="url(#fold-hatch)"/>
</svg>
```

主题插画可以单独写成 `.svg`，保存在技能项目的 `source/`，在浏览器里看轮廓和裁幅，再将同一 SVG 根元素内联进 HTML。保留 `viewBox`、命名分组和局部引用，单文件海报离开工程目录后也能渲染。

需要自然弯曲的刻线时，取形状两侧同向、控制点数量相同的三次贝塞尔曲线，对每对对应控制点分别计算 `P(t) = (1 − t) × P左 + t × P右`。用新控制点画一条中间曲线，逐步改变 `t` 即可得到一组顺着物体起伏的线。在背光位置取更密的 `t`，高光处露出纸色。数据图保持真实比例，插画的线条数量不代表测量值。素材自带说明时给 SVG 配置标题或图注，同义的装饰副本用 `aria-hidden="true"`。

## 静帧验收

1. 打开交付 PNG，按 README 或手机的实际显示宽度看一遍。先辨认主题，再顺着图找到证据和行动。若先读到装饰编号，降低其黑度或拿掉。
2. 放回原尺寸，检查字腔、切缝、行尾和图注。若裁掉关键笔画，移动裁切边界；若灰阶里两层混在一起，先调明度，再考虑换色。
3. 检查真实栅格化结果。密线在缩略时可能出现摩尔纹，优先减少线数、拉开间距。SVG 保留 `viewBox`，同页图形 ID 各自唯一。使用 `mask`、`clipPath` 或 `filter` 时核对坐标系和边缘的裁切。
4. 让页面首次加载就呈现可交付画面。静态版本固定图层位置和文字透明度，移除对悬停、滚动进度、随机种子和动画时钟的依赖。断网复核字体回退后字形与遮罩的对位。

## 手法来自哪些作品

- Codrops 的实验把逐字排好的 SVG 文字放入裁切路径，让不同图像通过字面显现。海报可取其中一个对位清楚的静帧，用本题的素材重新定义开窗位置。[TextClipScroll 原作及源码](https://github.com/codrops/TextClipScroll)
- BL/S® 在 2026 年的 Wide 实验中保持同一标题锚点，将同组素材编排成多种列宽、位置和空列。做横竖版转换时，可以用同一份素材重新排出两种阅读顺序。[Wide 作者拆解](https://tympanus.net/codrops/2026/09/28/wide-template/)
- Pentagram 为 Philharmonia 按词的发音节奏重排字标，再把乐器插画或照片与字标分层。将这种方法用于产品海报时，断行依据产品名的意义，前景图形取自产品自己的材料。[Philharmonia 设计案例](https://www.pentagram.com/work/philharmonia)
