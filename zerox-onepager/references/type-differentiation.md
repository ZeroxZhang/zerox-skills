# 内容类型差异化指南

本文件定义了 4 种 OnePage 类型的差异化要求。
Phase 1 识别类型，Phase 2 供用户确认，Phase 3 按类型重构内容，Phase 4 按类型验证必备要素。

---

## 类型总览

| 编号 | 名称 | 核心目标 | 一句话定义 |
|------|------|---------|-----------|
| T1 | 商业说服 | 建立信任，促成转化 | 卖东西——卖产品、卖方案、卖自己 |
| T2 | 使用指南 | 准确传递，降低门槛 | 教操作——步骤、参数、注意事项 |
| T3 | 信息图 | 数据可视化讲故事 | 用数据说话——对比、趋势、洞察 |
| T4 | 宣传海报 | 视觉冲击，情感驱动 | 一眼看穿——情绪钩子+单一焦点+CTA |

每种类型支持 `focus` 子参数，用于细化内部变体：

| 类型 | focus 子参数 | 说明 |
|------|-------------|------|
| T1 商业说服 | `product`（默认） | 偏产品功能卖点、使用场景、CTA |
| T1 商业说服 | `solution` | 偏方法论、案例数据、团队背书 |
| T2 使用指南 | `steps`（默认） | 偏操作步骤、关键提示、FAQ |
| T2 使用指南 | `spec` | 偏参数规格、配置要求、技术说明 |
| T3 信息图 | — | 无子参数 |
| T4 宣传海报 | — | 无子参数，视觉冲击放大器自动启用 |

---

## T1: 商业说服

### 核心目标
建立信任，促成转化

### 必备要素（缺一不可）
1. **价值主张**：一句话说明核心价值（放在标题或首屏）
2. **痛点→解决方案**：用户面临什么问题，我们如何解决
3. **核心支撑**：`focus=product` 时为 3-5 个功能点+场景；`focus=solution` 时为方法论+案例数据
4. **信任背书**：客户数量、案例数据、认证、团队资质（`focus=solution` 时为必备；`focus=product` 时推荐但不强制）
5. **CTA**：明确的行动号召（试用/购买/咨询）

### SCQA 应用（说服型骨架）
- S: 用户当前面临的痛点/低效场景（`focus=product`）或行业现状与趋势（`focus=solution`）
- C: 现有方案的不足
- Q: 如何更高效地解决问题？
- A: 产品名称+核心差异化价值（`focus=product`）或方法论+案例验证（`focus=solution`）

### 内容改写重点
- 痛点描述要具体（"每周浪费 3 小时手动整理数据"而非"效率低下"）
- 功能点要有 so what（不是"支持批量导出"而是"一键批量导出，节省 80% 操作时间"）
- CTA 必须明确单一
- `focus=product`：BigNumber 数据提取 → 用户数、增长率、效率提升百分比、收入规模
- `focus=solution`：BigNumber 数据提取 → 客户数量、ROI 倍数、项目成功率、行业排名

---

## T2: 使用指南

### 核心目标
准确传递，降低门槛

### 必备要素
1. **步骤/流程**：编号化的操作步骤（1→2→3→...）或流程说明
2. **参数/规格**：技术参数、配置要求等具体数据（`focus=spec` 时为必备；`focus=steps` 时可选）
3. **注意事项/关键提示**：常见的错误操作、易错点、快捷方式、最佳实践
4. **示意图/FAQ**：关键步骤的可视化说明（`focus=steps`）或常见问题及解答（`focus=spec` 时可选）

### SCQA 应用（指导型骨架）
- S: 用户需要使用该产品/功能
- C: 使用中有易错点或复杂流程
- Q: 如何正确高效地使用？
- A: 编号步骤+关键提示（`focus=steps`）或参数规格+注意事项（`focus=spec`）

### 内容改写重点
- 步骤必须可执行、无歧义
- 参数必须精确（版本号、尺寸、阈值等）
- `focus=steps`：步骤动词开头，语言口语化，避免专业术语堆砌
- `focus=spec`：删除营销性语言，保留纯功能性描述
- BigNumber 数据提取 → 处理速度、支持量、兼容性覆盖率、错误率降低、操作时间缩短

---

## T3: 信息图

### 核心目标
数据可视化讲故事

### 必备要素
1. **主线叙事**：一个贯穿始终的数据故事线
2. **数据对比**：至少 2 组对比数据
3. **视觉隐喻**：用图形隐喻强化数据含义
4. **来源标注**：所有数据的来源出处

### SCQA 应用（数据叙事变体）
- S: 数据揭示的现状
- C: 数据中的反差/趋势/异常
- Q: 这意味着什么？
- A: 关键洞察+行动建议

### 内容改写重点
- 数据必须标注来源
- 对比要有参照基准（同比/环比/竞品）
- 图表类型严格匹配数据类型（参考 diagram-guide.md）
- 每个数据点要回答 so what
- 删除无法可视化的纯文字论述，转为图表表达
- BigNumber 数据提取：核心对比数字、占比、增长率、规模数据

## T4: 宣传海报

### 核心目标
视觉冲击，情感驱动，促成行动

### 海报与其他类型的本质区别
T1-T3 的信息是被"阅读"的——读者有耐心逐字理解。T4 的信息是被"扫描"的——读者只给 3 秒，必须在 3 秒内传递核心信息。因此 T4 不遵循通用的黄金三段式 (15%/70%/15%)，而是使用专属布局（参考 [交叉规则](cross-reference.md) 的 T×A 布局变体章节）。

### 必备要素（缺一不可）
1. **主视觉焦点**：一个不可动摇的视觉锚点——极大字号的 BigNumber 或主标题。字号必须比其他类型更极端（BigNumber 可达正文字号的 8-12 倍），读者在 3 秒内必须能说出核心信息
2. **情绪钩子**：先抓住情绪，再传递信息。通过震撼数据（BigNumber）、鲜明色彩（满铺色块/高对比度）、或极简留白制造"不得不看"的视觉张力
3. **核心信息层**：2-4 个极简模块，每个模块最多 1 句话（C1）或 2-3 句话（C2）。文字是被"扫描"的，每个句子必须通过 So What 测试
4. **行动号召 (CTA)**：明确单一的行动指引。CTA 占画面 3-5% 面积，使用 10% 强调色，放在视觉动线终点
5. **时空锚点**：时间/地点/联系方式（若有）。格式简短统一（如"2026.06.15""北京·国贸"），最多保留 2 种联系方式

### SCQA 应用（情感驱动变体）
- S: 读者当前的状态/痛点/渴望
- C: 核心冲突/机遇/紧迫感（**情绪冲击点**）
- Q: 为什么现在必须行动？
- A: 核心价值主张 + CTA

> ⚠️ T4 的 S-C 阶段必须有**情绪冲击**而非仅仅是理性铺垫。情绪冲击的手段可以从下方的视觉冲击放大器中选取组合。

### 视觉冲击放大器

T4 海报的核心目标是**视觉冲击力**。P1 巨型字号是所有海报的底线（没有极端字号对比就不叫海报）。P2-P8 是达成冲击力的可选手段——根据风格和内容，从中选择 **2-3 个放大器组合使用**。P2 满铺色块是 B9 谷歌原生、B2 瑞士精密、B4 建筑粗野等风格的自然选择，但并非唯一路径：极简东方可能只用 P1+P4+P6，赛博街道可能用 P1+P3+P7。

各风格在 T4 模式下的子模式切换和字体/按钮适配参考 [交叉规则](cross-reference.md)。

| ID | 名称 | T4 状态 | 做法 |
|---|---|---|---|
| **P1** | 巨型字号 | **强制** | Hero 标题或 BigNumber 使用极端字号 clamp(80px, 14vw, 220px)，line-height 0.9-1.0 |
| P2 | 满铺色块 | 推荐 | 段落使用满铺纯色背景——B9 品牌四色 / B2 正红 / B4 安全橙等，是多数风格的推荐视觉手段 |
| P3 | 描边/镂空文字 | 可选 | 部分标题 `-webkit-text-stroke: 2px ink; color: transparent;`，与实心字混排制造双层效果 |
| P4 | 超大编号 | 可选 | 区块内 160-300px 半透明大数字（01/02/03），可部分溢出视口边界（`top:30px; right:24px; opacity:0.08-0.18`），使用 Anton 或 Bebas Neue |
| P5 | 非对称网格 | 可选 | 打破 12 列，用 5:7、3:2:7、8:4 等非对称分栏 + 负边距让元素跨区块 |
| P6 | 贴纸标签 | 可选 | 旋转 3-8° 小标签（"NEW""限时""2026"），强调色底 + 深色文字 |
| P7 | 走马灯字带 | 可选 | 横向滚动巨型字带，CSS animation，60s+ 一圈，尊重 prefers-reduced-motion |
| P8 | 双色调图像 | 可选 | 照片加 CSS filter（grayscale + sepia 或 mix-blend-mode: multiply）与配色合成 |

### T4 排版细节

以下是与放大器正交的排版技巧，适用于所有 T4 海报：

- **等宽字体用于元信息**：标签、眉题（eyebrow）、署名、列表编号、数据标注——这些"功能性文字"推荐使用 JetBrains Mono，与 display 字体形成节奏对比。参考网页中 nav link、feature tag、meta label、quote attr 均用 mono。
- **边框作为视觉节奏**：1.5-2px 实线（`border-bottom: 1.5px solid var(--ink)`）贯穿 section 分隔，形成统一的"海报/笔记本"视觉语言。**这种手段可以替代或补充满铺色块**——当不使用 P2 时，边框节奏 + 留白 + 巨字同样可以达成海报级冲击力。
- **装饰性圆点**：小号实心圆（8-14px，`border-radius: 50%`，使用强调色）可作为品牌标识旁的视觉标点、走马灯分隔符、或 section marker。
- **眉题横线装饰**：eyebrow 文字两侧用 `::before` / `::after` 伪元素加短横线（`width: 40-80px; height: 1.5px`）包裹，是 Google 活动页的常见手法。

### 字号特殊规则（T4 专属）

T4 允许比 T1-T3 更极端的字号跨度：

| 层级 | T1-T3 标准字号 (A2) | T4 海报字号 (A2) |
|------|---------------------|-------------------|
| BigNumber | 120-180px | **140-220px** |
| 主标题 | 56-72px | **64-96px** |
| 正文 | 18-20px | **16-20px** |
| 辅助说明 | 14-16px | **12-14px** |

> ⚠️ 字号放大不是"所有字都变大"。T4 的核心是**极端的字号对比**——焦点元素更大，非焦点元素可能更小。

### 内容改写重点
- **单一焦点原则**：一张海报只传达一个核心信息。删除测试：删掉任何一个模块，整体逻辑是否依然成立？
- **情绪优先**：先问"这句话能引发什么情绪"，再问"传递什么信息"
- **极简叙事**：低密度下每模块仅 1 句核心金句；中密度下 2-3 句
- **量化即冲击**：128% 比"显著增长"有力量 100 倍
- **CTA 动词开头**："扫码获取"而非"更多信息"
- **缩略图测试**：200px 宽下是否依然可读？
- **信息分区服务于冲击力**：若使用 P2 满铺色块，以色块本身作为信息分区手段，不使用传统边框卡片。若不使用 P2，信息分区方式（网格/排版/留白）应服务于视觉冲击目标而非默认为常规卡片布局
- BigNumber 数据提取：核心冲击数据、规模数据、截止时间数字、排名/限量数字

## 类型识别指引

当内容特征不明确时，按以下优先级判断：

1. 内容包含编号步骤 + 操作说明 → **T2 使用指南**
2. 内容包含活动/事件 + 时间地点 + 行动号召 → **T4 宣传海报**
3. 内容包含数据对比 + 趋势分析 → **T3 信息图**
4. 内容包含产品名称 + 功能列表 → **T1 商业说服** (focus=product)
5. 内容包含方法论 + 行业分析 + 案例 → **T1 商业说服** (focus=solution)
6. 无法判断时 → 默认 **T1 商业说服** focus=product

**注意**：内容原则是分析指南，非刚性删除规则。当用户素材有明确意图与原则冲突时，保留用户原始内容并在交付时提示。
