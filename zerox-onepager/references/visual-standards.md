# 视觉规范

本文件定义了跨风格通用的视觉硬性规则。
无论选择哪种设计风格 (B1-B10)，以下规则必须遵守。
当本文件与 SKILL.md 或其他参考文件出现矛盾时，以 SKILL.md 为准。

> **分工**：本文件负责"硬性规则 + 可验收阈值"；审美判断、九个大图设计手法的定义/代码/反例见 [aesthetic-standards.md](aesthetic-standards.md)。

以下是被明确禁止的"AI 味"设计元素。它们是区分专业设计与生成式堆砌的底线。

### 绝对禁止
1. **蓝紫渐变**：`linear-gradient(135deg, #6366f1, #a855f7)` 及其变体是 AI 设计的首要标志
2. **无意义发光**：`box-shadow: 0 0 30px rgba(...)` 没有信息传达目的的纯装饰发光
3. **多层半透明毛玻璃堆叠**：超过一层 `backdrop-filter: blur()` 会产生浑浊、廉价的视觉效果
4. **无目的圆角**：所有圆角必须有风格一致性的理由（B3 自然形态的大圆角 vs B2 瑞士风格的零圆角）
5. **Emoji 作为图标**：在所有输出 HTML 中必须使用 SVG 图标，emoji 仅限配置菜单（且需克制）
6. **无意义的装饰 blob**：大面积的径向渐变 blob 如果只是为了"让页面不那么空"，那就是设计失败的证据
7. **多个视觉事件**：同一页出现两个同强度焦点（双 hero 的判定见 §9.1）
8. **超额质感与渐变**：质感层超过 1 层、opacity > 0.04，或使用未经风格许可的渐变（风格许可的例外只有 B8 扫描线与 B10 底部可读性渐隐；其余渐变一律视为装饰）

### 优先使用（替代上述禁止项）
- **纯色块** 替代渐变
- **粗体字重对比** 替代发光对比
- **留白** 替代装饰元素
- **精确的对齐和网格** 替代随机放置的装饰

---

## 1. 网格与对齐系统

- 采用 12 栅格或 8pt Grid 作为底层对齐结构
- 所有元素对齐到网格，禁止"目测对齐"
- 模块间距遵循 8 的倍数节奏：8 / 16 / 24 / 32 / 48 / 64 px
- 内边距与外边距也必须对齐到 8pt 节奏

### 8pt 节奏对照

| 用途 | 推荐间距 |
|------|---------|
| 元素内部微间距 | 8px |
| 同组元素间距 | 16px |
| 不同模块间距 | 24-32px |
| 主要区块间距 | 48px |
| 大区块分隔 | 64px |
| BigNumber 模块间距 | 32-48px |

### 光学对齐（几何对齐的补充）

- 大字标题以引号/括号开头（如 “标题” 或 「标题」）时做悬挂：`text-indent: -0.42em`，否则视觉上比正文缩进 4-8px
- 圆形图标/圆点与文字并排时视觉重心偏低：上移 1-2px（`transform: translateY(-1px)`），或放大 2-4% 补面积
- 箭头、三角、勾号不贴基线：`position: relative; top: 0.08em`
- 字距分两套：display 大字 -0.02~-0.04em 收紧，mono 元信息 0.12-0.18em 放开
- 以上四类至少落实 3 类；完整代码与反例见 [aesthetic-standards.md](aesthetic-standards.md) 手法 6

## 2. 留白规则

- 整体页面留白占比 ≥ 30%
- **接近性原则**：模块间留白 > 模块内留白
- BigNumber 模块周围必须有充足的独立留白（至少 32px），以强化其视觉焦点地位
- 按密度分级：
  - 低密度 (C1)：留白 50%+
  - 中密度 (C2)：留白 30-35%
  - 高密度 (C3)：留白 15-20%
- 大图额外要求**一处连续留白 ≥ 画布 25%**，且必须作为"主体"存在（区内元素 ≤1），不是四角散落的缝隙；C3 可降到 ≥15%，但必须归拢成一整块

## 3. 色彩系统

### 60-30-10 法则

- **主色 60%**：通常为中性背景色（白/灰/深色底）
- **辅助色 30%**：品牌/主题色，用于标题、卡片、区块
- **强调色 10%**：高饱和度色，仅用于 CTA、关键数据、重点标注

### 色彩数量限制

- 全页不超过 **3 个主色 + 2 个中性色**（B5 新波普编辑、B8 赛博街道、B9 谷歌原生、B10 短视频潮流例外，但需保持大致的 60-30-10 比例原则；B9 品牌四色满铺色块与 B10 的暗色层级不计入主色限制）
- 强调色不超过 1 个（B5 新波普编辑、B8 赛博街道、B9 谷歌原生、B10 短视频潮流例外，但需有明确的交替规则；B10 允许红+青两个强调色，合计面积 ≤12%，且不得并联成色块）
- **B5 新波普编辑例外**：可使用更多撞色，但需保持 60% 中性底 / 30% 主题色 / 10% 强调色的大致比例
- **强调色面积是硬上限**：全部强调色合计 ≤10%（B10 ≤12%）。这比"强调色不超过 1 个"更强——两个强调色各 10% 依然违规

### 对比度要求

- 正文与背景对比度 ≥ 4.5:1（WCAG AA）
- 大标题与背景对比度 ≥ 3:1
- 装饰性文字对比度 ≥ 3:1
- BigNumber 数字与背景对比度 ≥ 4.5:1（数字必须清晰可读）

### 蓝紫色调警示

生成 HTML 时，主动审查配色方案：
- 如果强调色是 `#6366f1` (indigo)、`#8b5cf6` (violet)、`#a855f4` (purple) 或其邻近色 → ** redesign **
- 如果使用了 `linear-gradient(135deg, blue, purple)` 或类似 → ** remove immediately **
- 允许使用的蓝色：纯蓝 `#2563eb`（仅 B5）、深海军蓝 `#1e3a5f`（仅 B7）、Google 蓝 `#1a73e8` 和 `#4285f4`（仅 B9）
- 允许使用的紫色：`#c58af9`（仅 B9 Dark I/O 模式，因为这是 Google Material Dark 主题配色的一部分，不作为主强调色使用）

## 4. 字体系统

- 字体家族不超过 **2 种**（一种用于标题，一种用于正文）
- 若标题和正文使用同一家族，视为 1 种
- 字号建立清晰阶梯（参考 typography.md 的尺寸-字号对照表）
- 单行字符数控制在 45-75 字符（中文 25-40 字）
- **字重限制**：每页最多 3 种字重（如 400/700/900）
- **三层对比**：同一页必须同时存在字号、字重、色相三个维度的落差——最大/最小字号 ≥10:1（T4；质检脚本 T4 硬门槛 8:1）或 ≥3:1（T1-T3），字重差 ≥300，至少一处高饱和强调色；只靠字号放大不构成层级（转灰度后仍应能数出 ≥3 级）
- **家族计数**：等宽字体只在承载数据/元信息时使用，按 B1/B7/B9 与质检 `[FONT]` 的现状不计入"2 种家族"限制；全页家族总数仍 ≤3（B10 = Inter + Noto Sans SC + JetBrains Mono 即为上限）

## 5. 图形与图标

### SVG 图标规范（强制）

所有图标必须使用内嵌 SVG，禁止在任何输出 HTML 中使用 Emoji。

**使用方式**：
```html
<!-- 在 HTML 头部定义图标（base-skeleton.html 已预置） -->
<svg style="display: none;">
  <symbol id="icon-check" viewBox="0 0 24 24">
    <polyline points="20 6 9 17 4 12"/>
  </symbol>
</svg>

<!-- 在内容中引用 -->
<svg class="icon"><use href="#icon-check"/></svg>
```

**图标风格统一**：
- 线性图标（线宽 1.5-2px）：B1 暗夜编辑、B2 瑞士精密、B7 数据新闻、B8 赛博街道
- 面性图标：B3 有机自然、B5 新波普编辑、B6 极简东方
- 粗边框图标：B4 建筑粗野

**图标尺寸**：
- 默认：24×24px（`class="icon"`）
- 小：16×16px（`class="icon icon-sm"`）
- 大：32×32px（`class="icon icon-lg"`）

### 各风格图标风格速查

| 风格 | 图标类型 | 特征 |
|------|---------|------|
| B1 暗夜编辑 | 线性 | 线宽 1.5px，精细、科技感 |
| B2 瑞士精密 | 线性 | 线宽 2px，简洁、专业 |
| B3 有机自然 | 面性 | 圆角 12px，柔和、自然色 |
| B4 建筑粗野 | 面性 | 粗黑边框，力量感 |
| B5 新波普编辑 | 面性 | 高饱和填充，杂志感 |
| B6 极简东方 | 极简线条 | 线宽 1px，极度克制 |
| B7 数据新闻 | 线性 | 线宽 1.5px，精确、理性 |
| B8 赛博街道 | 线性 | 线宽 1.5px，霓虹色描边 |
| B9 谷歌原生 | 线性 | 线宽 1.5px，`#5f6368`(Light) / `#9aa0a6`(Dark)，Google 4px/8px 圆角 |
| B10 短视频潮流 | 线性 | 线宽 2px（比 B9 更硬），`currentColor`，24×24 viewBox，`stroke-linecap: round`；动作栏 28-32px、正文内联 14-16px |

### 图表规范

- 图表选型遵循"数据—图表"匹配原则（参考 diagram-guide.md）
- 图表配色必须与当前设计风格一致
- 图表中的文字使用与正文相同的字体栈

## 6. BigNumber 设计规范

### 存在性要求
若用户选择 E1（包含 BigNumber），则每张 OnePage 必须包含至少一组 BigNumber 数据展示。BigNumber 是信息图的核心视觉锚点。若用户选择 E2（不包含 BigNumber），则跳过 BigNumber 模块。

### 位置建议
- **A1 纵向长图**：Header 下方，2 个数据横向排列
- **A2 横向宽图**：Header 下方或左侧标题区旁，3-4 个数据横向排列
- **A3 正方形**：Header 下方，2 个数据横向排列

### 视觉冲击原则
1. **数字必须是页面上最大的文字元素**，字号超过主标题的 1.5 倍
2. **字号对比**：数字与标签的字号比至少为 4:1
3. **拒绝平庸**：禁止"小数字+大图标"的做法，数字本身就是视觉焦点
4. **精确对齐**：多个 BigNumber 的基线必须水平对齐
5. **趋势指示**：使用 SVG 箭头（↑/↓/→）+ 颜色区分方向
6. **hero 唯一性**：BigNumber 与主标题不能同时以最高强度争抢第一眼。默认 BigNumber 是 hero、标题降一级；两者同强时按 §9 降级其中一个

### 结构规范
```html
<div class="bignum-item">
  <div class="bignum-value">128<span class="bignum-unit">%</span></div>
  <div class="bignum-label">同比增长</div>
  <div class="bignum-trend up">
    <svg class="icon"><use href="#icon-trend-up"/></svg>
    <span>+23%</span>
  </div>
</div>
```

### 风格差异化

| 风格 | 数字字体 | 数字颜色 | 装饰特征 |
|------|---------|---------|---------|
| B1 | JetBrains Mono | 琥珀 `#f59e0b` | 底部琥珀短横线 |
| B2 | Noto Sans SC 900 | 正红 `#dc2626` | 顶部黑粗线 |
| B3 | Noto Serif SC | 陶土 `#c2410c` | 手绘感下划线 |
| B4 | 系统字体 900 | 黑字+电黄底 `#facc15` | 粗黑边框包裹 |
| B5 | Noto Sans SC 900 | 黑字+黄底 `#fbbf24` | 杂志封面感色块 |
| B6 | Noto Serif SC 400 | 墨黑 `#1c1917` | 朱红细线 |
| B7 | JetBrains Mono | 海军蓝 `#1e3a5f` | 精确网格对齐 |
| B8 | JetBrains Mono | 霓虹粉 `#ff006e` | 错位阴影 |
| B9 Light | JetBrains Mono | Google 蓝 `#1a73e8` | 无装饰线，纯数字 |
| B9 Dark | JetBrains Mono | 浅蓝 `#8ab4f8` | 无装饰线，纯数字 |
| B10 | JetBrains Mono | 红 `#FE2C55`（主）/ 青 `#25F4EE`（辅），第三个起回归 `#F5F5F7` | 无装饰线；仅 T4 允许 1 个数字带双色硬错位阴影（Paper 用墨黑 `#161823`，不做错位） |

## 7. 信息架构视觉规则

### 黄金三段式

- **Header（顶部 15%）**：标题 + 副标题 + 价值主张（一句话）
- **Body（中部 70%）**：3-5 个核心模块，按逻辑组织
- **Footer（底部 15%）**：CTA + 信任背书 + 联系方式

### 视觉动线

- **F 型**：适合文字密集型内容，左上角放最重要信息，读者视线从上到下、从左到右扫描
- **Z 型**：适合图文混排，视线从左上→右上→左下→右下流动
- 右下角放行动指引/CTA
- 各尺寸推荐：
  - A1 纵向长图：F 型动线
  - A2 横向宽图：Z 型动线
  - A3 正方形：Z 型动线
  - A4 竖版海报：Z 型动线

### 视觉层级

通过尺寸、颜色、粗细、对比度，建立至少 3 级层级：
- **L1 主标题**（最大、最重）
- **L2 模块标题**（次重）
- **L3 正文与说明**（轻量、可读）
- **L0 BigNumber**（绝对最大，凌驾于所有层级之上）

### 组块化

- 每个信息组块控制在 **7±2 个元素**以内
- 超过 9 个元素时必须分组
- 不足 3 个元素时考虑合并或视觉强化

### 单一视觉事件与节奏（大图设计感基础层）

- 每页只指定 1 个 hero，写进 Phase 3.8 的设计意图声明；其余元素主动让位：更小、更淡、更规整
- section 高度不平均：最大/最小 section 高度 ≥1.5×，按"大—小—大"或"密—空—密"交替；至少 1 个 section 不放卡片
- "文档感"诊断：所有 section 等高、≥4 个等高卡片、字号阶梯只有 2 级且差 <2×、右缘留白恒为 0——命中 3 条必须重排
- 手法细节、代码与反例见 [aesthetic-standards.md](aesthetic-standards.md) 手法 1 与手法 4

## 8. T4 海报附加视觉模式

以下模式是 T4 宣传海报的推荐视觉手段（与放大器正交），源自 Google 活动站和编辑站的实测分析。

### 边框作为视觉节奏

满铺色块（P2）不是海报冲击力的唯一来源。**1.5-2px 实线边框**贯穿 section 分隔，配合白底+巨字+留白，可以达成同样强烈的海报效果——且更接近 Google 编辑风的克制感。

```css
.section {
  border-bottom: 1.5px solid var(--ink);
  padding: 80px 0;
}
```

适用场景：(a) 不使用 P2 满铺色块时作为替代，(b) 极简东方、编辑风等"以留白为武器"的风格，(c) 需要突出文字内容本身而非色彩冲击时。

### 等宽字体用于元信息

JetBrains Mono 不限于 BigNumber 和数据展示。T4 海报中以下元素**推荐**使用 mono：

| 元素 | 示例 | CSS |
|------|------|-----|
| 眉题 (eyebrow) | "ONEPAGER — 信息图生成 SKILL" | `font-family: var(--font-mono); font-size: 12-14px; letter-spacing: 1-2px; text-transform: uppercase` |
| 功能标签 | "01 · INPUT" | mono 编号 + display 文字 |
| 署名/出处 | "onepager 设计理念" | `::before` 短横线(48px) + mono 文字 |
| 列表编号 | "A." "B." "C." | mono 14px, opacity 0.6 |
| 页脚信息 | "© 2026" | mono 12px, letter-spacing 1px |

### 装饰性圆点

```css
.dot {
  width: 14px; height: 14px;
  border-radius: 50%;
  background: var(--accent);  /* 使用强调色 */
  display: inline-block;
}
```

用途：(a) Logo 旁的品牌标点，(b) 走马灯文字间的分隔符（替代 emoji），(c) Section 开头的标记。

### 眉题横线装饰

```css
.eyebrow {
  display: flex; align-items: center; gap: 16px;
  font-family: var(--font-mono);
  font-size: 13px; letter-spacing: 1.5px;
}
.eyebrow::before, .eyebrow::after {
  content: ""; flex: 1; max-width: 80px;
  height: 1.5px; background: currentColor;
}
```

两侧横线包裹眉题文字，是 Google I/O 和 Year in Search 的常见手法。

### 满血出血与切边巨字

- **满血出血**：元素突破页面 padding 直达画布边缘，一次出血 = 至少一条边与画布边距为 0。实现用负 margin（base-skeleton 的 `.page` 已 `overflow: hidden`，会被准确裁到画布边）：`margin-inline: calc(var(--page-padding) * -1)`；不要用 `100vw`——它含滚动条宽度，A1 桌面预览会多出约 15px 横向滚动，render_check 会报 `[BOUNDARY]`
- **切边巨字**：字号按 `容器宽 ÷ 字符数 × 1.5-1.8`（西文/数字）或 `× 1.0-1.2`（中文全角）估算，再乘 1.15-1.4 的裁切系数；必须保留 ≥2/3 字高，并另有一处 12-24px 的完整标题保证语义可读（可配合 `aria-label`）。对应放大器 P9，每页只用一次
- **质检边界**：让文字真的超出画布会被 render_check 判 `[BOUNDARY]` ERROR；裁切线优先放在画布内部（父级 `overflow: hidden` 的 frame），物理画布边裁切只用于 A1，并在交付摘要登记理由
- 完整代码、安全区规则与反例见 [aesthetic-standards.md](aesthetic-standards.md) 手法 2 与手法 3

## 9. 大图设计感：硬性验收与视觉预算

本节把"一眼看上去有设计感"折算成可勾选的硬指标。手法的定义、代码、反例见 [aesthetic-standards.md](aesthetic-standards.md) 的「大图设计感手法库」；本节只负责**阈值与判定方法**。

### 9.1 九条硬性阈值

| # | 手法 | 硬性阈值 | 强制范围 |
|---|------|---------|---------|
| 1 | 单一视觉事件 | hero 视觉区 ≥ 画布 25%（A1/A2 ≥20%）；"最高强度"元素计数 = 1 | 全部；T4/A3/A4 必须 |
| 2 | 满血出血 | ≥1 处元素与画布边距 0px；出血块宽 = 画布宽 ±1px；无横向滚动 | T4 必须；T1-T3 推荐 |
| 3 | 切边巨字 | ≤1 处/页；保留 ≥2/3 字高；同页另有 12-24px 完整标题 | T4/A4 推荐（放大器 P9，每页仅 1 次） |
| 4 | 节奏而非等分 | section 高度极差 ≥1.5×；≥1 个 section 无卡片；视觉重心偏离几何中线 ≥5% | A1/A4 必须；A2/A3 推荐 |
| 5 | 负空间作为主体 | 一处连续留白 ≥ 画布 25%，区内元素 ≤1；总留白 ≥30% | 全部（C1 ≥50%） |
| 6 | 光学对齐 | 四类补偿（悬挂标点/圆形上移/箭头基线/字距）至少落实 3 类 | 全部 |
| 7 | 可控质感层 | 层数 ≤1；`opacity ≤0.04`；文字对比度下降 <10% | B3 纸纹、B8 扫描线；B9/B10 禁止 |
| 8 | 三层对比 | 字号 ≥10:1（T4）/ ≥3:1（T1-T3）；字重差 ≥300；强调色合计 ≤10% | 全部；T4 强制 |
| 9 | 视觉预算 | §9.2 前 8 项"必须"全部为真（第 9-10 项为 T4/A1 扩展检查） | 每次构建 |

## B10 短视频潮流（Short-Video Feed）的视觉规则

> 设计哲学：把短视频 Feed 的沉浸感搬到静态画布。黑是舞台不是装饰，红青是唯一两个高音，其余交给灰度层级；信息像"悬浮在视频之上"。
> 本节定义 B10 的**视觉层硬规则与验收**；完整配色/字体/组件参数见 [design-styles.md](design-styles.md) 的 B10 章节，模式覆盖以 [config-schema.json](config-schema.json) 为准（Dark 默认、Paper 编辑白、T4 固定 Dark）。

### B10.1 调色板

| 角色 | Dark（默认） | Paper（编辑白） |
|------|-------------|----------------|
| 页面底 | `#0B0B10` | `#FAFAFA` |
| 视频沉浸区 | `#16161C` | 卡片白 `#FFFFFF` |
| 卡片 / 悬起 | `#161823` / `#1C1E2A` | `#F2F2F4` / `#FFFFFF` |
| 分隔线 / 强调边框 | `#262838` / `#3A3D52` | `#E8E8EC` / `#161823` |
| 正文 / 次要 / 三级 | `#F5F5F7` / `#AEB2C0` / `#84868F` | `#161823` / `#5D5F6B` / `#87878F` |
| 强调红（深压） | `#FE2C55`（`#E61E45`） | 仅 1px 线与角标 |
| 对位青（深压） | `#25F4EE`（`#14D6D0`） | 仅 1px 线与角标 |
| 强调底上的字 | `#161823` | — |

- ⚠️ 一页最多 **12 个唯一色值**（质检已登记 B10 上限 12）：Dark 的 11 个基础角色 + 二选一（`#1C1E2A` 悬起卡，或状态色 `#10B981`/`#E5484D`），不要同时用满；红底/青底上的字永远 `#161823`，不要白字压青

### B10.2 色彩预算与禁忌（硬规则）

- 红 **5-8%**（动作色：CTA、首个关键数字、警示、当前项）+ 青 **4-8%**（结构色：分隔线、编号、右栏、引用条、单位符号），**合计 12-16%**；红青**不得并联成大色块**（相邻或同段落成片即违规）
- ⚠️ **青色必须承担 ≥2 处结构功能**：只出现在双色错位的 4px 描边里等同于没用。落地前回答"青在这张图上干了哪两件结构性的活"
- T4 例外（继承 design-styles.md）：允许**一条**满宽红色 CTA 条（高度 ≤ 画布 8%；A2/A3 ≤86px、A4 ≤115px）或**一块**满铺红 hero 区（面积 ≤35%），二选一，不得同时出现
- 全页 pill 只允许 1 个（CTA），`border-radius: 999px` 只给它；其余元素圆角 ≤12px
- Paper 模式红青合计 ≤8%，只做 1px 细线、角标、下划线与小色块，**不能承载文字**（`#FE2C55` 在白底约 3.5:1，低于正文 4.5:1）
- 圆角只用 2 / 6 / 8 / 12（卡片 8）。B10 的圆角上限为 4 档（quality_check 已按风格放宽：B10 为 4 档、其他风格仍为 3 档），所以 2/6/8/12 四档属**合规通过**，不产生 `[CONSISTENCY]` 告警；只有超过 4 档才告警

**B10 禁忌（命中任一项即返工）**：扫描线 / 故障 glitch / 霓虹光晕 / 蓝紫与霓虹紫；红青铺成大色块或相邻成"廉价霓虹"；引入第三种强调色；除底部渐隐外的任何渐变；两个 pill 或两个红色 CTA；500/600 字重、面性/彩色/圆底图标、圆角超出 2/6/8/12。

### B10.3 标志性手法（可选签名每页最多 2 个；双色错位全页 1 处）

| 手法 | 做法 | 次数预算 |
|------|------|---------|
| 双色错位 | 一个元素拆三层：青 `translate(-3px,-2px)`、红 `translate(3px,2px)`、主体白/墨在最上层 | 1 处/页 |
| 底部渐隐 | 唯一允许的渐变；覆盖底部 25-30%，只为压字可读性 | 1 处/页 |
| 右栏动作堆叠 | 右边缘竖排 icon + mono 计数，3-4 项 | 1 条/页 |
| mono 元信息 | 11px / `letter-spacing:.14em` / uppercase，色 `#84868F` | 所有元信息 |
| 硬边框节奏 | `1.5px solid #3A3D52` 贯穿 section 分隔 | 贯穿全页 |
| 胶囊 CTA | `border-radius: 999px`，红底，全页唯一 pill | 1 个/页 |

> mono 元信息与硬边框节奏属于**结构层**，默认全用；双色错位、底部渐隐、动作栏、胶囊 CTA 是**可选签名**，每页最多选 2 个（双色错位恒 ≤1 处）。

```css
/* 双色错位：父级必须建立层叠上下文（z-index:0），否则负 z-index 会被页面底色吃掉 */
.chromatic { position: relative; display: inline-block; z-index: 0; color: #F5F5F7; }
.chromatic::before, .chromatic::after { content: attr(data-text); position: absolute; left: 0; top: 0; pointer-events: none; }
.chromatic::before { color: #25F4EE; transform: translate(-3px, -2px); z-index: -1; }
.chromatic::after  { color: #FE2C55; transform: translate(3px, 2px);  z-index: -2; }
```

```css
/* 底部渐隐：全风格唯一允许的渐变，压在视频区与底部文字之间 */
.scrim {
  position: absolute; left: 0; right: 0; bottom: 0; height: 28%;
  background: linear-gradient(to top, rgba(11,11,16,.92), rgba(11,11,16,0));
  pointer-events: none;
}
```

- **右栏动作堆叠**：`position:absolute; right:24px; bottom:28%; flex-direction:column; gap:18px`（A2 用 32-40px），配 2px 线性 icon 28-32px + mono 计数 11px `#AEB2C0`；3-4 项，只承载关键指标或目录

**底部渐隐的可读性约束**：只在"视频沉浸区/图像块 + 压在其上的底部文字"之间使用；文字必须落在透明度 ≥0.85 的区段；Dark 起始 0.92-0.95 → 0，Paper 图像段 `rgba(250,250,250,.96)` → 0；覆盖 25-30%，超过 30% 就变成背景渐变，禁止；视频区是纯色且底部无文字时不要叠。全页渐变层数 = 1，不得叠加第二层（"银幕上暗下亮"由底色与这层渐隐共同形成）。它会被质检识别为「可读性渐隐」（readability scrim：`to top` + 单一色相 alpha 斜坡）并直接 PASS，不报 `[GRADIENT]` 告警；只有多色相渐变、或叠加第二层渐变才会告警。

### B10.4 字体与字重

- display：Inter / Archivo 700-800，`letter-spacing: -0.02em`，`line-height: 0.95`；中文标题 Noto Sans SC 900
- 正文：Inter + Noto Sans SC 400，`line-height: 1.6`；等宽：JetBrains Mono 400/500/700，mono 元信息固定 11px / `letter-spacing: .14em` / uppercase
- Paper 强调词：Georgia / Noto Serif SC 斜体，只替换 display 里的一个词，不叠加新家族
- 字重最多 3 种：400 / 700 / 900；禁止 500/600 混入 display 层级
- 家族计数：Inter + Noto Sans SC + JetBrains Mono = 3；等宽不计入"2 家族"限制（见 §4），但不得再引入第 4 个家族

### B10.5 图标与 BigNumber

- 图标：线性 2px stroke（比 B9 的 1.5px 更硬），24×24 viewBox，`stroke-linecap: round`，`currentColor`；动作栏 28-32px、正文内联 14-16px；禁止面性/彩色/圆底图标
- BigNumber：JetBrains Mono 700，红（首个）/ 青（第二个）/ 第三个起回归 `#F5F5F7`，无装饰线；与正文比 ≥8:1（T4）
- 唯一允许的 text-shadow：`text-shadow: 3px 2px 0 #25F4EE, -3px -2px 0 #FE2C55`——仅 T4、仅 1 个数字，且与标题的双色错位共用"每页 1 处错位"额度
- Paper 模式 BigNumber 用墨黑 `#161823`，不做错位；禁止任何带模糊的阴影（`0 0 Npx` 一定是发光，不是错位）

### B10.6 T4 用法

- 固定 Dark（config-schema `mode_rules`）。两条路径二选一（继承 cross-reference.md §5）：**路径 A 银幕海报**（上 55-65% 视频沉浸区 + 下 35-45% 信息层；P1 巨字 + P9 切边出血 + 底部渐隐 + 1 处双色错位）；**路径 B 动作海报**（满宽红 CTA 条 ≤8% 高，或满铺红 hero 区 ≤35% 面积 + P4 超大 mono 编号）
- 放大器：P1 强制 + P4/P5 选其一（路径 A 可加 P6 红/青角标）；**禁用 P2 满铺色块**（与 ≤12% 预算冲突）；**禁用 P3 描边文字**（B10 明确不允许）；P7 走马灯慎用（静态 PNG 看不出动画，若用必须静帧可读并尊重 `prefers-reduced-motion`）
- CTA：满宽红条或胶囊 pill，二者只留一个"红色动作"；全页唯一
- 底部渐隐只压在视频区与底部文字之间；纯色无字区不叠

### B10.7 与 B8 赛博街道的视觉层分界（不可混用）

| 视觉层标记 | B8 赛博街道 | B10 短视频潮流 | 质检信号 |
|-----------|------------|---------------|---------|
| 扫描线 | 允许（`repeating-linear-gradient`，opacity .03） | **禁止**（出现即风格越界） | `[GRADIENT]` WARNING（多色停靠，不享受 scrim 豁免） |
| 噪点/纹理 | 允许（opacity ≤0.04） | **禁止**（B10 靠灰度层级，不靠材质） | 质感层检查 |
| 故障/错位 | 允许标题 glitch | 只允许 1 处双色错位，不是 glitch | 多处 text-shadow 即违规 |
| 发光 | 允许霓虹描边 | **禁止**霓虹光晕 | `[SHADOW]` WARNING |
| 霓虹紫 | 不用（只用粉+青） | **禁止**，且不得引入第三种强调色 | `[COLOR]`/蓝紫 WARNING |
| 渐变 | 不用 | 仅底部可读性渐隐 1 层 | 识别为 readability scrim → PASS；多色相才告警 |
| 圆角 | 0（锐角） | 2/6/8/12，pill 仅 CTA | PASS（B10 上限 4 档；其他风格 3 档） |

> 判定口诀：看到扫描线/故障/发光边 → B8；看到右栏竖排 icon + 底部渐隐 + 唯一胶囊 CTA → B10。

### B10.8 Paper 模式：保持同一套节奏

- **不变**：section 高度序列（大—小—大）、右栏动作堆叠、1.5px 硬边框（改 `#E8E8EC`）、mono 元信息、BigNumber（墨黑 `#161823` + 红青只做角标）；`grid-template-rows` 与 Dark 版用同一套数值
- **只变三处**：底色翻白；红青降为 1px 线与角标、下划线、小色块（合计 ≤8%）；强调词改用 Georgia / Noto Serif SC 斜体（全页 1 处）
- 留白从 ≥30% 提到 ≥35%——Paper 靠留白而不是暗场制造沉浸；不要给 Paper 加暗色 scrim（除非该段真的压了图像）
- 禁止：红青做成满铺色块；混入 Dark 卡片色；用 Dark 的硬边框色

### B10.9 B10 验收清单

- [ ] 红+青面积实测 ≤12%（Paper ≤8%），无并联色块；T4 红色例外二选一且不超标；渐变 =1（仅底部渐隐）且覆盖 25-30%
- [ ] 双色错位 ≤1 处；pill ≤1；扫描线 / glitch / 发光 / 蓝紫 / 霓虹紫 = 0
- [ ] 字重只有 400/700/900；icon stroke 统一 2px；圆角仅 2/6/8/12；唯一色值 ≤12
- [ ] T4 已用 P1、未用 P2/P3；正文与 BigNumber 对比度达标；Paper 红青不承载文字
