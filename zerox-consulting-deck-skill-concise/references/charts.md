# 图表选型：准确且丰富的表达

S3 逐页构思时读。先扫 13 类关系，再读命中类别的候选与条件；不从现成组件或最熟悉的图开始。本文件吸收 Gene Zelazny 方法导向的 charts.md 中的分类、资格筛选和候选比较，面向静态 HTML／PDF；五类基础比较之外的分类是现代业务表达扩展。

## 从内容决定表达

**主题 → 数据支持的信息／待探索的问题 → 读者要完成的判断 → 主要与次要关系 → 候选表达 → 实现。** “销售分析”只是主题；“海外贡献多数增量”才是信息；比较增量贡献时，增长率柱图不能代替贡献图。解释型传达已支持的信息，探索型保留问题与不确定性，监测型显露基准、状态与异常。

**准确且丰富的图表使用是本技能的质量目标。** 有可视化价值的分布、变化、层级、流向、机制与条件应主动展开，不能因缺少封装退回三栏摘要、重复短条图或纯表格。丰富来自不同阅读任务得到适合的表达；同一种任务保持一致编码，不能为凑种类换图。

**图型一旦选定，就不因放不下而改为普通表格。** 类别多、连线密、标签长、有小片或零值、组件装不下、渲染报错，都不是换表达的理由：先改空间、方向、分面、总览＋局部或绘制路径，仍做不出来就如实报未完成。工具不会替你返回表格，也不允许把绘图受阻改写成"重新选型"后交付表格。表格只有在读者的任务本来就是逐格查数时才作为主动选择。

1. 识别主要关系，在相关类别中浏览候选；多个关系考虑互补组合。不要求遍历无关类别或逐项记录淘汰过程。
2. 先排除不成立的方案：必要数据／真实关系缺失、口径不可比、编码误导、静态媒介不可读或当前依赖不可用。视觉表现力不能补偿这些缺陷。
3. 对真正可行的方案比较任务匹配、比较精度、重点识别、信息容量、学习成本和制作成本。检查熟悉的图是否隐藏重要关系，较少使用的图是否能更直接回答问题。
4. 确定主方案；只有实质取舍才记一个备选及胜出条件。不编造分数，不另建候选台账；理由融入已有页面构思。

## 关系、候选与选择条件

统计图以构成、项目、时间序列、频数分布、相关性为基础，再扩展到以下关系。定性材料不强塞进五类比较。候选是可组合、可扩展的知识范围，**不代表原生支持或已实测的组件清单**；同一图可服务多类关系，小多图、表格与文字同台竞争。

### A. 对象比较与排名

候选：水平条形图；垂直柱形图；分组条形图／分组柱形图；点图；棒棒糖图；哑铃图；坡度图；发散条形图；排名变化图（Bump Chart）；带状排名图（Ribbon Chart）；帕累托图；小多图；排名表／带数据条的表格。

- 类别名较长时，优先水平布局；
- 精确比较时，优先共用基线的位置或长度编码；
- 两个状态之间的变化，可考虑哑铃图或坡度图；
- 多期名次变化，可考虑排名变化图；
- 累积贡献与重点对象识别，可考虑帕累托图；
- 对象过多时，考虑分组、小多图或有依据的 Top N + 其他。

不得用排序破坏时间、阶段或业务流程的固有顺序。

### B. 时间趋势与周期

候选：折线图；阶梯线图；时间柱形图；面积图；堆积面积图；百分比堆积面积图；柱线组合图；火花线／迷你趋势图；日历热力图；季节性子序列图；时间热力矩阵；河流图／主题河流图；区间带趋势图；预测区间图；地平线图；小多趋势图。

- 连续趋势通常优先折线图；
- 离散期间总量可用柱形图；
- 状态在特定时点跳变可用阶梯线；
- 周期、日历异常可用日历热力图；
- 多个系列相互遮挡时，优先小多图，而不是不断增加颜色；
- 河流图适合观察组成与起伏，不适合精确比较各系列数值；
- 平滑曲线不得暗示数据中不存在的连续变化或精确拐点。

区分缺失、零值、插值和预测值，不得混画为同一种已观测事实。

### C. 构成、占比与层级

候选：饼图；环形图；堆积条形图／堆积柱形图；百分比堆积图；华夫图／单位方格图；矩形树图；旭日图；冰柱图；树形图；圆打包图；马赛克图；Marimekko 图；嵌套构成图；构成小多图。

- 饼图和环形图仅在类别较少、整体定义明确时作为候选；
- 精确比较占比时，优先条形图；
- 多对象占比对比可用百分比堆积图，但注意中间片段难以比较；
- 大量类别及层级规模可用矩形树图；
- 强调层级路径可用树图、旭日图或冰柱图；
- 圆打包图适合结构概览，不适合精确数值比较；
- Marimekko 图可同时呈现组规模与组内构成，但必须说明宽度和高度的含义；
- 单位方格图需说明每格代表的数量及取整规则。

不对非互斥、不可加总的数据强行制作部分与整体图。
不得把任意缺失类别简单并入“其他”而不说明。

### D. 分布、离散与异常

候选：直方图；密度曲线；箱线图；小提琴图；条带图；蜂群图；山脊图；经验累积分布图；QQ 图；二维分箱热力图；六边形分箱图；单变量点分布图；分组分布小多图。

- 观察集中区间和尾部时，可用直方图；
- 比较多个群体的中位数、离散程度和异常值时，可用箱线图；
- 需要看分布形状时，可用小提琴图或密度图；
- 样本较少时，优先保留单个观测点；
- 比较阈值以下的累计比例时，可用经验累积分布图；
- 点大量重叠时，考虑确定性错位、透明叠加、分箱或密度表达；静态版检查遮挡与叠加色能否被正确理解；
- QQ 图主要用于分布诊断，不作为一般管理者页面的默认图。

必须说明或检查：
样本量、分箱规则、密度估计方法、异常值定义及统计口径。

不得仅展示均值而掩盖决定解读的分布差异。

### E. 相关性、多变量与群组

候选：散点图；气泡图；散点图矩阵；相关矩阵热力图；带趋势线的散点图；四象限图；平行坐标图；雷达图；多变量热力矩阵；分面散点图；联合分布图；聚类结果可视化。

- 两个数量变量的关系优先考虑散点图；
- 第三个数量变量可用气泡面积，但需控制大小范围；
- 多变量关系可用散点矩阵或平行坐标；
- 多对象多指标对比通常优先热力矩阵，而非叠加大量雷达图；
- 雷达图仅在维度较少、尺度可比、维度顺序有合理依据时作为候选；
- 四象限阈值必须有业务依据，或明确注明为探索性划分；
- 聚类可视化必须有真实的聚类方法或已知类别支持。

气泡数值按面积映射，不能直接按半径映射。不能将相关性描述为因果性。
不能把视觉上看似分组直接宣称为统计显著的群体。
雷达图面积不得被当作无定义的“综合能力总分”。

### F. 目标达成、绩效与指标状态

候选：指标卡／Card；KPI 卡；子弹图；目标对比条形图；进度条；仪表盘／Gauge；阈值分区图；实际值与预算组合图；指标卡 + 火花线；绩效矩阵／记分卡；控制图；多指标状态表。

- 单一指标展示需同时考虑单位、时间和比较基准；
- 目标、实际值和绩效区间并列时，优先考虑子弹图；
- 仪表盘适合少量关键指标的状态识别，不作为高密度比较的默认形式；
- 同比、环比、预算差异必须标明基准；
- 指标上升不一定代表变好，要依据业务语义设置颜色；
- 控制图需有合适的统计过程和控制限计算依据。

不得将任意目标线称为统计控制限。
不得将 0—100% 的装饰刻度用于没有合理百分比含义的指标。

### G. 增减变化、贡献与桥接

候选：瀑布图；桥接图；差异条形图；发散贡献图；起终点哑铃图；增量贡献排序图；收入／利润变动桥；驱动因素分解图。

- 展示起点如何经由增减项到达终点，可用瀑布图；
- 比较各因素增减幅度，可用差异条形图；
- 比较增长贡献时，优先展示增量或贡献比例，而不只是增长率；
- 分解方法依赖模型时，说明计算方式及假设；
- 交互项、残差和无法解释部分不能隐藏。

必须核验起点、各增减项和终点能否对账。
不得把描述性拆分直接称为因果归因。

### H. 流程、流量、迁移与转化

候选：漏斗图；阶段转化条形图；桑基图；冲积图；平行集合图；转移矩阵；队列分析热力图；留存曲线；用户路径图；流程图；泳道图；客户旅程图。

- 有明确顺序的阶段转化可用漏斗图或转化条形图；
- 不同来源、去向和数量分配可用桑基图；
- 跨阶段类别迁移可用冲积图；
- 大量类别之间的迁移可改用转移矩阵；
- 留存与不同进入批次表现可用队列热力图；
- 定性流程使用流程图或泳道图，不伪造流量宽度。

漏斗各阶段必须具有可比较的统计口径。
非递减的阶段数据要先检查是否适合漏斗表达。
桑基图应检查节点流入、流出以及损耗、补充和统计口径；不强行假设所有业务过程都严格守恒。具体渲染器要求无环／守恒时，显式表示边界节点或更换实现，不能改数据。

### I. 网络、关系与生态

候选：节点连接图；力导向关系图；环形网络图；邻接矩阵；弦图；二部图；树状关系图；关系小多图。

- 少量实体的关系概览可用节点连接图；
- 稠密网络通常考虑邻接矩阵；
- 两组对象之间的对应关系可用二部图；
- 弦图适合有限类别间的流量概览，不适合大量精确查数；
- 节点大小、边宽、颜色和箭头必须有明确定义。

力导向布局中的几何距离不自动代表真实业务距离。
不得把布局生成的团簇直接视为经验证的社群。

### J. 地理、空间与位置

候选：分级设色地图；比例符号地图；地理散点图；地理气泡图；地理密度图；起讫流向图；路线图；区域填充地图；瓦片／网格地图；变形地图；地图小多图；室内平面／空间位置图。

- 只有地理位置确实参与问题解释时，才优先使用地图；
- 单纯比较各地区数值，排序条形图往往更清晰；
- 分级设色地图通常适合比率、密度等标准化指标；
- 总量可考虑比例符号，避免区域面积误导；
- 点密度不等于业务发生率；
- 地图流线要控制数量、重叠与方向编码。

检查：
边界版本、地理编码、投影、缺失区域和数据分母。

地图底图、地理数据及外部服务的可用性和许可需单独确认。

### K. 区间、不确定性与金融

候选：误差棒图；区间点图；置信带；预测区间图；范围条形图；扇形预测图；森林图；龙卷风图；K 线图／蜡烛图；OHLC 图。

- 区间必须说明代表标准差、标准误、置信区间、预测区间还是最小—最大值；
- 多个估计值及区间比较可用区间点图或森林图；
- 敏感性分析可用龙卷风图；
- 开盘、最高、最低和收盘数据可用 K 线图；
- 不为增加“专业感”而给普通经营指标套用金融图形。

没有区间数据、模型或统计计算依据时，不得编造不确定性范围。

### L. 项目进度、时间安排与定性信息图

候选：甘特图；范围时间条；里程碑时间线；路线图；泳道时间线；资源负荷热力图；优先级矩阵；责任分工矩阵；逻辑树；架构图；循环图；层次结构图；对照卡片；图标阵列；词云。

- 时间安排与依赖要分开表达或清楚关联；
- 定性矩阵的评分依据需要说明；
- 图标阵列的数量编码必须准确；
- 词云只适合粗略展示词频印象，不代替准确排序、语义分析或情绪分析；
- 定性结构不因画成漏斗、金字塔或圆环就自动具备数量关系。

机制与定性材料还可用机制／反馈、价值链、依赖、条件决策、战略屋、鱼骨和服务蓝图；箭头标清作用、交接、包含或前置条件及证据状态，不能用连接制造已证实因果。

### M. 表格与复合视图

候选：明细表；交叉表；矩阵；高亮表／热力表；数据条表格；带火花线的表格；图表与明细联动；小多图；主图 + 局部放大；总览 + 分解；KPI + 趋势 + 驱动因素；地图 + 排名 + 明细。

当读者的主要任务是查询准确值时，表格是首选之一，不是退而求其次。**这个判断要在选型时就成立**：依据是读者要逐格核对明细、口径与零值，不是图放不下；同页既需扫描又需核对时用分工清楚的两个展品。

复合视图应使用互补表达。
不得用多个图重复展示同一信息，仅为了填满页面。

## 从选择接到成稿

- **先选表达，再选实现。** `sweep_forms.cjs` 只查已有组件的入口与容量；没有封装不是淘汰图型的理由。**有配方的图型就走配方**（`recipe.*`）：ECharts 出图，旁解读交给通用标注层，写法与 kit 页一致——不要仅仅因为"这页要加旁解读"就退回手写 SVG。没有配方的组合图用原生 option 经 `render_echarts_svg.cjs` 输出内联 SVG（这条路径没有锚点，不能声明 `annotations`），或手写 `svg.custom`；精确表格用 HTML。都遵守[实现与容量](exhibits.md)与[精度](precision.md)。
- `pages.json` 用 `form` 指定实现入口；通用 SVG 用 `svg.custom`，并用 `visual` 写实际图型，如 `ecdf`、`forest`、`adjacency-matrix`；成稿对应 `data-visual`。相同表达跨页使用相同名称，不把不同自定义图都称为“自定义图”来评估丰富度。
- 相近选择要讲清取舍：哑铃／坡度／分组柱；箱线／小提琴／蜂群／ECDF；桑基／流程／转移矩阵；地图／排行；子弹／KPI；机制／依赖／树。只比较与本页相关的项，不强制多方案产物。
- 全篇复看：是否有被摘要掩盖、值得展开的关系；是否因组件方便错过合适的图；复杂图是否增加理解；重复是否为了比较一致。不得用图型数或换色证明丰富，也不得用“简洁”豁免内容适合的丰富表达。
- 静态读者不能悬停、筛选、钻取；关键值、标签、单位、期间、解释和来源须直接可见。交互视图改为明确路径、分面或总览＋细节，不能将关键证据藏在交互后面。实际／预测、缺失／零、百分比／百分点分开。
- 精确比较优先共尺度的位置和长度；柱／条以零为基线，折线的非零起点明确标示，双轴不制造相关。跨图同语义保持名称、颜色、单位、顺序和量尺；独立尺度显著说明。
- 选型通过仍需核对真实数据映射、标签、尺度与静态可读性，实际看 HTML／PDF。独立 planner 只在用户指定或仍有实质性选型难题时按[可选专家接入](planner.md)使用；常规选型不加载它。
