# 方法选择：从业务问题到可执行分析

**什么时候读这一份**：S1 判断用什么方法研究、S2 实际执行分析时。不必通读——先看路由，再只取相关方法的行。
**读完要能做什么**：为每个关键议题说出用了什么方法、为什么成立、结论边界在哪；材料不足时知道该输出什么、不该输出什么。结果如何表达见[证据与表达](exhibits.md)。

## 从问题出发的路由

| 业务问题 | 首选方法链 | 重点回避 |
|---|---|---|
| 公司怎样创造价值和赚钱 | 商业模式 → 客户任务与价值主张 → 单位经济性 | 用画布填满代替验证商业可行性 |
| 行业是否值得进入、哪个细分优先 | 边界与规模 → 五力 → 价值链与利润池 → 进入选项 → 投资情景 | 把 TAM 或行业高增长等同于可获得利润 |
| 收入或利润为何变化 | 口径与探索 → 盈利驱动树 → 量价组合分解 → 客户任务与因果检验 | 把贡献分解当因果；把 GMV 当净收入 |
| 增长来自哪里、是否可持续 | 增长方向 → 细分需求 → 漏斗与 cohort → 单位经济性 | 只看总量均值；把新增与迁移重复计算 |
| 多业务如何配置资源 | 业务组合 → 资本回报 → 现金与情景 | 由象限自动下投资或退出命令 |
| 项目值得投多少、何时回收 | 单位经济性 → 经营预测 → 增量现金流 → 敏感性 | 先画增长曲线再编假设；强行计算 IRR |
| 企业价值或交易价格是否有依据 | 经营预测 → 估值 → 情景边界 | 混用企业/股权价值、现金流/折现率 |
| 经营效率怎样改善 | 流程瓶颈 → 成本机制 → 增量收益 | 用裁员比例代替工作量与产能分析 |
| 组织怎样支持战略 | 组织一致性 → 责任与依赖 → 资源预算 | 只重画组织架构；阶段箭头混合不同维度 |
| 大量文本或案例说明什么 | 数据质量 → 文本编码 → 细分或自定义对照分析 | 把采访频次当市场比例；把成功案例当必要条件 |
| 开放行业研究 | 研究地图 → 五力/价值链/成本供需按议题取舍 → 数据与文本 → 综合未知 | 没有材料就先宣布投资方向 |
| 已确认文稿变成报告 | 必要核对 → 叙事组织 → 既有图示路由 | 强行重做全套研究与财务模型 |

**一个问题可以组合方法；一种方法可以服务多个议题。** 方法目录不是白名单，符合问题与证据的方法可直接使用。

## 方法速查

每个方法只记两件事：**什么时候该用它**，**最容易犯的错 / 必须成立的前提**。方法本身的定义按既有知识使用，不在此重复。

### 商业模式与客户

| 方法 | 什么时候用 | 最容易犯的错 / 必须成立的前提 |
|---|---|---|
| 商业模式（价值创造—交付—获取） | 解释谁使用、谁付费、为什么付费、如何交付；新业务或模式比较 | 画布填满不证明需求、盈利或竞争优势；平台把用户、商家、平台收入分开，**GMV 不自动等于收入**；无财务数据只给模式假设，不给盈利结论 |
| 客户细分、任务与价值主张 | 何种客户在何种情境选择或放弃；比较真实需求 | **不能由几段引言测算市场渗透率**；意向与付费行为分开，写明样本选择偏差；不把品牌口号当价值主张证据 |

### 行业研究

| 方法 | 什么时候用 | 最容易犯的错 / 必须成立的前提 |
|---|---|---|
| 研究地图与市场规模（TAM/SAM/SOM） | 界定研究对象、细分空间与可服务市场；进入或行业研究 | 市场规模不回答企业能赢多少、能赚多少；容量/存量/年度流量分开；**缺基础数据给变量化模型与取证计划，SOM 不能默认 TAM×随意份额**；不同方法差异要解释，不平均成"共识" |
| 五力与行业盈利机制 | 竞争结构如何影响议价与盈利；结构正在变化 | 竞对名单不替代五力分析，五力不单独决定进入；**不能以主观 1–5 分合计成进入概率**；证据薄弱时报待验证机制，不画精确百分比 |
| 价值链与利润池 | 识别活动、价值获取位置与利润分布；进入环节、纵向整合、经营诊断 | 收入最大环节不等于利润最多或最好进入；**上下游收入相加常含中间交易重复，不称终端市场规模**；利润口径须声明；经济利润需资本成本依据，不与营业利润混加 |
| 成本曲线、供需与外部情景 | 同质产品的成本位次与供需约束；技术/政策变化的经营影响 | **跨质量服务不能强排成本曲线**；成本位次不单独确定价格；经验曲线不把相关的成本下降当自动学习效应；情景写"变化→暴露业务→影响机制→指标→行动"，不罗列新闻 |

### 数据分析

| 方法 | 什么时候用 | 最容易犯的错 / 必须成立的前提 |
|---|---|---|
| 数据质量与探索性分析 | 分析初始阶段与开放研究；识别范围、分布、异常与口径问题 | 探索发现不能冒充预先设定并通过的因果检验；**只有聚合值就不能恢复原始分布**；缺失≠0、异常≠错误，不为改善故事删除有效极端值 |
| 量价组合分解 | 量化净收入变化的会计贡献；同一粒度且数量可加总 | 不能推断提价引起销量变化；**零或负基数不能硬算常规增长率**；分解顺序影响各项分配，须跨页一致；新品无历史价不填 0 冒充价格下降 |
| 漏斗、cohort 与留存 | 区分获客、转化、留存与客群组合，判断增长质量 | 累计总客户或总收入不足以估算留存；**右删失窗口不能填 0**；收入留存可超过 100%，客户数留存定义另验；总体增长可能来自群体结构变化 |
| 预测、回归与模型评估 | 预测未来量值或识别条件相关；需足够历史与合理泛化对象 | 少数年度点不支持复杂预测或"精确拐点"；**禁止把未来特征或全样本预处理泄漏进训练**；无稳定外推条件时做条件情景，不把管理目标接在历史折线上称预测；**回归系数本身不证明因果** |
| 因果问题与竞争解释 | 判断某行动是否改变结果，而不只是二者同时变化 | 没有识别设计就只报相关或机制假设；观察性方法须逐项写识别假设与可检查证据；**统计显著不等于经营重要**；无法支持识别时停止因果措辞 |
| 文本编码与案例综合 | 从访谈、报告和案例发现共同维度、机制、分歧与边界 | **少量成功案例不能证明某做法是必要或充分条件**；频次注明分母是文档、片段还是受访者，多标签可超过 100%；同一报告被转述不计独立案例 |

### 战略与经营

| 方法 | 什么时候用 | 最容易犯的错 / 必须成立的前提 |
|---|---|---|
| 增长方向与三层面组合 | 比较现有/新客户市场与现有/新产品的增长路径 | 分类不是风险评分或预测模型；检查交叉销售、渠道迁移与并购收益的重复计算；三个层面须同时管理，不是第一年只做核心 |
| 业务组合与资源需要 | 多业务且市场边界可定义；比较吸引力、竞争地位与资源需要 | **不能把象限当自动投资/退出命令**；阈值须说明，不一律用随意 10%；市场边界或权重改变若使象限翻转要交代；没有可靠份额时保留证据矩阵，不猜象限 |
| 市场进入与方案取舍 | 进入/不进入、合作/自建/收购；有明确决策与候选方案 | **不得把市场增长直接变成进入建议**；先列不可违反的准入/资源条件；不把综合评分高等于财务价值高；不满足硬约束的方案不能靠别项高分补偿 |
| 流程瓶颈、产能与实施责任 | 找出交付时长、成本与服务质量的限制，设计执行路径 | 局部效率提升不自动提高系统吞吐；平均时长不能掩盖长尾；**顺序不是因果，等宽阶段不是等时长**——箭头须注明先后/依赖/条件；无时间数据先作假设与采样计划，不承诺节省比例 |
| 组织一致性与能力差距（7S） | 判断组织是否支持既定战略，定位协同与能力缺口 | 组织图变化不代表组织问题已解决；相互关联不能自动证明因果；不用一句"文化差"解释所有结果；缺实施资源时输出待验证差距 |

### 财务

| 方法 | 什么时候用 | 最容易犯的错 / 必须成立的前提 |
|---|---|---|
| 盈利驱动树与贡献分解 | 解释收入/利润变化由哪些会计分项贡献；同口径经营数据 | 恒等式分解不证明经营原因；分项合计须等于总计、变化和须等于起止差；分项降幅可大于净降幅，分母需显式；粒度不足时只报贡献，不填量价假数 |
| 单位经济性与盈亏平衡 | 比较每客户/订单/门店的增量贡献与回本条件 | 单位数量、GMV 或收入增长不证明单店模型成立；**LTV 不是终身收入**；无稳定留存依据不套无限期 ARPU×毛利率/流失率；单位贡献≤0 时不报正盈亏平衡量 |
| 经营预测与三表联动 | 判断经营计划对利润、现金与融资的影响；资本或现金约束会改变决策 | 历史增长率外推不替代经营计划；**缺期初表则不能称三表预测完成**；不作无解释配平项；未获授权或承诺的融资不能写成已落实 |
| ROIC 与经济利润 | 分析利润与资本占用是否匹配，比较资本效率 | 负或近零投入资本、金融机构不宜机械套一般工商企业口径；**资本成本缺失时可报 ROIC，但不能断言超过资本成本**；账面回报不是项目增量 NPV |
| 投资评估：增量现金流、NPV、IRR 与回收 | 比较投资与不投资、不同规模或时点的方案；项目现金流可界定 | **利润或收入不能直接当投资回收现金**；排除沉没成本、纳入蚕食与可避免成本；多次变号可能无唯一 IRR，未回本就写未回本；折现率缺失时先做未折现现金与敏感性 |
| 情景、敏感性与改变决策的条件 | 识别不确定变量与决策翻转点；预测与资源配置 | **情景不是概率分布，不能无依据给概率或置信区间**；不是先随意设 ±10%；价格、销量、成本不能忽略相关性随意同时取最优 |
| 估值：DCF 与可比法 | 用户确需估值且输入可支持时，估计价值区间 | **并非每份行业报告都需要 DCF**；**禁止用目标价格倒填模型**；查终值占比与 r/g、再投资敏感性；EV/EBITDA 不等于 P/E；负分母、特殊金融企业另选方法 |

## 财务的共同底稿与缺字段边界

分开输入、假设、计算与输出，记录币种、含税/不含税、期间、合并范围、名义/实际值与来源；一个派生值只从一份输入计算。保存可复算的工作表或脚本并给出公式与输入证据，未知保留 null。金额与率、利润与现金、GMV 与收入分别定义。

**目标单列 target，预测单列 forecast，已发生单列 actual；不得倒推假设使二者相等。**

**缺财务字段时不要编预算、DCF、回本期或财务三表。** 不是每个项目都要三表或 DCF——按决策选择最小模型；缺少必要输入时输出变量化结构、已知部分与取证优先级，不编造"基准情景"，也不用默认利润率、WACC 或增长率填补缺口。

## 从业务问题发现更多方法

基础方法不足以回答、或材料显示还有分析空间时，从下表检索可组合的经典方法。这是入口不是作业清单；可用目录之外的方法，无须先扩充本文件。

| 问题或材料信号 | 方法 → 要形成的分析，而非填表 |
|---|---|
| 宏观环境改变进入条件 | PESTEL、情景规划、CAGE → 外部变化→传导机制→暴露程度→选项/监测信号；国家差异要有具体证据 |
| 利润被谁获得、竞争怎样变化 | 五力、价值链、利润池、战略群组、成本曲线 → 交易/议价/替代机制与利润资本分布，不用"竞争激烈"代替分析 |
| 哪些优势真能维持 | VRIO／资源基础观、核心能力、活动系统、7S → 稀缺性、可模仿性与组织接连接到实际证据；缺锚点不编成熟度分 |
| 从环境诊断形成可行行动 | SWOT→TOWS、3C、增长选择 → 内外部证据配对成行动假设并比较可行性；四格本身不是结论 |
| 商业模式或价值主张重构 | 商业模式画布、价值主张画布、JTBD、商业生态 → 客户任务、价值交换、成本收入与伙伴依赖闭合；区分已知与待试验 |
| 差异化与增长路径 | Ansoff、三层面增长、战略画布、四步行动 ERRC → 哪些因素应减少/增加/去除/创造，客户与成本证据如何支持；不虚构价值曲线分值 |
| 客户分层与增长质量 | STP、客户旅程、漏斗、cohort、RFM、留存与 LTV/CAC → 分群差异、转化/留存与贡献连起来；样本和窗口一致，不把终身收入当净价值 |
| 多业务或项目选择 | BCG、GE 九宫格、实物期权思路、决策树 → 同口径位置、经济性、资本与不可逆性共同影响选择；没有概率就保留条件分支 |
| 盈利与资本回报 | 利润驱动树、量价组合、单位经济性、盈亏平衡、DuPont、ROIC → 可复算恒等式与经营机制分开；资本/现金口径写明，避免平均数掩盖结构 |
| 运营等待、返工和约束 | SIPOC、价值流图、服务蓝图、约束理论、Little 定律、鱼骨、5 Whys → 沿实际案例查等待/处理/瓶颈与替代解释；稳定流量前提不成立时不用 Little 定律推断 |
| 组织执行与决策权 | 7S、RACI、RAPID、利益相关者地图 → 责任、决定权、依赖与组织激励对应；RACI 与 RAPID 的角色定义不能混用 |
| 战略到实施与学习 | 战略地图、平衡计分卡、KPI 树、OKR、阶段门禁 → 指标与战略机制、基线、责任及反馈对应；目标不是已验证预测，相关指标避免重复计收益 |
| 不确定性与反证 | 假设树、预演失败、反事实、竞争假设、实验/准实验 → 找到最可能改变选择的证据，决定补什么；并非所有观察都能推断因果 |

经典术语不能替代业务机制，适用前提在具体任务中核验。

## 把丰富材料接成分析链

按问题选用，不要求逐项开展。

| 场景 | 执行路径与主展品（一句话） |
|---|---|
| 增长快但价值下降 | 明细连到收入/成本/留存，同口径贡献桥分离数量、价格、结构与成本，再看分群；单位经济性桥＋分群差异图。声明交互归属，保留固定费用边界 |
| 行业有规模但企业未获利 | 价值链环节连接销售额、利润、投入资本与交易依赖，统一口径后看利润池与回报并用议价/替代机制检验；利润池或成本曲线＋价值链机制。缺资本时不把利润率当资本回报 |
| 客户抱怨很多但动作不清 | 交易/服务节点连接时间、触点、等待与流失，访谈解释机制并保留反例；服务蓝图＋等待分布或旅程流失。**没有代表抽样或因果设计，不把投诉频次当总体影响** |
| 新业务需要验证 | 客户任务、价值主张、交付活动与收入成本逐项连接，找出最敏感且最不确定的假设并定最小验证条件；价值交换图＋假设敏感性＋验证路线图 |
| 多项目争夺资源 | 统一基线算增量价值与现金需求，枚举预算/人力/依赖可行组合；可行组合比较＋情景区间＋条件决策树。无概率不算伪期望值 |
| 战略已定但执行反复卡住 | 从受阻决定追溯输入、决定权、责任、依赖与激励，比较正式职责与实流程，设少量触发信号；决策权矩阵＋泳道/依赖图＋反馈回路 |

业务框架提出问题、数据方法执行检验、视觉结构让读者看出答案；三者不要求一一对应，也不必每个框架各占一页。

## 使用与表达

选定方法时简记：它回答什么、前提是否足够、做了什么、得出什么及边界；多个方法服务同一问题可合并底稿。**没有重要新发现时，不为展示知识广度加入额外框架。**

方法输出可转成数据图、比较表、机制图、价值链、旅程或关系网络；先做分析，再决定是否保留原框架外形——用五力不强制画五边形。

**没有命名框架适用时，用透明的自定义分析，记录输入、步骤和边界；也不得为了匹配已有方法改变问题。** 不从主题品牌推断方法，不把方法数量或"经典"身份当作质量指标。

## 几条不能越过的线

贡献不等于因果、样本不等于市场、口径不同不能强比、目标不是预测——这四条硬线见[分析与叙事](analysis.md)「结论综合与主线」。本文件的方法行各自标注自己的前提与误用，两者须一起遵守。
