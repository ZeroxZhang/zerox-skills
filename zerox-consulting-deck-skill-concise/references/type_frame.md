# 母版、排印与语义色

> **什么时候读**：S4 实现阶段，页面片段与样式写定之前。
> **读完要能做什么**：知道每个文字角色用哪个字体、多大字号；知道每个颜色角色承载什么语义、从哪里取值；知道本页该声明哪种页面边界，并写出一段不会返工的最小页面结构。

## 一、字体与角色

### 唯一配置源

`assets/deck-typography.js` 是字体的唯一配置源。固定一套中西文标题搭配与一套中西文正文搭配，默认最多四个实际家族；备注与数字复用正文家族。页面和组件里不要另外写死字体名。

**选择优先级**：用户明确选择 > 项目已有记录 > 新报告媒介默认。配色变化不触发字体变化。非法 ID 报错，不静默退回。

### 角色基线（1280×720 reading）

| 角色 | 中文 | 西文 | 基线 |
|---|---|---|---|
| 封面主标题 | Noto Serif SC700 | Playfair Display700 | 46px / 1.28 |
| 章节标题 | 同上 | 同上 | 38px / 1.25 |
| 页主判断 | 同上 | 同上 | 32px / 1.28，通常两行 |
| 模块、展品标题 | Noto Sans SC600 | Inter600 | 18–20px / 1.3 |
| 正文、解释 | Noto Sans SC400 | Inter400 | 16–17px / 约 1.5 |
| 常规表格数据 | Noto Sans SC400 | Inter400，选择性 600 | 15–16px；表头 15px／600 |
| 图表标签、数据 | Noto Sans SC400 | Inter400，选择性 600 | 通常 14–16px，按图与媒介预算 |
| 副题 | 同正文 | 同正文 | 15px / 约 1.45 |
| 解释备注、口径 | 同正文 | 同正文 | 14–15px / 1.5 |
| Source、页码 | 同正文 | 同正文 | 12px；深灰且反差达标 |

### 使用规则

- **只有封面、章节和页主判断用衬线**，不能把所有 h2 改成衬线。
- **正文强调用真实 600，主标题默认真实 700**；不能为了强调把全页改成粗体。不要默认细字重、中文斜体或拉大字距。
- **重要限制按解释性正文呈现，不压进 12px Source。**
- 常规查数表不要默认放大成 KPI。
- 数据表与图表文字启用 `lining-nums`/`tabular-nums`，数字右对齐；HTML、浏览器测量探针与 SSR 测宽使用同一数字特性。
- 字号是逻辑像素，不冒称 PowerPoint 点数。
- 标题通常两行，按实际测量换行；不强行用 20 个中文字截断一个完整判断。

角色变量 `--fs-data` / `--fs-table-head` / `--fs-subtitle` / `--fs-exhibit-title` / `--fs-annotation` 是制作入口。

**继承**：已有认可成稿时继承其角色层级；必要变化要明确说明并与原成稿同内容对照，不能因为换图而重设字号密度。

### 预设

- **serif-report-bold**——新 reading 默认。标题 Noto Serif SC700 ＋ Playfair Display700，均为真实静态实例；正文资源与其他预设相同。
- **serif-report**——旧报告选择。标题 Noto Serif SC600 ＋ DM Serif Text400。**保留原含义，不偷偷改变**（DM Serif Text 没有粗体）。
- **serif-playfair**——显式选择时以 Playfair Display500 替换英文标题；整份统一，不逐页混用。
- **sans-presentation**——新现场演示默认，标题改用 Noto Sans SC / Inter600；预设本身不保证投影可读，字号仍需按场地和内容预算扩大。
- **legacy-system**——系统字体方案，不声称跨设备字形锁定，也不声称复刻任意旧稿。

用户点名自定义品牌字体时，必须补全资源与字重，不可只局部写死字体名。

引擎按所选配置给 `.type-latin` 字重，`font-synthesis:none` 防伪粗。标题中的日期和百分比保留标题字体。混排西文优先回退中文家族，中文标点保留；页面语言要正确标记。

### 字体资源与打包

`assets/fonts/manifest.json` 固定上游提交、URL、SHA256、字重、体积和许可。资源是真实字重的 WOFF2 静态实例，随 skill 提供，不需要下载；CSS 以 Deck 前缀别名引用，不通过 `local()` 调用本机可能不同的版本。已交付的 HTML 打开时不需要 Node 或 Python。

**改字必须重新打包字体。** 缺字、缺资源、哈希不符均拒绝。**标题和正文分别核对实际字体链覆盖，不能用正文支持的字形掩盖标题缺字**；未覆盖的特殊符号要调整表达或完整扩展字体方案，不能静默回退。

### 测量边界

- 容量预检含保守估算，**不能替代最终浏览器字形边界验收**。
- 浏览器加载全部所需字重和字符后才初始化图表；`window.deckReady` 是截图、打印和后续测量的入口。动态改文本要重新打包并重建图表，不能只触发 CSS 重绘。
- SVG 统一使用 `text-rendering:geometricPrecision`。SVG 里的 text 仍然是文字，必须内联到同字体配置且已打包的 HTML；**不能把一个独立 SVG 冒称字体自包含**。
- 字体变化要重算标题和证据区，不缩数据字、不省略证据。

## 二、语义色

### 先选语义，再选颜色

| 角色 | token | 用法 | 不应混用 |
|---|---|---|---|
| 品牌/结构 | brand | 标题、表头、边界 | 不自动给所有系列 |
| 关键强调 | accent | 关键论据、注释 | 不改变实体登记 |
| 分类实体 | cat-1..6 | 无序实体，跨页一致 | 不表示排名或状态 |
| 顺序量值 | seq-1..5 | 同量尺低→高 | 缺失不等于零 |
| 数学偏差 | delta-negative/neutral/positive | 围绕 0 或目标，附 +/- | 正数不自动好 |
| 经营评价 | good/risk/caution | 已定义指标的评价，附文字 | 不与分类混成同一图例 |

- 不设颜色硬配额，但**禁止颜色没有图例或语义**。
- 灰色可以表示背景、基准或未选择，不笼统等于"不重要"。
- 实体图的重点用描边、编号箭头、局部底纹或直接文字表达，不必给被关注的实体临时换色。
- 一个图可用 4 种以上类别色，但先测试能否用分面或直接标签降低识别负担。

### 唯一色值源

色值统一从 `assets/deck-themes.js` 读取（`get(id)`、`palette(id)`、`css(id)`；缺省 `mckinsey`，非法 ID 抛错），**不手工复制到页面或组件**。CSS、ECharts series/visualMap、SVG、表格和状态列必须来自同一预设。

页面用角色引用而不是 HEX：ECharts 的 `color`／`itemStyle` 与 visualMap 使用 `@cat-1`、`@accent`、`@seq-1..5`（visualMap 须给出量尺上下限），引擎递归解析为当前 CSS 值，未知角色报错；SVG 组件传入 `themes.palette(theme_id)`，任意自画 SVG 也从 palette 或 CSS 变量取色。

**静态 SVG 的 fill 已经固化：换主题必须重新生成相关图，只替换 CSS 不算完成切换。**

`pos`/`neg`/`warn` 是经营状态的兼容别名；**瀑布的正负必须用 delta 角色**，不能借用经营状态色。

### 三套主题

`theme_id` 固定为 `mckinsey`（默认）、`bcg`、`accenture`。缺省或空值用 mckinsey；**非法非空值必须报错**，不能静默退回让用户以为已经选中。

三套共享同一套语义接口，各自拥有完整色值；切换主题不改变结论和实体身份，只改变色值映射。已经完成的项目继承原主题，除非用户要求切换。

McKinsey 的当前取值：主标题与主强调 `#000080`，辅助底纹与选中 `#D9D9EC`，次级灰 `#50606E`（对辅助底色约 4.66:1）。正文 ink 与说明灰按角色读取。连续量色阶从 `#D9D9EC` 逐级加深到 `#000080`，服务数量编码，不直接当作五档文字颜色。辅助色只用于底纹和辅助色块，搭配 ink 或 brand 深色文字；**不用于白底小字或必要细线**。

三套的差异与易错点：

- **McKinsey**：深蓝负责标题、关键总计和结构边界，电蓝负责本页关键论据。分类图不要用六级蓝表示六家企业，否则容易被读成有顺序。青色只用于大图形或非文字辅助强调。
- **BCG**：绿色首先代表主题结构，所以经营利好特意用深蓝，并加"达标/改善/✓"文字或符号。**品牌绿不代表盈利，增长不代表好**，成本增长尤其不能自动标绿。**禁止白色小字叠放和白底正文**；亮绿只能作有深色标签的大形状填充或边缘点缀，重点数据优先用深绿 accent。
- **Accenture**：深紫结构、白底、局部紫色强调。**紫色不等于"未来/AI/高优先级"**，除非显式登记。连续量必须单调明度递增，分类图用离散色板，不用彩虹或按类别逐项渐变。

### 共同原则

- **先语义后装饰**：品牌/结构、实体类别、连续量、数学方向和经营评价是五种不同问题；同一填充在同一个图里只承载一种语义。
- **实体登记跨页稳定**：主题切换按类别索引重映射同一实体。登记存索引或 token，不只存 HEX。
- **默认不使用暗底或渐变**：分析页白底；深色限封面与分节页；渐变不进入绘图区、数值编码区或文字底。
- **表格底色可解释**：结构表头 brand ＋白字；交替行 surface ＋ ink；强调列用 selected ＋ ink；只有热力表使用数值色阶。**缺失数据用"—/未披露"和专用空值纹理，不伪装成最低值。**
- **色阶图例完整**：顺序量说明上下限与单位；偏差说明中心、正负方向和区间；统计意义上的"正"不自动映射经营利好。
- **颜色不能是唯一编码**：类别提供直接标签或线型，偏差提供 +/-，状态给文字与符号。六类别仍分不清时先分面、排序或合并尾项，不无限扩展颜色。
- **打印适配**：灰度相似的类别不要靠颜色硬分，转为线型、标记、直接标签或分面。**截图通过不等于灰度通过**；浅色连续量边缘可加 border，防止最低档和白底丢失。
- **反白文字显式计算**：类别和色阶按真实填充计算，亮底深字、暗底白字，不假设"图形有颜色就能放白字"；透明叠加后的实际背景也要计算。

### 可读性与验收

- 普通文字对背景至少 4.5:1；浅灰只用于辅助线和底纹。**正文和来源不使用 `#8A9199` 对白底。**
- 颜色、大小、字重、位置一起建立层级；不要用所有内容加粗来消除层次。
- 原尺寸、缩略图和灰度都要看，比较时对焦关键点、实体识别、状态解释和来源可读性。
- **单独保留不依赖颜色的标签、+/-、线型或状态文字**；完整信息必须在静态打印中保留。

## 三、母版：页面边界

母版让整套页面有一致的完成度，同时让结论、关键数字和证据保持视觉优先。默认 quiet 母版使用浅中性细线、左缘短标与右下小折角；色彩来自 gray-2 与页面底色，**独立于数据的 accent、类别色和风险色**。

### 三种边界与 off

| 页面情况 | 属性 | 处理 |
|---|---|---|
| 标题之后需要清楚的分区 | `data-frame-boundary="line"` | 在标题组与正文留白中放 1px 淡线 |
| 正文首排模块已有承担分区的顶线 | `data-frame-boundary="integrated"` | 省去额外标题线，保留正文顶线 |
| 全幅图、密集页或留白已足够 | `data-frame-boundary="space"` | 仅保留页边识别 |
| 封面有独立视觉、全出血或其他不适合母版的页面 | `data-frame="off"` | 关闭本页母版装饰 |

`integrated` 是作者对正文结构的判断，**不由程序扫描任意横线推断**。图表坐标轴、网格线和数据连线服务数据，不能拿来充当页面边界。封面和章节页沿用同一轻重关系；已有品牌母题时可以关闭页边标记，不额外叠加装饰。

### 每页必须显式声明

`data-frame-boundary` 是页面契约的一部分，**不留静默默认值**。制作时逐页写入 line / integrated / space；封面与全出血页用 `data-frame="off"` 关闭装饰，同时仍要声明 `data-frame-boundary="space"`——**off 不是 boundary 的替代字段**。不写的静默行为按 line 渲染，会造成"标题线 ＋ 正文首排顶线"的双层边界，或者线贴内容；这属于视觉缺陷，不是母版选项。这些是选择工具，不要求每页同样的线条数量。

### 最小页面结构

```html
<section class="slide reading" data-frame-boundary="line">
  <div class="slide__frame" aria-hidden="true"></div>
  <div class="slide__tracker">章节名称</div>
  <header class="slide__header">
    <h1 class="slide__title">本页主判断</h1>
    <p class="slide__lead">必要范围或解释</p>
  </header>
  <div class="slide__body">正文与展品</div>
  <div class="source">来源与边界</div>
  <div class="slide__page">01</div>
</section>
```

标题容器不增加固定高度，细线放在已有间距中；页边元素绝对定位、隐藏于辅助技术且不接收点击。使用独立节点，不占用作者自己的 `slide` 伪元素。自由版式可以自行实现等效结构。

### 线的配对公式

唯一 CSS 源是 `assets/deck-frame.css`；调整后运行 `node scripts/sync_frame.cjs` 更新源引擎。构建器会再次内联最新 CSS，交付不需要额外文件或运行时脚本。

- `--frame-rule` / `--frame-mark`：中性灰分别以 24% / 42% 与页面底色混合；可按品牌和实看结果调整，但避免与内容重点形成同等信号。
- `--frame-rule-offset`：线相对标题容器底部的位置，默认 −7px，reading 为 −8px；对应正文 margin-top 为 14/16px。
- **配对公式：线下方到正文首排的留白 ＝ 正文 margin-top − |offset|**（16−8＝8px）。压小正文 margin-top 必须同步减小 offset，否则标题线会贴到正文首排顶线；只调 offset 不动 margin 则会把线挤进正文。自定义页若副题自身已有下边距，可改为正值把线放回这段留白。
- `--frame-mark-top` / `--frame-mark-width/height`：默认顶边 28px、3×40px，reading 顶边 32px。
- `--frame-corner-right/bottom/size`：默认 10px / 18px / 12px；角标留在页码、来源和展品之外，窄边距或全出血可直接关闭。

全局 `<html data-frame="off">` 关闭母版，单页 `data-frame="quiet"` 可重新启用；integrated/space 在该页继续生效。页码保留普通辅助文字样式，母版不提升其颜色或字重。

**改过母版的 HTML 必须重建同版 PDF。** 旧稿先显式加入相应容器，再用 `node scripts/apply_frame.cjs draft.html framed.html` 注入样式；这一步要在 QA 和正式打包之前。

### 禁用装饰色条

**报告禁止装饰性色条模块**：注释和判断块的侧边色条、数字卡片的顶部色条，以及换类名、用伪元素、阴影、渐变或用 SVG 绘制的同类外观，全部禁用。去掉边条后要按内容重排，**不能留下同样大的空框**。

不在禁令内的是：图表的数据条、坐标轴、关系线、必要的结构分隔线，以及 quiet 母版本身。

### 检查与交付

在正常阅读尺寸和分页 PDF 中看标题、副题、首排展品和页角。三项目视检查，自动工具只能提示、不能替代：

1. **每页边界显式声明**：内容页没有 `data-frame-boundary` 视为未完成母版选择。
2. **无装饰边条**：按上文「禁用装饰色条」核对，自定义类、伪元素、阴影、渐变和 SVG 同样适用。
3. **首排顶线合并**：出现"灰线紧贴正文顶线"的双线，就是边界选择或 margin/offset 配对错误。不得为了用 integrated 而新增禁用的装饰色条。

判断标准：线不穿内容、双层边界不重复、装饰不抢眼。浅装饰在灰度或低质量打印中变淡可以接受——信息层级仍应由标题、留白和正文自身成立。标题行数、图型或页边距改变时重新看受影响页面。

日常制稿复用成稿 QA；改动母版实现才跑 `test_frame.cjs`，改源引擎或示例同时跑 `test_engine.cjs`。
