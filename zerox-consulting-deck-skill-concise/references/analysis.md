# 从材料到主线：分析与叙事

**什么时候读。** S1 读懂目标与材料、S2 实际执行分析并形成主线时。分析类任务从这里开始；`editorial` 只需读「先按任务选深度」一节，其余按需。
**读完要能做什么。** 定准这次任务的深度；关键数字与计算可复查；重要未知写明它改变什么判断；标题骨架连读能形成推进；知道何时必须独立复核、什么状态才能进入制作。

## 先按任务选深度

深度由用户的任务范围决定，不因为手上有多少材料就自动加码。开工时把模式写进 `task.json` 的 `workMode`，并记一句理由。

| 模式 | 适用 | 必须做 | 可以不做 |
|---|---|---|---|
| analytical | 原始数据、访谈或多份资料，需要诊断或建议 | 议题与竞争假设、分析计划、实际分析、结论综合、内容去向、分析复核 | 与决定无关的模型、无影响的补研究 |
| exploratory | 问题尚不清楚的行业研究或材料探索 | 界定对象与范围、建立研究地图、探索性分析或文本编码、形成问题与发现、记录未知 | 预设推荐、为每段资料编造假设 |
| editorial | 用户已确认内容，要求改写、排版或转成报告 | 必要的算术/时点/状态核对、修正与未知、原文段落到页面的去向 | 新研究、财务建模、议题树、全量发现台账、逐值证据 JSON、逐项复核表 |

### editorial 的轻量路径

editorial 是最容易被做重的一类任务，单独说明。

- **不把用户文字自动标为已验证。** 发现错误时定位原文，提出收窄措辞或指出证据缺口；必要的局部核对继续做，只有涉及改变任务目标才回头问。
- **不得为了填表重新发明用户已确认的方向。**
- **最小交付**：在标题骨架前附一段范围/主题说明，加上简短核对记录——实际用到的公式、状态修正、未决项。重要调整保留原文定位和理由。不建全量台账，不为每个数字编号，只为重要数字或有争议的判断保留详细依据。
- 只有出现具体论证冲突时，才对受影响的部分补做分析；不因一处笔误把全篇升级成分析项目。

### 工作笔记

**上述结果可以全部放在一个工作笔记里，字段自定。** 复杂任务才展开明细（议题、任务、发现、证据、去向各自成段或成表）；editorial 和小任务用连贯文字写清实质依据即可，不要求为简单页建立坐标台账。

## 从资料到问题

1. 从任务中提炼：谁在什么时点需要理解或选择什么；候选行动、现状基准、资源与期限约束、成功标准分别是什么。没有决策请求的研究报告以"理解目标"替代"行动选项"。
2. S1 先做足以理解材料的清单与口径检查——不先穷尽抽取，也不等到标题定了才找证据。围绕问题和竞争假设定向补证据，新发现回写清单。
3. 问题不清楚时先探索材料再收敛议题；**不要用一个熟悉框架重新定义用户的问题**。
4. 每个重要诊断议题列出竞争解释、支持信号和可能推翻它的证据；初步答案标为"工作假设"，探索研究允许从异常和开放问题开始。
5. 按对结论的影响、可改变程度、未知程度和取证成本排序；先做可能改变建议的分析，不强制 80/20。

问题结构决定分析任务。常见四种：

- **议题树**：分解"必须回答什么"，叶节点能转成可执行任务；同层用相同拆分依据，重要交叉依赖单列。
- **驱动树**：用恒等式描述数量关系，例如 `利润 = Σ销量×单位贡献 − 固定成本`；节点说明口径与运算符，**恒等式不能证明影响路径的因果**。
- **假设树**：同一现象的竞争解释、支持/推翻信号与证据缺口；结果可以是支持、反驳、混合或未决。
- **决策树**：可选行动、条件与不确定事件及其结果；决策节点与机会节点分开，概率缺依据就保留条件分支。

MECE 用于检查重叠与遗漏；复杂系统允许显式交叉依赖，**不能为了画整齐的树而假装独立**。

## 实际执行分析

**分析不能以一份计划代替。** 执行筛选、聚合、公式计算、案例对照或文本编码，保存可复算的工作表/脚本/公式、输入定位与结果。没有运算的定性分析，保存比较维度、引文和推理过程。

**不要把输入先压成几条摘要。** 围绕问题读原材料：数值保留明细、分布和比较口径；文本保留主体、动作、条件、层级、反证和依赖。

方法按这条顺序选：

`问题类型 → 业务机制 → 数据可用性与口径 → 方法假设 → 最简单够用的方法 → 核验与回退`

一个问题可以组合多种方法，一种方法也可以服务多个议题。没有现成框架适用时，用透明的自定义分析并记录输入、步骤与边界；**不得为了套上某个框架而改变问题**。方法入口见[方法路由](methods.md)。

计算与记录的基本要求：

- 表格和脚本中的假设、输入与输出分开；未知保留 `null`，**不能把 0 当缺失**。
- 派生值保留输入定位与公式。
- 关键来源与计算要能复查；**普通文字无需逐句台账**。
- 综合时检查各任务之间的依赖、矛盾和重复计算。

### 推理链的最小检查

`事实 → 分析结果 → 解释及替代解释 → 对问题的含义 → 条件性建议/下一步`

逐步自问：1. 事实口径一致吗？计算能复算吗？2. 分析证明了什么，尚未证明什么？3. 相反材料会怎样改变解释？4. 建议需要的成本、现金、能力、时限依据在哪？5. 若未知暂时无法解决，最有价值的下一步验证是什么？

### 研究顺序与表达顺序

研究可以从工作假设或探索性问题开始；提出初步答案的同时，写出替代解释和改变答案的条件——研究任务是检验，不是保护假设。

表达时将有依据的答案前置。计划中的模型、支持性资料的数量、顺畅的标题，都不能证明结论已经成立。相关性、分组差异和会计贡献必须分别标明。

**方法服务问题的检验，标题服从分析结果。** 重要反证不能因为不支持标题而被删除，也不能只藏进附录。

## 证据契约

高密度输入先建清单再写页面。数据文件记录表名/工作表、行列数、主键、字段类型、单位、时间粒度、缺失与异常；文本文件记录文档/章节或页码、对象、时间、可抽取主张与引文、可否系统编码。

**不要把整份表或整段文本当成一个证据项。** 关键证据定位到原文或行。无法判断口径时先标 `comparability: unknown`，**禁止进入排名、差异和同色阶图**。

需要详细证据库时，重要量化证据记录下列字段（普通句子不必）：

```json
{"id","claim","value","unit","period","scope","denominator",
 "source":{"title","url","locator"},"status","retrieved","formula","limitations"}
```

`status` 区分六种来源性质：`verified` 必须打开原始来源并找到对应数字，**摘要或转述命中只能是 `unverified`**；`user-provided` 不自动升级为 `verified`；`derived` 保留输入定位和公式，由合成输入派生的结果继续注明合成来源；`estimate` 说明假设与不确定性，有根据时给区间；`synthetic` 明确标为虚构；无可靠来源时保留 `null` 与缺口，**禁止填"合理数值"**。

**来源状态与推断可信度是两件事**：`verified` 的事实仍可能支撑不了因果或预测。不能从证据条数直接跳到建议——证据要经过问题和实际分析才能连到结论。

## 数据几何契约

- 百分比同比与百分点差分别计算，**不同分母不能相减**。
- 半年与全年不连成连续趋势；保留分区或做同期比较。
- 气泡面积编码用 `r = k√value`，必须有单位、尺度图例和来源；跨单位规模不能共用面积编码。
- 定性轴使用低/中/高或有定义的等级；**没有量化数据就不画百分比刻度**。
- 线性轴坐标必须由同一公式计算；**不得手动挪动数据点"改善布局"**——能移动的是标签和引导线。
- 桑基图需流量守恒或显式流失节点；Mekko 列宽按总量、段高按列内份额；网络图箭头注明关系。

表格补充列单位与数据条 domain；流程补充顺序、依赖和条件含义，等宽阶段不编码时长。选型与实现见[证据与表达](exhibits.md)。

## 分析复核：触发与放行

### 什么时候必须复核

**复杂分析、重大结论或建议时，在 S2 形成核心结论之前就安排复核**——不是等页面做完。

**关键推理存在争议时同样要安排复核，哪怕 `complexity=simple`。** 这是判断要求，不是合同字段：下面写的派生规则只看 `complexity`/`majorConclusion`，识别不出"替代解释没被排除""证据强度与结论不匹配""口径还可能有别的读法"这类情形。合同只要求 author 不等于争议不存在——作者要自己识别，安排复核，并在 review 里如实记录实际独立性。

- 复核要求由 `task.json` 的 `complexity`/`majorConclusion` 派生（字段语义见[交付契约](delivery.md)）：**未判断时按 complex**，`simple` 必须是真实判断，不能为了绕过复核而填；**不能用 fragment 降低复核要求**。
- editorial 新增重大推断仍需复核；已确认内容不重做无关研究。
- 无代理工具或无法看图时，如实标"作者自检，独立分析审查未执行"，需要独立复核的任务保持相应的未完成状态，**不用自检冒充独立**。

复核输入包含原始材料、所采用的方法、实际计算、发现与计划；**不提供作者自评分，也不给希望得到的结论**。

### 放行状态

复核结论只有三种：

- **ready**——适用项已核查通过，可以进入 S3 综合与制作。
- **ready_with_limits**——未知已转化为有限判断或验证计划，不存在仍会误导的断言；**限制必须进入相关正文**。
- **rework**——仍有错误口径、无推导的数字目标、因果越界、隐去反证、关键结果不可复算等实质问题；先修正或收窄断言，再复核。

问题按影响定级：**Blocking** 是错误可能改变核心结论或资源决策；**Major** 是关键解释、方法前提或追溯缺失；**Minor** 是不影响判断的表达问题。Blocking 与 Major 未解决不能放行。

缺少资料不自动禁止交付——关键是**停止依赖该缺口作确定判断**。分析未复核不能写 ready；作者自检也必须有证据。允许合并小任务的产物，但不省略实质检查。

进入制作后如果发现来源或推理问题，退回受影响的议题与发现，更新结论、标题、内容去向和相关数值，再复核受影响的部分；不必重跑无关模型，也不必让用户重复确认。

## 结论综合与主线

综合不是把发现排成顺序，而是让每一页带来新的理解。检查各判断之间的依赖、矛盾和重复计算。

几条容易越界的推断：

- **贡献不等于因果**：会计分解说明变化来自哪里，不说明为什么。
- **样本不等于市场**：定性访谈能揭示机制、提出假设；**没有抽样依据不能推断全市场比例**。
- **口径不同不能强比**：分母、期间、范围不同就不能相减、排名或共用色阶。
- **目标不是预测**：用户期望的目标单列 `target`，模型产生的预测单列 `forecast`；**不得倒推假设使二者相等**。

建议要对比现状基准与其他可行选项，说明收益、成本、风险、现金和执行条件。缺少这些信息时，可以形成"建议先验证 X"，**不能升格为"已证明应全面投入 X"**。

重要未知要写明它改变什么判断。但**不要把整份报告退化成"尚不能证明"的提示集**——限制应融入论证，与已知结论一起呈现。

### 选叙事结构

叙事帮助读者理解推理，不承担替缺失证据补洞的职责。下面几种可以组合，不强制每份报告都用同一种，也不强制给出投资推荐。

| 结构 | 用在什么场合；不要怎么做 |
|---|---|
| 金字塔（归纳/演绎）／进展与提案 | 已有综合结果或汇报进度，需快速给出总判断及理由；不用三条弱理由制造强结论，无综合答案不硬写确定推荐，无基准不宣布提前/延期，不把方法承诺写成结果 |
| 情境—冲突—问题—答案 | 受众需要背景与变化解释；受众已熟悉时不重复铺垫，不人为制造危机感，不让问题只为引向作者偏好的答案 |
| 诊断／研究 | 读者要理解问题在哪、为何发生、如何检验，或形成可靠理解；不从描述性拆解直接跳到根因和处方，原因未知不宣布根因已确定，样本结论不升格为全行业，未知不伪装成确定趋势 |
| 决策 | 需选择并批准行动的明确决策；不只讲推荐方案的优点，要说明为何其他选项被淘汰、何时应改选 |

### 标题骨架与证明关系

**标题说明主判断**，保留期间、范围与必要限定，通常控制两行。数字有助于判断时入题；**不能为了"有力"删掉未知**。图标题说明对象与维度，正文提供证据与推理。

写骨架时逐页写清：**页码 | 读者问题 | 主判断 | 证据 | 证明责任 | 边界 | 与前后页的承接**。封面与过渡页不强填判断。

**上层判断不能强于下层支持**；相反证据与条件必须影响上层措辞。

三种检查：

- **纵向**——本页证据足以支持本页标题。
- **横向**——标题连读能回答受众问题，且与最终发现不矛盾。
- **覆盖**——正文与附录对应内容去向。

只读标题检查全篇逻辑，再按每页实际内容复核标题。**标题连读流畅不等于推理正确。**

### 页面分工

骨架不是"每条摘要独占一页"的清单。先判断每页分别带来什么新理解，再让系统总览、数值证据、机制解释和条件综合形成节奏。

- 没有足够内容支撑独立页面时**合并**。
- 同一关系被多个页面重复转述时**重新分工**。
- 相邻页重复三栏段落、同样的短条图加长说明，通常说明材料在选型前就被过度摘要了——回原材料找尚未表达的关联，而不是换一层外观。

S3 再把标题中的关系变成可见结构，见[整页创作](page_design.md)。视觉构思也可以反过来改进分组与页序。

### 媒介

reading/pre-read 保留足以独立复核的证据与限定；presentation 保留现场能听懂的核心证据。页数由内容和讲述时间决定，不统一规定每页多少秒。需要双版本时从完整版裁剪，**不得在现场版删掉会改变结论的重要限制**。

## 内容去向

材料登记与问题覆盖是两项检查。**重要材料不能无理由消失。**

每份重要材料记录：它在原文的位置、支撑哪个问题或判断、作用、最终去向，以及采用或不采用的理由。作用是 `support`/`counterevidence`/`context`/`duplicate`/`out_of_scope`/`unresolved`（支持/反证/背景/重复/移出范围/未决）之一；去向是正文、附录、暂不采用或待补。

- **多个来源重复转述同一份报告，不能算多份独立支持。**
- 逐个关键议题检查：有回答、明确未知，或经说明移出范围。
- **重要反证即使原文放进附录，也必须在正文相关结论中体现。**
- 完整报告的单页参考资料按[首尾规则](bookends.md)安排。

S3 定稿后再补章节与页码；不必在分析开始前冻结每页。

### 证据不够时按这个顺序补

1. 增加同口径基准（历史、竞品、目标）；
2. 分解总量驱动；
3. 检查分布与反例；
4. 增加机制、可执行条件与边界；
5. 仍不足则收窄判断或合页。

**不能为凑密度引入无关调查，也不能把单案例结果称为"成功公式被证明"。**

## 一个精简示例：深度应该到什么程度

以下业务与数据均为合成教学材料，来源状态为 `synthetic`，页面须写"示意数据"。

**情境与初检。** 某食品公司 2023–2025 年收入下降，董事会要理解降幅并询问能否把电商占比提到 40%、18 个月完成转型（两者是讨论目标，不是事实或预测）。材料是一张销售表（总收入＝商超＋电商＋经销）、一张指数表和问题原文。初检：销售表分项闭合；指数构造与行业边界未给出，**不能用于渠道量价归因或严格行业比较**；没有门店、客户、份额、分渠道费用、现金与能力数据。

**实际计算。** 保留公式才能进入解释：总收入 2025/2023 − 1 = −13.3%（两年累计，不是年化）；2025 − 2024 净变化 −0.8 亿元（商超 −1.1、电商 +0.4，分项闭合）。电商增量 / |商超降幅| = 36.4%，/ |净降幅| = 50%——分子相同、**分母不同**，是两个不能互换的说法，正是"口径不同不能强比"的具体形态。

**形成的判断——深度就在这里：**
