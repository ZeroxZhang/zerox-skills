# 完整报告的首尾页

> **什么时候读**：完整报告（kind=report）在 S1 确认范围、S3 定结构之前读；S4/S5 制作与复核这三类功能页时回看。
> **读完要能做什么**：知道封面、单页参考资料和封底各放什么、怎么排；知道参考资料收录与节选的判断标准；知道首尾页的验收要点。

这条规则只管封面、参考资料和封底三类功能页，正文继续按问题开放设计。用户只要单页、局部编辑或组件样稿时，不强行补全报告。

## 报告结构

完整报告声明 `<html data-deck-kind="report">`，顺序为：

**封面 → 正文 → 必要附录 → 参考资料一页 → 封底**

无须附录时省略；参考资料紧邻封底。组件集合可以声明 `collection`，局部稿可以声明 `fragment`。**kind 只决定首尾编排，不会代写内容。**

三类功能页分别声明 `data-page-role="cover|references|back-cover"`，内容页可声明 `content|appendix|divider`。封面和封底可以省略印刷页码，但仍计入导航和 PDF 页数。功能页不要求动作标题、判断条或图表，也不因为密度低就补无关内容。

**片段、组件集合，以及不带这些属性的既有稿件，不因为没有首尾页被拒绝**，也不自动补页、改页码或改字体。

## 封面

采用白底、直角、细线与留白：顶栏识别、中下部标题组、钉底元信息构成稳定结构。**主标题是唯一视觉焦点；不引入大面积色块、渐变、阴影、摄影背景或装饰插画。**

标题继承所选字体配置（新 reading 为 Noto Serif SC700 / Playfair Display700，正文仍 Noto Sans SC / Inter）。封面与封底主标题用 `--ink`，正文标题仍按主题 `--brand`。封面标题通常 46px/1.28，16:9 两行、4:3 三行是起点；按词组断行，**长标题先精编再重排，不缩小字号硬塞**。保留 `.cover-title` 角色，确保混排、字重和字体审计正常。

- 顶栏可放真实出品方与已有使用范围。
- 标题组为报告类型、明确客户（如有）、主题，以及按需副题。
- 元信息用低权重中性色。报告日期默认显示，数据期间放在副题等对应位置。
- 版本、项目编号、机构、客户、保密标识、声明和联系方式**只用已知真实内容**。没有客户不强填"致"，没有机构不套用虚构咨询公司，**不自动添加保密或法律声明**。

封面和封底共用一份报告元信息。报告版本与 skill 版本分开。**可选项没有值就收起，不保留空标签或占位符。**

封面和封底使用 `data-frame="off"`，避免与正文母版叠加（同时仍要声明 `data-frame-boundary="space"`，见[母版与排印](type_frame.md)）。左右 40px、顶 32px、底 26px、标题到页脚约 72px 留白是推荐起点；按内容高度保持安全区，不固定标题的绝对 Y 坐标。现有引擎 16:9 为 1280×720、4:3 为 1024×768；4:3 用同一字体与边距体系重新排版，**不能单独改成 960×720 或整体缩字**。

## 参考资料：单页书目与完整追溯

### 收录什么

收录实际支撑事实、数据、方法、判断及重要限制的独立文献、数据集或内部材料。**仅浏览过但未使用的资料不列入。** 去重同一文献的重复引用、镜像或转述；不同年份或实质版本保留各自身份。

优先记录实际读过的原始来源；只使用转述时如实记录。来源状态沿用原有的证据分级，**不因为列入书目就变成已核实**。

### 条目格式

**机构/作者 ·《标题》· 年份或版本 · 必要材料属性或定位**

缺少作者可用真实机构；无日期可省略或标"未注明日期"；内部资料无公开链接时保留准确的材料身份。**派生结果要回到输入及公式，"作者分析"不能代替原始来源。**

有真实公开链接时让资料标题链接原文、PDF 或 DOI；**不用"点击这里"或长裸 URL 替代书目身份**。动态数据保留使用版本或访问日期。链接要在 HTML 与 PDF 中都核对；正文与书目离线可读，外部网站本身不属于离线交付。

### 排版与容量

默认按首次使用顺序排列，复用已有来源标识；分组仅在确实有助查找时使用。参考页标题为"参考资料"，沿用正文标题角色、quiet 母版与显式边界。条目用无衬线、悬挂缩进、深色文字，**14–16px 起步，不把整页设成 12px Source**。少量资料用单栏自然留白；适宜时用双栏，先左后右，单个条目不跨栏拆开。最终以实际字体测量和 PDF 阅读判断容量，**不固定最多几条**。

### 超量处理

按顺序处理：去重 → 精编重复字段 → 调整单栏/双栏及间距 → 仍超量才**节选**。

节选标题必须写作"主要参考资料（节选）"，并有轻量说明。优先保留核心原始数据、关键方法、改变结论的反证与限制，再覆盖其他重要论点；辅助背景和重复转述优先不展示。**不能仅按机构名气、引用次数、年份或编造分数筛选。**

**不靠继续缩字、截断、滚动、hover、折叠或加第二页参考资料来绕开一页限制。** 展示集合由作者判断，构建 helper 不按条数自动截断。presentation 按观看距离减少展示数量。

### 三层出处

正文 Source 保留本页的具体定位；末页集中展示全篇书目；全部实际使用的来源保留在既有清单、原稿或必要底稿中。**节选不允许删掉正文的重要反证或口径。**

说明只指向实际存在且已交付的入口；**未随附完整清单时不能写"见随附清单"**。不强制增加全句台账，必要时补一份轻量清单。HTML 与 PDF 展示同一集合。

没有外部文献时如实列内部资料；示意稿标明合成数据。确实没有来源材料时，先检查报告内容是否为原创观点及其适用范围，**不编造参考文献填页**。

## 封底

复用封面的主题、字体、对齐、顶栏、页脚和同一份元信息，减少内容、增加留白。默认中部放报告简称或研究主题；可使用 38px 标题起点，日期和已知版本仍置底。客户称谓与完整副题不必重复。

**不引入新结论或新资料**；不默认使用巨大的"谢谢/Q&A"、口号或二维码。确有现场演示或联系用途时，使用用户提供的真实内容。**封底始终是最后一页。**

## 制作入口

`assets/deck-bookends.css` 是首尾样式的唯一维护源，`apply_theme.cjs` 已内联它。修改样式后用 `node scripts/sync_bookends.cjs` 同步引擎示例。独立升级样式可用：

```sh
node scripts/bookends.cjs draft.html styled.html report
```

注入只更新局部样式与显式文档属性，不改旧页正文，也不自动插页。

`scripts/bookends.cjs` 提供可选的构建函数；作者仍可直接写等效语义 HTML。函数按纯文本处理并转义，不把材料解释成 HTML：

```js
const bookends = require('/实际skill路径/scripts/bookends.cjs');
// meta：title 与 shortTitle 必填；按已知内容选填 type/date/producer/client/
//       subtitle/version/project/access/statement/closingText
const meta = { title: '报告主题\n与业务范围', shortTitle: '报告主题', type: '研究报告', date: '实际报告日期' };
const sources = [{ id: 'S1', author: '实际机构', title: '实际材料标题', date: '实际年份', kind: '用户提供', locator: '原文件/页码' }];
const front = bookends.cover(meta);
const refs = bookends.references({ sources, columns: 1, page: 3 });
const back = bookends.backCover(meta);
// 把 front、正文、refs、back 插入引擎 stage，再 applyStyles(html, {kind:'report'})
// 之后 pack_fonts → qa_deck → 实际审查 → package_delivery
```

来源字段为 `id/author/title/date/version/locator/kind/url`，**只有标题必填**；不强制 JSON 作为唯一底稿。相同 ID 的冲突由作者解决，不猜测版本；无 ID 时生成 S1、S2 等标识，书目可见标识要与正文和底稿一致。

需要节选时传 `selectedIds`，总清单仍传完整 `sources`；函数保留首次出现顺序和原编号，自动标识节选与展示/总数量，`note` 可补真实底稿去向。双栏可用 `splitAt` 按实际长度分配，默认按数量均分只是起点；**函数不承诺自动容量适配**。完整可运行示例见 `scripts/build_bookends_example.cjs`。

手工参考页保留这些属性：页面 `data-reference-scope="all|selected"`、`data-reference-total`，条目 `data-reference-id`，书目正文 `.reference-text`，可见来源标识 `.reference-number`。它们用于数量和打印检查，**不能替代内容复核**。

## 验收

**首尾成对看图**，逐项确认：

- 完整报告页序正确，首尾元信息一致，标题与页脚不碰撞。
- 参考资料只有一页，节选标识准确，引用真实且完整底稿有去向。
- **参考条目没有缩成微字、没有截断、没有滚动、没有被隐藏**；每项参考资料完整进入 PDF。
- 逐页 Source 不因为末页汇总而被移除；功能页没有假结论、空字段和示例残留。
- **点击来源不能同时翻页**；链接 Enter 可操作，焦点在链接或控件上时不触发背景快捷键。总览里点击缩略页只选择该页，之后再访问来源；普通背景翻页、深链与打印继续工作。
- 离线下载的同版 PDF 不改变报告状态。HTML 与 PDF 是同一集合。

`qa_deck.cjs` 对声明为 report 的稿件检查首尾完整性，对显式功能页检查书目数量、溢出、标题/日期和 PDF 完整条目。**自动结果不能证明去重语义、来源真实性或视觉完成**，必须看实际页面、PDF 与总览，并记录实际独立性。检查项与放行标准见[验收](qa.md)，交付链见[交付契约](delivery.md)。
