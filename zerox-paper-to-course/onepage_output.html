WHY传统读论文为什么失败

传统阅读困境
  • 从头读，卡在公式 3，跳到结论
  • 只记住摘要的大致意思
  • 论文默认的前置知识你并不具备
  • 形式化在前、直觉在后，认知倒挂
zerox-paper-to-course 翻转顺序
  • 先建立直觉，再讲形式化
  • 先讲背景，再讲论文贡献
  • 先提问，再给答案
  • 模块 0 给你词汇表，再进入正文

PIPELINE五阶段流水线：从 PDF 到交互课程

1

深度阅读

三遍阅读：略读结构 → 提取公式/结果/数据集 → 识别叙事弧线。目标：理解到能教别人的程度。

3-pass reading
2

知识扩展

WebSearch 补充前置概念、相关工作与研究脉络。"好奇的实践者"不知道什么？论文默认了哪些背景知识？

web search expansion
3

课程设计

5-8 个模块，按故事线组织：背景 → 问题 → 研究脉络 → 核心洞见 → 方法 → 实验 → 启示。模块 0 为必选。

5-8 modules · story arc
3.5

模块简报（复杂论文）

7+ 模块时先写简报：教学弧线、预提取公式、交互元素清单。支持并行子代理分发，每批 3 个模块。

parallel subagent dispatch
4

构建

创建目录，复制 CSS/JS/Footer/Build 脚本，自定义 HTML 壳，编写封面与各模块，一条 cat 命令组装为 index.html。

cat → index.html
5

审查与打开

15 条检查清单：术语提示、数学直觉、视觉密度 50%+、响应式布局、局限性暴露、模块过渡。

15-item review checklist

FEATURES核心能力

零依赖运行

IIFE 架构，无框架。仅 Google Fonts + KaTeX CDN，首次加载后可离线使用。

一键组装

cat _base _cover modules _footer > index，无 bundler。

双语术语

默认简体中文输出，自动检测语言切换。中文解释（English Term）。

5 色调色板

Vermillion / Coral / Teal / Amber / Forest。在 _base.html 中选一个，其余自动完成。

测试应用能力

选择题优先测"你会怎么预测"和"哪里出了问题"，错误答案有鼓励性解释。

并行构建

复杂论文（7+ 模块）通过模块简报 + 子代理分发，每批 3 模块并行写作。

PHILOSOPHY教学理念

1直觉优先，每个公式先日常语言解释，再给数学
2论文的故事，每个模块是章节，不是摘要
350%+ 视觉，每块文本最多 2-3 句，列表变卡片
4一屏一概念，杜绝文字墙
5质疑一切，暴露局限性、挑战假设
6知识扩展，前置概念 + 研究脉络 + 相关工作
7引导入门，模块 0 先给学习者词汇表
8双语术语，中文解释（English Term）

GET STARTED如何使用

arXiv URL
"make a tutorial from arxiv.org/abs/..."

DOI
"用这篇 DOI 做教程"
