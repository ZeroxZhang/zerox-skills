# 任务契约

动工前填好并与用户对齐；随任务目录保存为 `task-contract.md`。需求变更**先改本契约再改产出**，验收以本契约为准。

| 字段 | 内容 |
|---|---|
| 目标与决策用途 | <这份交付要支撑什么决策> |
| 受众与汇报场景 | <谁看、在哪讲> |
| 最终交付物 | <格式 · 页数/体量 · 文件名> |
| 证据要求 | <可引用来源、口径、时点、禁止使用的材料> |
| 验收标准 | <可检查的完成判据，逐条> |
| 边界（不做什么） | <明确排除的任务与近邻问题> |
| 约束 | <时间、隐私、授权、版式> |

---

填表说明：形容词（专业、深入、好看）必须改写成可观察行为；验收标准逐条可判定「做到 / 没做到」。
