## 三个入口

- 阅读结论：[主报告](report.md)。
- 复用数据：[数据说明](data/README.md)、[数据集目录](data/datasets.json)、[字段字典](data/dictionary.csv)。无可用数据时删除这组链接，明确写不可获得/不适用及理由。
- 核验证据：[来源索引](sources.md)，配合 notes/ 的摘录与 raw/ 的原件。

## 文件职责

| 路径 | 用途 |
|---|---|
| package.json | 格式版本、数据/检索适用性 |
| work/brief.md、work/plan.md | 任务契约、进度与缺口 |
| work/tasks/、work/search-logs/ | 有分工时的任务与交接、实时检索记录 |
| data/extracted/、data/curated/ | 按来源提取的记录、整理与派生的复用表 |
| notes/ | 逐字摘录、解读、冲突与采用理由 |
| analysis/ | 计算、转换、编码方法与复跑说明 |
| raw/sources/ | 来源快照与元数据 |
| raw/files/、raw/user-provided/ | 原始附件与用户材料副本，采集后不改 |
| qa/review.json、qa/checks.json | 人工实质核验、封包时机器结果 |
| manifest-sha256.txt | 除自身外所有包内文件的完整性清单 |

```bash
shasum -a 256 -c manifest-sha256.txt
```
