## 如何核验一条结论

1. 在 `report.md` 找到结论后的引用号，如 `[3]`
2. 翻到文末「参考来源」`[3]` 那一行，拿到来源 ID 与本地存档路径
3. 打开快照，按笔记里的定位（章节 / 页码 / 表号 / 时间戳）找到原文段落
4. 对照 `notes/` 中该论断的「逐字摘录」与「解读」——摘录是原文，解读是加工

## 完整性校验

```bash
shasum -a 256 -c manifest-sha256.txt   # macOS
sha256sum -c manifest-sha256.txt       # Linux
```

清单列出研究包内除它本身以外的所有文件，每行 `SHA-256 值 + 两个空格 + 相对路径`。
校验失败说明文件被改动或缺失。生成命令：`python scripts/check_package.py <研究包> --write-manifest`。
