# 信息提取与分级

## 1. 材料盘点

**先略读，再精读。** 略读顺序：目录 → 摘要与结论 → 图表标题 → 各节首段 → **末节与附录**。这一步建立全局地图与初始假设，之后才知道哪些该精读。

每份材料登记：编号（`S01`、`S02`…）、名称、类型、时间、作者或来源、可信度、与主题相关度、体量、处理状态（未处理 / 略读 / 精读完成）。

- **处理深度按相关度分配**，不平均用力。但低相关材料也必须完成略读级提取——漏掉一份「看起来无关」的材料里的关键信息，是最常见的翻车方式。
- **重复与多版本**：同主题的多个版本（v1 / v2 / 最终版、周报的多次汇总）只精读准据版本，其余标「重复 → Sxx」。裁定准据的原则依次是：时间更新 → 口径更明确 → 来源更权威 → 数据更完整。
- **长文档的后部必须读到**。关键数据经常在最后 10%——行业报告「风险提示」节、附录表格、会议纪要的「其他事项」、邮件的最后一段。判据：**超过 200 行或 20 KB 即视为长文档**，处理状态里必须写明读到哪一行/哪一节（如「精读完成，读至第 445 行」），光写「精读完成」不算。

相关度与处理深度的对照：

| 相关度 | 处理深度 | 产出 |
|---|---|---|
| 高（直接回答核心问题） | 精读全文，含附录与脚注 | 完整卡片，含 A 级 |
| 中（提供背景或佐证） | 精读关键节 | 卡片，多为 B 级 |
| 低（边缘相关或过时） | 略读 + 定位关键段 | 至少 1–3 张卡，标 C 级或说明为何无卡 |

## 2. 卡片字段

一卡一信息，不合并、不嵌套。

| 字段 | 填写规则 |
|---|---|
| **卡片ID** | `C001` 起顺序编号，全文唯一，不复用；删除卡片时保留空号并在索引注明 |
| **类型** | 数据 / 事实 / 观点 / 洞察 / 案例 / 引语 / 问题 / 风险 / 约束 / 建议 / 方法 / 背景 |
| **内容** | 保留原始数字、单位、时间、统计口径、主体、限定条件。**关键表述保留原话**（加引号）。不写「增长显著」，写「同比 +12.4%」 |
| **含义 So what** | 这条信息对决策意味着什么。只给 A / B 级填，且**与事实分开写**。没有含义就留空，不硬凑 |
| **来源定位** | `S03-p12`、`S05-§2.1`、`S07-表3`；多来源并列；与准据版本冲突的来源单独标注 |
| **性质** | 事实 / 推断 / 观点 / 假设——写材料**本身**的性质，不是你的判断 |
| **可信度及依据** | 高 / 中 / 低 + 一句话依据（谁说的、方法是否披露、有无利益立场） |
| **价值等级** | A / B / C，判据见下节 |
| **主题标签** | 自由词，用于后续聚类；同主题用同一个词，不要一会儿「市场规模」一会儿「市场容量」 |

可选字段：`冲突`（并列记录的对象与差异）、`备注`（处置说明）、`外部补充`（用户允许外部知识时，补充内容**必须**进这个字段并说明来源，不得混进「内容」）。

**含义与事实分开的意义**：主线做减法是靠「含义」排序的，但保真回查时核对的是「内容」。混在一起，两件事都做不好。

## 3. 价值分级 A / B / C

分级问的是**「这条信息在论证里承担什么角色」**，不是「它好不好」。一条信息可以非常准确、非常有价值，而在论证里只配当背景。

**决定性问句**（对每条候选 A 卡问一遍）：

> **把这张卡从材料里抽掉，中心论点或某个关键支撑点会不会不成立、或必须改口？**

会 → A。不会，但它让某个论点更可信、更具体、更好懂 → B。既不影响论证也不需要 → C。

| 级别 | 判据 | 典型 |
|---|---|---|
| **A 决定性** | 抽掉它，主线或某个关键支撑点要改口：独有或稀缺的数据、决定性的量化证据、反直觉的洞察、影响决策的风险与约束、关键人物的原话、与主线冲突的少数派证据 | 试点店净利率 −4.2%（推翻「营收高就该进」）、核心商圈租金 +18.7%（解释为什么亏）、加盟商一年亏 41 万（反方证据） |
| **B 支撑性** | 让论点更具体可信，但抽掉它论证仍成立：佐证、背景、例证、口径说明、过程数据 | 客单价的加权算法说明、区域分仓的行业规律、同行做法 |
| **C 不进入** | 重复、空泛、过时、与主题无关 | 上一版的旧数据、行业通识、与本议题无关的行政通知 |

**校准经验值**：A 级是稀缺的。一批决策材料里，A 级通常不超过卡片总数的 **1/4 到 1/3**。如果算出来超过 35%，几乎可以确定是把「与决策有关」（在决策材料里人人满足）当成了「决定性」——按决定性问句重刷一遍，通常会有大批 A 降到 B。脚本在 A 级占比 ≥35%（且卡片数 ≥20）时会给出这条提醒。

**宁可收紧也不要放松**：A 级要 100% 有去向，把无关紧要的卡判成 A，实际效果是让 A 级失去意义、让覆盖审计变成走过场。判不准时先判 B——阶段 3 复核还能升回来，而一个虚高的 A 级会在定稿时制造无谓的安置压力。

四条硬规则：

1. **C 级保留在卡片库中，不删除，也不进交付物**。C 级是「已评估过、判定为不必进主线」，不是「没看过」；审计时要能说出它为什么是 C。但它**不进正文、页面、讲者备注、备用页或附录正文**——只在卡片库与审计报告里登记。一条 C 级信息若确实影响决策，那是分级错了，改级，而不是把它塞进风险章。
2. **与主流结论冲突的少数派证据，默认不低于 B 级**。哪怕它只是访谈里的一句反对意见、一份报告的脚注。
3. **提取阶段不做价值判断的过滤**。先穷尽提取，再分级；按初始假设过滤是主动丢弃。（分级本身可以保守，因为它改得回来；漏提取补不回来。）
4. **分级复核直接改卡片文件**。阶段 3 与阶段 6 复核后，改的是卡片 `- 价值：` 字段本身，并同步合并索引的统计；复核依据（升级/降级的理由）写进 `03_storyline.md` 的复核表。只写复核表而不改卡片文件，脚本仍按旧等级算覆盖率——等于没复核。升级会新增必须安置的 A 级卡，这部分安置要求要在写正文时一并解决。

## 4. 分类型材料的处理要点

| 材料类型 | 提取要点 | 特别禁止 |
|---|---|---|
| **会议纪要** | 区分发言人与立场（「A 认为…」不是事实）；保留有分量的原话；记下结论、待办与**分歧点**；注意日期与参会层级 | 把某人的判断写成公司结论 |
| **访谈记录** | 标注受访者身份与利益立场；保留代表性原话；把「受访者推测」与「受访者陈述的事实」分开；记录与主流不一致的意见 | 把访谈里的一句抱怨升级成普遍结论 |
| **数据表** | 保留关键行列与**原始数值**，不只写结论；记录列名、单位、口径说明行、备注行；注意总计与分项是否对得上 | 丢单位、丢口径注释、自行四舍五入 |
| **旧 PPT** | 提取其结论与数据，注明制作时间；**只取内容，不继承结构**（旧 PPT 多半是平铺的「现状—竞品—建议」） | 沿用旧 deck 的章节顺序或标题 |
| **报告 / 白皮书** | 优先取数据、图表与结论；记录方法论与样本；注意口径与适用范围；读到末节与附录 | 照抄其叙述顺序 |
| **邮件 / 往来记录** | 提取承诺、数字、时间节点与分歧；保留发件人角色与日期 | 把邮件里的口头估算当正式数据 |
| **网页 / 摘录** | 记录 URL、访问日期、发布方；注意是否被截断 | 把摘录的片段当完整表述 |

## 5. 去重

同义信息合并为**一张**卡，来源栏保留**全部**来源，内容栏采用**最精确**的表述。

判定：两条卡说的是同一件事吗？是 → 合并。同一件事的两次不同表述（一次模糊一次精确）→ 用精确的那次，模糊来源仍保留在来源栏。

不要把「看起来相似但口径不同」的合并掉——那属于冲突，见下节。

## 6. 冲突

不同来源的数字或说法不一致时：**并列记录，标注冲突，不擅自取舍**。

1. 先查是不是「假冲突」：口径、时间、方法三者不同，往往就是差异原因。
2. 建**冲突清单**表（格式见 `../assets/info-cards-template.md`），记录双方数值、口径、位置与差异原因。
3. 处置可选：说明差异原因 / 并列呈现 / 采用更权威一方并写明理由——**任何一种都要写下来**，不能只在正文里改个数字了事。
4. 裁决权在阶段 3 与阶段 6，不在提取阶段。
5. **行文层面允许收敛，但必须说明**。并列两套数字会让页面难读，此时可以收敛为一句判断（「取两个来源中较严的一组，理由：本公司抗风险能力低于样本均值」），但前提是：冲突清单里双方原值与口径都还在，且正文写明取用理由。**禁止的收敛方式**是把两个数平均或折中（「约 1 万家」「大致 150 亿」）——那既不是甲也不是乙，是编出来的第三个数，脚本查不出，人要负责。
5. 冲突本身是发现：它通常指向口径分歧、利益立场或未公开信息，值得单独写进风险或待决问题。

## 7. 术语与口径对照

同一概念在不同材料里可能有不同叫法，同一指标可能有不同统计口径。建一张对照表，锁定全文用词：

| 概念 | 材料中的叫法 / 口径 | 采用表述 | 说明 |
|---|---|---|---|
| 单店营收 | 「月均营业额」（含外卖）/「单店月收入」（仅堂食） | 单店月均营收（含外卖） | 两处相差 5.4 万元，引用时必须写口径 |

没有这张表，内容稿与 PPT 迟早会在同一个指标上写出两个口径的数字——这是审计「一致性检查」抓到最多的问题。

## 8. 大材料的分批与断点续做

材料总量超出单次处理能力时：

1. 按**自然结构**切块：章节、页码区间、工作表、邮件会话——不要按字数硬切。
2. 每批处理完**立即落盘**：卡片写入 `02_info_cards.md` 或分批文件，材料索引的「处理状态」同步更新。
3. 维护一张进度表（材料 × 块 × 状态），断点续做时从第一个未完成的块开始。
4. **追加新材料**时走增量：新编号续编（`S09`…），只提取新卡片，然后评估是否动摇已有主线——不动摇就不重跑，动摇就回到阶段 3 并说明影响范围。
5. 分文件存放时（按来源拆成 `02_info_cards_S01.md` 等），最后生成一份合并索引 `02_info_cards.md`，列出全部卡片 ID、等级与主题，供脚本与审计使用。**索引用表格，不要重复贴 `### Cxxx` 卡片块**——脚本按 `### Cxxx` 解析卡片，索引里再写一遍会被判成卡片 ID 重复。索引文件本身不含卡片块时，脚本只从它读不到东西，不影响结果。

## 9. 机器可读格式

卡片库以 Markdown 为准（人读），可同时导出 `.jsonl`（一卡一行，字段同名）供工具消费。`scripts/check_content.py` 支持这两种格式。

Markdown 卡片块的写法固定为 `### 卡片ID` + 字段行，字段名与本文 §2 一致，续行会被并入上一个字段：

```markdown
### C012

- 类型：数据
- 内容：2026 年上海现制茶饮市场规模 210 亿元，同比 +8.2%（口径：仅现制茶饮，不含预包装与咖啡）
- 含义：上海增速低于全国均值，市场已进入存量竞争
- 来源：S03-§2.1；S07-p14
- 性质：事实
- 可信度：中 ｜ 依据：第三方机构测算，方法未完全披露
- 价值：A
- 主题：市场规模
```

卡片 ID 在内容稿与 PPT 中一律用〔C012｜S03-p12〕的格式引用（全角括号与竖线，多个卡片用 `、` 分隔）。脚本按这个格式反查覆盖率与数字溯源。

## 10. 派生卡片

你在成篇过程中会算出材料里没有的数：两个数的差额、占比、按同一口径重算的比率、按某情景推出来的结果。这些不能凭空写进稿件（不变量 1），也不该塞回某张材料卡的内容栏（那会篡改原始信息）。**给它们建派生卡片。**

- ID 续编在材料卡片之后（如 `C174` 起），不占用材料编号段。
- **性质**固定为 `推断`。
- **内容**栏写的是**算式与结果**，不是结论：写清用了哪几张卡、怎么算的。例：
  `上海两店 4—6 月月均营收 25.35 万元 ÷ 西南门店月均 19.8 万元 − 1 = 高出 28.0%（输入：C005、C012）`
- **来源**栏写 `派生自 C005、C012`；**可信度**取「输入卡片中最低者」与「推算精度」两者中更低的一个，并注明是哪一项拉低的。例：输入三张卡都是「高」，但计算用区域均值替代了门店加权，精度不够 → 写 `中 ｜ 依据：输入卡均为高，但净利率用区域均值近似`。机械跟着输入卡走会高估推算结果的可信度。
- **价值**按决定性问句正常评。

派生卡片与材料卡片同等纳入覆盖率与数字回查：脚本认它的 ID、核它的数字。这样「卡片库是事实的唯一来源」与「推断可以是新材料里没有的数」就不再打架——推断是**有出处的**，出处就是它的输入卡。

引用的写法与材料卡片一致（〔C175｜派生自 C005、C012〕），行文中仍要带「推断」二字。
