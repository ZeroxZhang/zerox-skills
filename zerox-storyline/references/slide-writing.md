## 1. 行动标题

一页的标题必须是**这一页的结论**，不是这一页的话题。读者只看标题列，就应该读到一个完整的故事。

| ❌ 话题式 | ✅ 行动式 |
|---|---|
| 市场分析 | 华东市场增速连续 3 个季度放缓至 5%，已低于全国均值 |
| 竞争格局 | 前五名门店数一年增加 40%，我们同期只增加 6% |
| 试点店表现 | 两家试点店 6 个月复购率 41%，高于成都同期 12 个百分点 |
| 成本结构 | 租金占单店成本 28%，是唯一还在上涨的成本项 |
| 风险提示 | 租金同比 +23%，把盈亏平衡周期从 14 个月拉到 26 个月 |
| 下一步工作 | 建议四季度先开 3 家小店验证租金假设，通过后再放到 8 家 |

写法：

1. 先把**话题**写出来（「试点店表现」）。
2. 问自己：这一页到底要说明什么？把答案写成一句完整的话。
3. 把这句话里的抽象词换成数字。
4. 检查：这句话需要正文来支撑吗？不需要 → 这页可以删掉。

**长度**：建议 ≤30 字，最多两行。超了说明有两个结论，拆成两页。

**标题与正文的关系**：正文只放支撑这一句标题的证据。放不进去或支撑不上的内容，移到讲者备注或备用页。

## 2. 演讲型与阅读型

| | 演讲型 | 阅读型 |
|---|---|---|
| 场景 | 现场讲，有时限，讲者控场 | 会前阅读，可能没人讲 |
| 页面密度 | 低（3–5 条要点或 1 张图） | 高（信息自解释，可含更多文字） |
| 细节去哪 | 讲者备注 | 页面本身 |
| 页数 | 少，按时长硬约束 | 可多，按逻辑完整度 |
| 备用页 | 几乎必须 | 可选 |
| 失败样子 | 页面上是讲稿，讲者照着念 | 页面上是文章，读的人找不到重点 |

两种类型**都需要行动标题**。阅读型的正文可以更完整，但标题依然是结论句。

## 3. 页数估算

| 场景 | 节奏 |
|---|---|
| 演讲型，正式汇报 | 每页 1.5–2 分钟 |
| 演讲型，含讨论互动 | 每页 2–3 分钟（留出追问时间） |
| 阅读型 | 不按时长，按逻辑完整性，通常比演讲型多 30–60% |

页数超上限时的处置顺序：**先合并同层级的次要页 → 再移入备用页 → 再进附录**。不允许的处置：删掉该内容；把三条要点塞进一条；缩小字号（那是下游的事，且不是解决方案）。

封面、目录、章节过渡页不计入内容页预算，但也不该滥用——过渡页超过 4 页说明章节切得太碎。

## 4. 页面类型库

| 类型 | 何时用 | 结构 | 标题写法 |
|---|---|---|---|
| **封面** | 第一页 | 标题 / 副标题 / 受众 / 日期 / 保密级别 | 主标题可用话题式，其余页面不行 |
| **目录** | 5 页以上 | 章节与页码 | 「本报告回答三个问题」优于「目录」 |
| **执行摘要** | 紧跟封面 | 中心论点 + 2–4 条理由 | 直接写中心论点 |
| **章节过渡** | 章节切换 | 章节名 + 本章一句话结论 | 本章结论句 |
| **观点 + 证据** | 最常用 | 标题 + 3–5 条要点（每条带证据） | 行动标题 |
| **数据图表** | 有量化证据时 | 1 张图 + 标注 + 结论条 | 图表揭示的结论 |
| **对比** | 两三个方案 / 前后 / 竞我 | 并列栏 + 同一维度的对照 | 对比得出的判断 |
| **流程** | 讲步骤、机制、链条 | 3–6 步，标出关键节点 | 流程的产出或卡点 |
| **时间线** | 讲演进、计划、里程碑 | 横向时间轴 + 事件 | 时间线揭示的转折或节奏 |
| **矩阵** | 二维定位、优先级排序 | 2×2，标出我们的位置 | 落点判断与含义 |
| **案例** | 用一个实例支撑论点 | 背景 → 做法 → 结果 → 启示 | 案例说明的道理 |
| **建议** | 结论章 | 建议条目 + 优先级 + 责任 / 时间 | 建议本身 |
| **下一步** | 结尾 | 行动、时间、请求决策 | 明确的 ask |
| **备用** | 预判追问 | 一页一个问题 | 被问的那个问题 |
| **附录** | 支撑材料 | 数据表、方法、来源 | 内容说明 |

**结尾页必须是建议、下一步行动或请求决策三者之一**，不能是「谢谢」或「Q&A」。

## 5. 图表选择

先明确要表达**哪一种比较关系**，再选图。数据与关系不匹配是最常见的图表错误。

| 比较关系 | 要回答的问题 | 图表 | 备注 |
|---|---|---|---|
| **成分** | 各部分占整体的比例 | 饼图（≤5 项）、堆叠条形、瀑布图 | 项目多时用堆叠条形；占比随时间变化用面积图 |
| **项目排序** | 谁大谁小、排第几 | 横条图 | 项目名较长时横放；不要用饼图排序 |
| **时间序列** | 怎么变的 | 折线（趋势）、柱状（离散期间） | 关注变化率用折线；关注绝对量用柱状 |
| **频率分布** | 落在各区间有多少 | 直方图、箱线图 | 不要用折线画分布 |
| **相关性** | 两个变量是否相关 | 散点图、气泡图 | 相关不等于因果，标题里不许写因果 |

每个图表页要在逐页内容里写清三件事：

1. **图表类型**与**为什么是它**（对应上表的关系）。
2. **所需数据字段与数值**——具体到列名与数字，让做片的人不用回头查稿；数值必须来自卡片库。
3. **需要高亮的重点**——哪个点、哪条线、哪个区间是这一页要读者看见的；以及轴、单位、口径、时间范围的标注要求。

图表标题本身也应当是行动标题或结论句，读者只看图题就能拿到信息。

## 6. 讲者备注

写成**可直接口述**的话，不是提纲。

- 开头一句承接上一页，结尾一句过渡到下一页。
- 包含页面上没有但要说的细节（数据来源、限定条件、被追问时的补充）。
- 口语化：短句、少术语、有停顿感。
- 长度按每页讲述时间估：中文约每分钟 200–250 字。

过渡语不要用「接下来我们看下一页」，用内容连接：「既然租金是主要变量，那我们的单店模型能不能扛住——下一页是测算结果。」

## 7. 备用页

预判受众最可能追问的 3–5 个问题，各准备一页。

- 首选材料：**未进入主线的 A / B 级卡片**——这正是「主线做减法、交付物做加法」的兑现处。
- 每页一个问题，标题就是那个问题（或它的答案）。
- 备用页同样要标注来源与追溯，不能因为是备用就松掉。
- 常见追问方向：数字怎么算的、口径是什么、最坏情况、为什么不选另一个方案、同行怎么做。

## 8. 页面规则与常见错误

**规则**：一页只讲一个核心信息；不支撑标题的内容移到备注或备用页；页面上的一切事实来自内容稿或卡片库，不得新增。

| 错误 | 症状 | 修法 |
|---|---|---|
| 一页多结论 | 标题用了「与」「及」连接两件事 | 拆页 |
| 正文与标题无关 | 正文讲的证据支撑不了标题那句话 | 换标题或换正文 |
| 标题是话题 | 读者读完标题列得不到故事 | 按 §1 改写 |
| 数字失真 | 页面上的数字与内容稿不同，或多了卡片库没有的数字 | 回母版改，再同步 |
| 口径丢失 | 页面上写「单店月均 18 万」，没写含外卖 | 补口径标注 |
| 备而不用的备用页 | 准备了 10 页，没有一页是可能被问的 | 按 §7 重列 |
| 结尾是「谢谢」 | — | 换成建议 / 下一步 / 请求决策 |
