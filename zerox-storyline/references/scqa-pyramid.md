# SCQA 与金字塔

把一堆卡片变成一条能说服人的主线，靠的是两件事：纵向的疑问—回答链，横向的分组与排序。本文给出判据、四种开场顺序与正反例。

## 1. 金字塔四原则

| 原则 | 判据（做不到就是没做到） |
|---|---|
| **结论先行** | 全文第一段、每章第一句、每页标题，读到的都是结论而不是话题或过程 |
| **以上统下** | 上层是下层的概括，不是下层的引言；把下一层全部读完，得到的信息不超过上一层 |
| **归类分组** | 同一组里的条目属于同一逻辑类别，不是拼盘（「市场、竞争、我们的优势」不是一组） |
| **逻辑递进** | 组内顺序有依据（时间 / 结构 / 重要性 / 因果），不是想到哪写到哪 |

自上而下是**表达**顺序，自下而上是**思考**顺序。工作时要两头走：先从卡片归纳出组级观点，再从受众的问题出发核对这条线是否回答了真正被关心的东西。

## 2. 纵向：疑问—回答链

上层抛出一个断言，读者心里会冒出一个问题；下一层必须正好回答那个问题。链就成立了。

**自检方法**：站在每一层断言下面，写下读者此刻会问的那句话。

```
中心论点：2027 年应进入上海，但必须以 8 家以内的直营小店切入（而不是大开）
  └ 读者会问：凭什么进？（机会）
      └ 支撑点一：上海单店坪效比成都高 34%，且我们的品类在上海尚无强势占位者
  └ 读者会问：为什么要小？
      └ 支撑点二：核心商圈租金同比 +23%，大开模式的盈亏平衡周期从 14 个月拉长到 26 个月
  └ 读者会问：凭什么说是「我们」能做成？
      └ 支撑点三：两家试点店 6 个月复购率 41%，高于成都同期 12 个百分点
```

如果某一层的回答答的是**另一个**问题（读者问「凭什么进」，你答「怎么进」），链条就断了。这不是内容不够，是顺序错了。

## 3. 横向：分组与排序

**MECE 检查**（用于同组条目）：

- *相互独立*：任意两条是否重叠？两条都覆盖同一片事实，就是没切开。
- *完全穷尽*：是否还有第三类？把组内条目反过来当问题的答案，看有没有漏。

常用的分组维度（一次只用一种，混用必然重叠）：时间阶段、组织结构、价值链环节、重要性档位、因果链。

**排序依据**（选一种，写进故事线）：

| 依据 | 何时用 | 例子 |
|---|---|---|
| 时间 | 有明确阶段或先后依赖 | 试点 → 扩张 → 深耕 |
| 结构 | 按业务 / 区域 / 部门切分 | 门店、供应链、品牌 |
| 重要性 | 受众只记得住前两条时 | 最大的风险排第一 |
| 因果 | 需要论证链条 | 客流下滑 → 坪效下降 → 回本周期拉长 |

## 4. 演绎与归纳

| | 演绎 | 归纳 |
|---|---|---|
| 形式 | 大前提 → 小前提 → 结论 | 一组同类事实 → 共性结论 |
| 强度 | 前提为真则结论必真 | 结论是概率性的，依赖样本 |
| 风险 | 前提被攻击，整条链崩塌 | 被一个反例打穿 |
| 适用 | 结论反直觉、受众专业、需要严密 | 受众时间紧、需要好记、事实充分 |

**混用是常态**：主体用归纳（好记、好讲），关键结论处用演绎（扛得住攻击）。但**不要在同一组里混**——一个支撑点下面既讲「因为所以」又讲「三个例子」，读者会不知道你在证明什么。

## 5. SCQA 四要素

SCQA 是**问题定义与开场框架**，不是四段式模板。不要在产品里写「一、情境 二、冲突」这种小标题；它通常在引言里表现为几段自然文字。

| 要素 | 定义 | 判据 | 常见错误 |
|---|---|---|---|
| **S 情境** | 受众已知、认同、无争议的背景 | 念出来受众不会反对 | 写成公司简介或行业科普，长篇背景铺垫 |
| **C 冲突** | 打破现状的变化、矛盾、风险或机会 | **具体、有证据**；念出来受众会「哦？」 | 写成「面临诸多挑战」「竞争日益激烈」 |
| **Q 问题** | 由 C 自然引出的、受众最关心的那一个问题 | 把 C 读出来，Q 是「所以呢」的必然答案；只有一个问题 | 罗列五个问题；Q 与 C 无关，是硬接上去的 |
| **A 答案** | 对 Q 的正面回答，即全文中心论点 | 是断言（「应该做 X」），不是「我们要分析 X」；能回答 Q | A 答的是另一个问题；A 是「需要综合考虑」这种不表态的话 |

**C 的强度决定整份材料的上限。** C 弱，后面的 A 再漂亮也没人听。

| ❌ | ✅ |
|---|---|
| 公司面临诸多挑战 | 今年线下客流同比下降 18%，而竞品线上份额翻倍 |
| 行业竞争日益激烈 | 前五名门店数一年增加 40%，而我们同期只增加 6% |
| 数字化转型势在必行 | 同规模企业的系统投入产出比已达 1:3.2，我们的手工流程单店每月多耗 46 工时 |
| 存在一些风险 | 核心商圈租金同比 +23%，直接把盈亏平衡周期从 14 个月拉到 26 个月 |

Q 的写法：**把 C 翻译成受众会脱口而出的那一句**。「客流跌了 18%，竞品还翻倍——那我们怎么办？」这句就是 Q。注意 Q 要用受众语言，不是你的分析语言。

A 的写法：一句话，可执行、有方向、有边界。「要进上海」不如「要以 8 家以内直营小店切入上海」。

## 6. 四种开场顺序

| 顺序 | 展开 | 何时用 | 代价 |
|---|---|---|---|
| **标准式 S-C-A** | 情境 → 冲突 → 答案 | 受众不了解背景，需要铺垫；书面报告 | 高层没耐心时显得啰嗦 |
| **开门见山 A-S-C** | 答案 → 情境 → 冲突 | 面向高层、时间紧、结论已被期待 | 受众缺背景时答案悬空，需在备注里补 |
| **突出忧虑 C-S-A** | 冲突 → 情境 → 答案 | 需要制造紧迫感、推动行动或争取资源 | 用多了显得危言耸听，损伤信任 |
| **突出信心 Q-S-C-A** | 问题 → 情境 → 冲突 → 答案 | 受众带着明确问题而来（答标、评审、答疑） | 问题不成立或问偏了，整个框架失效 |

选择判据按顺序问自己：受众是否带着问题来（是 → Q-S-C-A）？受众是否已经认同结论（是 → 用 C 开路制造紧迫）？受众是否需要背景（不需要且时间紧 → A-S-C）？都不满足 → 标准式。

顺序只影响**开场**，不影响正文——正文永远是 A 的逐层论证。

## 7. 形式化 SCQA 的十种死法

1. C 是形容词堆砌，没有数字、没有时点、没有主语。
2. C 后面直接跳结论，中间没有 Q——读者没来得及提出问题就被喂了答案。
3. Q 有五个，等于没有重点。
4. A 是一个话题（「我们的应对策略」），不是断言。
5. A 回答了 Q 之外的另一个问题。
6. S 太长，占掉开场一半篇幅，受众开始看手机。
7. 四个要素齐了，但 A 在正文里从没被真正论证过——正文讲的是别的。
8. 为了故事顺畅，把不利的 C 删了（例如只讲机会不提租金压力）。
9. 纵向链条断：第二层答的是「怎么干」，而读者问的是「为什么干」。
10. 横向不 MECE：三个支撑点里有两件事其实是一件事，第三件事没地方放。
