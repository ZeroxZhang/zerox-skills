## 1. 三条生成路径

**自下而上（归纳）**：把 A / B 级卡片铺开，按内容亲缘度归类（不是按材料来源归类——来源分类是别人的结构，不是你的）。每归出一组，追问三次：

1. 「这组卡片的共同点是什么？」→ 组名
2. 「所以呢？」→ 组级观点（这一步才是产出，组名不是）
3. 「这个观点支持什么结论？」→ 上一层

如果追问到「所以呢」时答案是「说明情况比较复杂」，说明这组卡片还没归好，回去重切。

**自上而下（受众）**：不看卡片，只看受众与目的，写出三个东西——受众现在相信什么？他需要相信什么才能做出你要的决定？他现在最担心什么？第三个问题的答案通常就是 Q。

**交汇**：自上而下得到的 Q 与自下而上得到的组级观点对撞。能对上 → 主线成立；对不上 → 要么 Q 问偏了，要么卡片里有更值得说的东西没被归出来。

## 2. 主线模式库

受众对不同类型的材料有不同期待。**缺了该类型必备的那一块，材料再漂亮也是失败的。**

| 模式 | Q 的形态 | A 的形态 | 典型支撑点序列 | 最容易翻的车 |
|---|---|---|---|---|
| **问题诊断 → 方案** | 为什么会这样 / 该怎么办 | 根因是 X，所以要改 Y、Z | 现象 → 根因（分层） → 方案 → 实施与代价 | 只讲现象不挖根因；方案与根因不对应 |
| **方案比选** | 几个方案选哪个 | 选 B，因为…（附淘汰理由） | 评估维度 → 各方案对照 → 推荐与理由 → 风险与回退 | 维度是事后凑的；只讲推荐方案的好，不讲它的代价 |
| **请求批准 / 资源** | 给不给 | 请批 X（金额 / 人数 / 授权） | 现状与缺口 → 为什么现在 → 投入产出 → 风险与不批的后果 | **没有明确的 ask**（要什么、多少、什么时候） |
| **进展汇报** | 现在怎么样了 | 整体在轨，但 A 项偏离，需决策 B | 目标回顾 → 关键结果 → 偏差与原因 → 下一步与请求 | 报流水账；偏差轻描淡写；没有请求 |
| **机会论证** | 要不要进 / 要不要做 | 要进，但以 X 方式、Y 节奏 | 市场与机会 → 我们的胜算 → 打法与资源 → 风险与止损线 | 只有 upside，没有下行与止损；把「市场大」当成「我们能赢」 |
| **复盘 / 事后总结** | 当初为什么会这样 | 三个可复用的判断，两个要改的机制 | 结果对照目标 → 归因（可控 / 不可控） → 可复用与要改的 | 归因全在外部；教训不可执行 |
| **行业研究** | 这个行业往哪走 | 趋势 X 确立，格局将向 Y 演化 | 格局 → 驱动因素 → 链条与价值链 → 关键变量 → 影响与启示 | 资料汇编，没有观点；有观点但没有证据链 |
| **尽调结论** | 投还是不投 | 投 / 不投 / 有条件投 | 业务 → 财务 → 团队 → 风险 → 估值与条件 | 风险章变成免责声明，遮遮掩掩 |

选模式的判据是**受众听完要做什么动作**，不是材料长什么样。

## 3. 造出真正有差异的候选

2–3 个候选必须是**真的不一样**，不是同一个主线的三种说法。差异来自三个可调旋钮：

| 旋钮 | 变化方式 | 例 |
|---|---|---|
| **角度** | 换成另一个因果起点 | 「因为租金涨所以别大开」vs「因为我们的品类在上海还没被占位所以必须快进」 |
| **结论强度** | 保守 / 中性 / 激进 | 「先开 3 家试水」/「8 家小店」/「一年 20 家抢占位」 |
| **受众侧重** | 换成另一个决策人的关心点 | 对 CFO 讲回本周期，对 CEO 讲竞争窗口 |

**不合格的候选**：把同一个结论换个措辞；只改了支撑点的顺序；一个候选明显是陪衬（凑数）。如果材料真的只支持一条线，写一条并说明为什么没有第二条——这比造假候选诚实。

每个候选必须写清**放不进去的重要信息及安置方式**。这一步是「不静默丢弃」的执行点：写不出安置方式的候选，说明它的主线太窄。

## 4. 假设—证据—结论链

每个支撑点都是一条小论证链，写成三段：

```
支撑点：核心商圈租金同比 +23%，大开模式的回本周期从 14 个月拉长到 26 个月
  ├ 证据：C031（S07-p42，租金涨幅）、C018（S01-表2，试点店单店模型）、C044（S04-访谈3）
  ├ 推断：以现有单店投入，租金每涨 10% 回本周期延长约 5 个月（本推断由 C018 与 C031 计算得出）
  └ 结论：所以扩张必须是「小店 + 短租约」，而不是复制成都的大店模型
```

- **证据栏**只放卡片 ID；查不到卡片的论断不能进这一栏。
- **推断栏**必须显式标注为推断，并说明依据来自哪几张卡——这是审计「保真回查」的重点对象。
- **结论栏**是这一层要回答的那句话，它同时是下一页/下一节的行动标题素材。
- 一条链里证据强度不足时，写**证据缺口**：缺什么证据、可以用什么方法补。

**证据强度**：强（多个独立来源或权威一手）/ 中（单一可靠来源）/ 弱（推断、个例、来源存疑）。弱证据可以支撑次要论点，不能单独支撑中心论点。

## 5. 压力测试

对推荐主线，模拟受众里最挑剔的那个人，提三类质疑，逐条检查现有证据能否回应：

| 质疑类型 | 怎么问 | 不能回应时 |
|---|---|---|
| **证据类** | 「这个数字哪来的？口径是什么？样本多大？」 | 补证据，或把该支撑点降级为待补充 |
| **反例类** | 「我见过一个反例，你怎么解释？」 | 把反例写进风险或待决问题，不许假装不存在 |
| **代价类** | 「按你说的做，最坏会怎样？止损线在哪？」 | 补下行分析与止损条件，否则这条主线不可执行 |

三个质疑的答案要么落在稿件里（作为风险章或子论点），要么落在审计报告的证据缺口清单里。**不许只写「已考虑」**。

## 6. 结构树与候选格式

选定主线后输出完整结构树，它是阶段 4 的写作蓝图与阶段 6 的核对清单：

```
中心论点（A）
├── 支撑点一：<结论句>
│   ├── 子论点 1.1：<结论句>  ← C012、C018（强）
│   └── 子论点 1.2：<结论句>  ← C031（中）；缺口：缺上海商圈租金的第三方数据
├── 支撑点二：<结论句>
│   └── …
└── 支撑点三：<结论句>
    └── …

移出主线的重要信息：
- C055（A 级，竞品在苏州的打法）→ 讲者备注 / 备用页
- C061（B 级，加盟商态度）→ 附录
待定池：C070（可信度低，需核实后再决定）
```
