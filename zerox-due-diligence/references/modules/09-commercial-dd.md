# 09 商业尽调

通用的主体/期间口径、证据与缺失、反证及权限规则见[证据标准](../evidence-standard.md)与[来源策略](../sources/source-strategy.md)；展开深度按[目的手册](../purpose-playbooks.md)和[行业适配](../industry-adapters.md)裁剪。

## 核心问题

公司怎样获客和营销，顾客如何转化与留存，收入、客户和合同能否兑现。营销机制是主报告必答内容；官网活动、内容、代言和客户Logo可说明企业做过或声称做过什么，不能直接证明销售、转化或回款实绩。

本模块验证模块03所描述的需求、客户和交易机制是否实际成立、能支持多大范围的结论；不重复编写业务流程。

## 调查项目

检查项按本次问题与重大性选择展开；缺资料保留未知，不能改为不适用。

| 检查 ID | 核验问题与特有判断 | 关键证据 |
| --- | --- | --- |
| M09-01 | 客户真实性、付费与试点、合作时间、集中度、客户质量与流失。 | 双方公开披露及获授权合同/订单/验收/回款记录 |
| M09-02 | 订单、履约、验收、开票和收款的可核对链条。 | 双方公开披露及获授权合同/订单/验收/回款记录 |
| M09-03 | 营销渠道、目标人群、内容/活动/销售动作、转化入口、渠道依赖、销售漏斗、续约和定价能力。用具体例子解释从触达到下单/签约的机制，分开投入、触达、转化、留存和回款。宣传、曝光、粉丝、下载不能当销售实绩；无转化数据就说明效果未知。 | 已确认官网活动/内容/案例/渠道页、品牌官方账号及合作方原始披露；授权投放、订单和回款记录 |
| M09-04 | 供应商集中度、采购条件与替换成本。 | 采购/付款与供应商披露、合同、交付及替代认证记录；未授权访谈只列请求 |
| M09-05 | 重大合同中的期限、排他、控制权变更、终止、赔偿与服务约定。 | 双方公开披露及获授权合同/订单/验收/回款记录 |
| M09-06 | 官网案例与客户侧公开信息比对；客户 logo 不能证明当前收入关系。 | 双方公开披露及获授权合同/订单/验收/回款记录 |
| M09-07 | 对重要商业声明设置反证检索和资料请求。 | 合同、订单、验收、发票、回款链及客户侧披露；未授权访谈只列请求 |
| M09-08 | 样本是否覆盖关键业务、渠道和客户类型，是否包含流失、未成交、退款或异常交易；管理层精选成功案例不能代表总体。 | 客户/交易总体及抽样依据、客户侧采购/使用材料、流失与退款记录、授权访谈 |

## 方法与关键口径

承接模块03的交易机制，查清顾客发现产品、产生兴趣、完成购买/签约、留存与回款之间的实际联系，再在获授权范围抽样追踪订单、交付、验收、开票和收款。不把通用漏斗当目标已验证流程；分别核验获客方式、渠道依赖、续约与客户集中度，将可观察活动与归因后的效果分开。

有可靠数据时可画按同一队列和期间计算的漏斗、渠道结构或获客/留存图；缺数据时用有证据的营销机制图、具体活动例子和明确的效果未知，不补造点击率、转化率、CAC、LTV或营销ROI。

- 先按业务/渠道/客户类型界定总体与期间，再选择能回答问题的样本；覆盖关键收入或风险集中项，并主动寻找流失、未成交、退款、逾期或异常交易。记录样本由谁提供、覆盖比例或范围和选择偏差；非随机样本不外推总体比例。
- 客户侧核对需求强度、采购决策、预算来源、替代选择、实际使用和续约/流失原因，区分愿意称赞、签约、使用、付费与持续购买。公开研究用客户侧披露和可观察行为；未获授权的访谈或明细核查保留为补证任务。
- 同队列分析新增、扩购、收缩与流失，分清自然增长与补贴、折扣、渠道压货或短期大单；渠道销售与终端销售、经销商库存分开。交易抽样追踪合同到回款，并查期末异常、退货与期后收款；例外应扩大相关核验或限制结论，不能用成功样本覆盖异常。

关键口径：签约方、客户/渠道、营销对象与动作、活动/内容实例及发生时间、转化入口、可核验的投入/效果、时间、金额、币种、试点/付费、排他/变更控制/终止条款。对营销机制与营销效果分别说明已知和未知：有活动页面不等于有增量订单，有订单不等于已回款。

## 取证提示

营销方式先直接阅读已确认官网的活动、案例、产品与销售入口，以及有归属的品牌账号/合作方内容；不能只读首页或搜索摘要。用公开页面确认动作和企业自述范围，再用合同、订单、验收、发票、回款链及客户侧披露判断商业结果；未授权访谈只列请求。产品、官网或活动图片须真实并遵循[来源策略](../sources/source-strategy.md)的权限、署名、日期与适用范围要求，不生成营销“实景”冒充证据。

## 特有误判

Logo/意向合作→可能仅为试点或历史接触→取得双方可验证合同/履约证据。

## 输出与裁剪

主报告必须回答“向谁营销、用什么渠道和具体动作、如何连接销售、目前能证明什么效果”。至少使用实际取得的公司例子解释已有机制；没有例子或效果数据时写具体未知及判断限制，不用“营销能力强”替代分析，也不因缺数字删去营销主题。客户Logo、社媒截图和品牌合作图的图注说明来源和范围，不暗示已付费、当前有效或取得销售收入。

底稿给出主体/适用范围、证据、置信度与反证，保留可复核分析、风险、缺口、资料请求、责任角色与完成标准。

公司研究核验需求、客户选择及营销效果；合作/投资/并购加深合同和客户质量，授信聚焦回款；Deep抽样须说明总体与抽样局限。
