# 05 竞争与替代

通用的主体/期间口径、证据与缺失、反证及权限规则见[证据标准](../evidence-standard.md)与[来源策略](../sources/source-strategy.md)；展开深度按[目的手册](../purpose-playbooks.md)和[行业适配](../industry-adapters.md)裁剪。

## 核心问题

客户真实替代选择是什么，主要竞争对手是谁，在哪些可比维度不同，是否已有证据支持优势及其持续性。主报告必须回答竞争问题；缺数据时说明已识别的对手、选择依据和未知边界，不删除竞争部分。

## 调查项目

检查项按本次问题与重大性选择展开；缺资料保留未知，不能改为不适用。

| 检查 ID | 核验问题与特有判断 | 关键证据 |
| --- | --- | --- |
| M05-01 | 根据真实客户选择识别直接、间接、替代及潜在进入者。 | 双方公开披露及获授权合同/订单/验收/回款记录 |
| M05-02 | 竞品表比较产品、价格、服务、渠道、技术、客户、规模和商业模式；统一口径。每个单元格标证据、期间和适用范围；缺数据填未知，不能用主观高低、虚构评分或雷达图把缺口伪装成比较结论。官网标价与成交价、集团规模与单产品规模分开。 | 已确认的目标与竞品官网对应产品/价格/渠道页、双方公开披露及获授权交易记录 |
| M05-03 | 市场份额及 CR3/CR5/HHI 仅在市场边界和样本足够时计算；份额未披露时可按[估算与三角验证](../estimation-triangulation.md)自下而上与自上而下两条路径估算区间，并标为推断。 | 客户公开采购选择、竞争者原始披露、合同定价、产品试用和行业统计 |
| M05-04 | 评估议价能力、进入成本、转换成本、网络效应、牌照、数据、品牌与规模优势。 | 客户公开采购选择、竞争者原始披露、合同定价、产品试用和行业统计 |
| M05-05 | 区分拥有专利/数据/客户与形成可持续壁垒。 | 权利/许可原件及发证机关；核对主体、范围和有效期 |
| M05-06 | 对“无竞争对手”“行业第一”追溯定义与原始依据。 | 客户公开采购选择、竞争者原始披露、合同定价、产品试用和行业统计 |
| M05-07 | 竞品数量由市场结构决定，不为凑数量纳入无关主体。 | 客户公开采购选择、竞争者原始披露、合同定价、产品试用和行业统计 |
| M05-08 | 优势在不同期间/客户条件下是否延续，维持优势需要付出什么投入，竞争者或替代方案如何侵蚀它。 | 可比价格/毛利/份额、客户迁移及输赢记录、研发/品牌/渠道投入、竞争者行动 |

## 方法与关键口径

先按客户需求、地域、价格/预算和购买场景选择真实可替代者，再做同口径竞品矩阵；不要从搜索热度或同行标签直接推出竞争关系。矩阵可仅比较有事实支持的产品、客群、价格条件与渠道，其他格明确未知，不必先获得完整财务数据才开始比较。公司自述与竞品自述都标属性，独立交易或客户选择证据另列。

样本覆盖足够才算份额/CR/HHI；以迁移成本和客户行为验证壁垒。没有对照时称“经营特点”或“品牌打法”，不得先称“竞争优势”“领先”再在脚注撤回。评分、排名和比例须有数据与可复核方法，不能为了图形丰富临时给企业打分。

将优势写成可检验机制，例如“特定客户转换成本高，因此续约/定价更稳”，用跨期客户行为、可比价格/毛利或输赢记录检验，并查失效样本。区分阶段性景气、补贴/低价换份额与可持续优势；解释维持研发、渠道、服务或产能的代价，以及竞争者响应、技术替代和监管变化会如何削弱优势。跨期不可比时明确限制，不要求机械凑齐趋势。

关键口径：客户场景、竞品主体、比较期、价格条件、市场分母、样本覆盖。

## 取证提示

优先：客户公开采购选择、已确认竞品官网对应产品/价格页、竞争者原始披露、合同定价、产品试用和行业统计。直接读实际相关页，记录市场、版本、币种、促销与日期，不用首页口号或搜索摘要替代产品比较。

## 特有误判

声称行业第一或无对手→可能为自定义细分→核查分母与替代品。

## 输出与裁剪

主报告说明主要竞争对手或替代方案、为何纳入、竞争发生在哪个场景，并提供事实与未知并存的比较矩阵。对手数量由真实市场与可用证据决定；若尚不能可靠识别具体对手，直接写明目标市场/客户选择哪些环节未查清及其影响，不能编企业名或删章。只有规模数字而缺产品或客户场景时，也不能视为完成竞争解释。

底稿记录比较口径、每格证据、不可比项、反证与样本覆盖；结尾记录风险、缺口、资料请求、责任角色与完成标准。

公司研究解释相对位置；竞品/投资加深优势持续性和竞争响应；Deep可在授权内做产品和客户选择比较，不强行列固定家数。
