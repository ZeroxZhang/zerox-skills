# 从品牌到公司：追溯与研究

用户给出的常常是品牌名，而不是公司名。品牌不是法律主体，不能签约、不能出财报，也不承担责任。研究品牌时，真正要回答的是：这个品牌背后是哪些公司，它们各自做什么，最终由谁控制、谁赚钱、谁担风险。品牌层的认知、口碑和定价是补充，不能代替公司层研究。

## 1. 先建档，后判断

- 用 `init_project.py --target-type brand` 初始化。目标实体 `ENT-0001` 的 `entity_type=brand`，名称就是品牌名。
- 品牌和背后的主体分别建档，不把品牌名改写成某家公司的法定名。同一品牌在不同国家或品类可能由不同主体持有或经营，按地域分别记录。
- 在找到经营主体并以 `verified` 关系连接之前，控制链与上市关系保持待核实；`check_report --mode completed` 也会拒绝没有查明经营主体或商标权利人的品牌项目。
- 商标由个人持有、公司由个人控制时，另建 `entity_type=person` 的关联实体。身份核实使用公开登记、公司披露等证据与 `identity_notes` 中的同名排除依据；`registration_id` 留空，不编造企业登记号，也不收集私人证件号。自然人 `listing_status=unlisted`、证券字段留空；不能作为本技能的研究目标或公司的营收、利润、估算主体。调查仅限其与目标公司的商业角色、权利和责任。

## 2. 七条追溯路径

| 路径 | 能找到谁 | 边界 |
| --- | --- | --- |
| 商标登记 | 注册人、申请日、类别、状态、转让与许可备案 | 权利人可能是控股公司、创始人个人或境外主体；有商标不等于在经营 |
| 网站与 App 备案、应用商店开发者 | 网站主办单位、App 开发者或发行方 | 只说明谁登记了网站或应用 |
| 用户协议、隐私政策、支付与发票 | 合同相对方、个人信息处理者、收款方、开票方 | 三者可能各不相同，分别记录 |
| 电商店铺经营者资质 | 旗舰店或专卖店的经营主体 | 授权店和经销店不是品牌方 |
| 产品标签与产品备案 | 生产商、委托方、产品注册人或备案人 | 代工厂不等于品牌方；按行业查化妆品、食品、医疗器械等备案 |
| 特许经营与品牌授权 | 特许人、被特许人、授权方与被授权方 | 加盟门店不代表品牌直营 |
| 集团年报、招股书与官网品牌页 | 品牌所属集团、分部与披露口径 | 品牌收入通常只在分部或品牌层部分披露 |

不需要每条都走完；能确认经营主体和商标权利人、并能解释主要分工即可。每条路径的检索都写入 `search-log`，查不到也要记录。`search_plan.py` 会为品牌目标生成这些 `brand_trace` 任务和一个汇总的 `brand_resolution` 任务。

## 3. 用关系表达角色

在 `entity-relations` 中，品牌是下层（child），各主体是上层（parent）：

| relation_type | 含义 | 是否沿此边追溯控制和上市关系 |
| --- | --- | --- |
| `trademark_holder` | 商标权利人，可以是公司或自然人；不代表在经营 | 是 |
| `operator` | 品牌经营主体：实际组织产品、销售、收款并承担经营结果 | 是 |
| `brand_of` | 同一公司主体既持有又经营；或子品牌指向主品牌。主品牌仍是品牌，须继续追溯公司 | 是 |
| `licensee` | 被授权使用品牌经营的一方 | 否，授权不构成控制 |
| `manufacturer` | 生产或代工方 | 否 |
| `distributor` | 经销或代理方 | 否 |

经营主体确定后，继续用 `control` 等关系向上追溯到实际控制人和集团；若集团上市，按[模块18](modules/18-listed-company-research.md)执行研报流程。不同渠道指向不同主体时，登记 `conflict-register`，先查是否为集团内分工、授权或历史变更，再判断。

关系已标 `verified` 但任一端身份仍为 `pending/ambiguous`，不能据此宣称已查明品牌背后的主体。自然人可以通过 `trademark_holder` 持有商标、通过 `control` 控制经营公司；其本人不是品牌经营公司，不用 `operator` 或 `brand_of` 替代公司建档。子品牌与主品牌关系、权利与控制关系都按有效日期核验，不允许形成生效的循环关系。

## 4. 常见结构

- **单一主体**：一家公司既持有商标又经营。用一条 `brand_of`。
- **控股—运营分离**：控股公司或个人持有商标，运营公司经营并收款。分别用 `trademark_holder` 和 `operator`，并核实两者是否同一控制。
- **集团多品牌**：品牌只是集团的一个业务单元。品牌的经营数据往往只有分部口径，集团合并数字不能直接当作品牌业绩。
- **授权经营**：外国或他方品牌由本地公司授权经营。研究对象通常应同时包括授权方（品牌价值、授权条款与期限）和被授权方（实际经营与财务）；授权到期或终止是核心风险。
- **加盟与渠道**：品牌方收取加盟费、供货差价或管理费，门店由加盟商经营。要区分品牌方收入与全系统终端销售额。
- **代工贴牌**：品牌方负责设计、营销和渠道，生产外包。代工厂信息说明供应链，不说明品牌归属。

## 5. 报告里怎样写

- `identity` 主题先说明“这个品牌属于谁”：经营主体、商标权利人、所属集团及三者关系，再讲品牌本身。
- 至少一幅 `purpose=ownership` 的关系图（`diagram`）展示品牌与各主体的关系；方向与关系都要有依据，未核实的关系用 `unknown` 并在图注说明。
- 财务数字逐项标明属于品牌、经营主体还是集团（`scope=brand / standalone / consolidated / segment`）。品牌层只有零售额或 GMV 时，按[估算与三角验证](estimation-triangulation.md)处理，不能写成公司收入。
- 品牌层信号（认知、口碑、价格、内容）放在营销与竞争相关章节，按[模块09](modules/09-commercial-dd.md)的品牌健康检查执行。

## 6. 何时停下

- 经营主体无法确认：控制链保持待核实，公司层的财务、风险与决策判断都不能形成；报告保留品牌层研究和已查明的部分，状态保持 `limited`。
- 品牌被多个主体在不同地区分别持有或经营：先与用户确认研究范围，再继续；在确认前不合并各地数据。
