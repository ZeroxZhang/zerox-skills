# 评分、风险与证据充分程度

1. 业务/合作适配评价：业务质量与用户目的是否匹配。
2. 风险评价：具体风险的性质、严重性、可能性、时间范围与缓释。
3. 证据充分程度：资料覆盖率、关键缺口、研报门槛状态与结论置信度。

不得用一个总分同时代表上述三项，不把高商业潜力写成低法律/信用风险。

### 10.2 评分规则

- 针对六类目的给出独立权重表；适用维度权重总和为 100%。
- 目的尚未明确时不计算场景综合评分；不得把通用研究状态当作未经定义的第七类目的。
- 采用 1–5 分且高分更好的维度，每一分值提供可观察、与目的相关的锚点。
- 缺失维度保留空值与原因，不自动给 0 分、3 分或行业均值。
- 不适用维度须有依据；按适用维度重新归一化权重。
- 同一底层风险避免重复计罚；如影响不同目标，应说明其各自传导路径。

设适用维度集合为 A，有充分证据可评分的集合为 K：

```text
证据覆盖率 = Σ(K 的原始权重) / Σ(A 的原始权重)
已覆盖维度分数 = Σ(K 的分数 × 原始权重) / Σ(K 的原始权重)
```

第二项在覆盖不足时只能展示为局部分数，不得包装成完整总评分。

综合评分发布的默认管理门槛为：加权证据覆盖率至少 80%，且该目的规定的所有关键维度均有充分证据，没有足以改变决策的重大未解决冲突。80% 是可配置的内部治理阈值，不是统计置信度，也不是行业公认标准。

未满足门槛时输出“证据不足，暂不提供综合评分”；可以提供已核实的分项结论。研报要求未满足时，即便其他资料可支持局部分数，也必须保留单独的研报未完成状态。

边界处理：A 为空时评分不适用；A 非空而 K 为空时，覆盖率为 0、分数为 null、状态为证据不足。权重必须有限且非负，适用权重总和必须大于 0；非空分数必须在 1–5 内。非法输入应报错，不能当成缺失静默跳过。每类目的的关键维度清单必须显式配置。

### 10.3 红旗与建议

- 红旗触发的是复核/升级流程；只有身份、当前状态、适用规则与用户决策条件明确时，才给出否决或停止推进建议。
- 已确认的法定禁止或用户明确的否决条件优先于商业评分。
- 关键事实缺失可能导致“暂缓判断”，不等于已经证实目标高风险。
- 行动建议说明依据、前置条件、负责人角色、完成标准和残余风险。
- 竞品研究输出相对优势、威胁、观察指标与应对；不使用交易审批结论。
- 需要持续观察时提供更新触发条件；没有额外授权不自行建立监控、联系第三方或执行交易。

## 配置覆盖

`scoring_threshold` 可修改，但必须在报告解释选择；`scoring_override` 如使用须包含 `reason`、完整 `weights` 和 `critical_dimensions`。不得通过标关键维度“不适用”绕过门槛；如目的确实要求不同配置，明确理由后修改关键维度。若关键证据低/未知置信度，不计为充分评分。
