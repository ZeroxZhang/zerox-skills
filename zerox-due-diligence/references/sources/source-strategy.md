# 来源与检索策略

围绕会改变公司理解或专项决策的问题选来源：登记与控制先查原件；经营用财报/合同/交付；观点用研究报告；负面线索回溯监管司法原文。来源等级、访问程度、事实核验和置信度是四件事，使用[证据标准](../evidence-standard.md)。

先广泛扫描共同研究骨架，再把检索收敛到关键问题的当前解释、替代解释和区分证据；重要新发现可重新扩大范围。关键词组合使用主体/别名/品牌、实际业务与客户场景、问题、地域/语言、来源和时间，不机械展开全部笛卡尔积。正证、反证、澄清和当前状态并查；名称无结果时换别名与权威路径，不把多个搜索网站当多个独立原件。

顺序：官方与授权原件→专业研究与透明方法统计→有归属的媒体/自述→匿名线索。用户提供的合同/审计报表依据真实性与内容评级，不统一降为宣传。使用 `origin_group` 追踪共同原件，`upstream_source_id` 保存二手关系；原件没拿到不能写已直接访问。

历史时点只用当时已公开/授权可得资料；后来修订隔离为 retrospective。行业统计、司法状态、财报和政策更新机制不同，不设统一有效期。报告临近交付复查控制、重大事件、新披露和报告修订。

工具/访问失败记录：渠道、时间、查询、错误、已尝试替代、剩余限制与获取路径。搜索摘要只能证明结果页曾出现表述。OCR或扫描件无法确认则不用该数字和页码。未经授权不绕登录/付费墙，不自动联系、购买或外发资料。

停止规则：约定范围的关键问题已有足够适用证据、重要冲突已处理，剩余缺口的影响已逐项评估且新增检索边际收益低。研报等强制检索仍须实际执行；资料未取得或未读保持真实覆盖状态。范围可否完成另按[质量门槛](../quality-gates.md)判断，不以“未找到”推定“没有风险”，也不以预算用尽代替完成条件。

来源目录列出运营方、地域、资料/适用事实、入口、更新、权限、局限、回溯及核验状态。最后核验仅证明列明的访问结果，不保证深层检索、付费权限或历史完整性。

## 目标官网的基础阅读

官网身份确认与基础阅读是所有目标的共同任务，不因某一尽调模块被裁剪为不适用而消失。`search_plan.py` 只生成这些任务，不自动访问网站，不把计划写成已执行。先用用户提供的已核验入口、监管/登记披露的链接、App发行方信息或其他可靠的双向关联确认官网归属；单凭域名相似、搜索排名或站点自称不能确认。未确认前不猜域名或 `/about` 等页面路径。

确认归属后，从实际导航、站内搜索或已取得的真实链接直接读取对应页面，至少逐项判断下列路径是否存在和可读：

| 页面任务 | 应提取的内容与边界 |
| --- | --- |
| 关于/公司介绍 | 品牌与公司范围、主营活动、客户定位和经营地区；自述与独立证据分开。 |
| 产品/服务/价格 | 实际提供什么、怎样购买、品类与价格条件；记录国家、币种、促销、版本和采样日期，单个商品不能代表全部价格带。 |
| 团队/创始人 | 具名背景、创始或合伙关系、职责与任职时间；现任和历史角色分开，不搜无关隐私。 |
| 历史/新闻 | 创立、产品、市场、渠道、组织和融资变化；保留实际事件日期和发布日期的区别，宣布不等于完成。 |
| 门店/渠道 | 已开业/计划地点、运营方式与范围；服务可达不等于已产生销售。 |
| 投资者关系/财务 | 营收、结构、利润率和财报原件；私企无此栏目时记录路径限制，不以宣传数字代替审计。 |
| 条款/隐私/发行方 | 服务、收款、数据控制与合同责任主体的公开说明；不同角色不自动等同。 |
| 品牌/媒体/产品与门店素材 | 真实Logo、官网界面、产品和门店图，保留来源、时间、展示范围和使用权限。 |

逐页记录实际URL、页面标题、归属真实性及其依据、发布日期、信息适用期、访问日期、正文可访问程度和具体定位；沿用 `source-register` 与 `evidence-ledger`，必要的缺失和失败进入日志/缺口。日期未给出就保留未知，访问日不能伪装发布日期或事件日期。只看首页、搜索摘要、缓存片段或URL存在，不能登记其他页面已读；动态正文、图片内文字或付费内容不可访问时如实标注，采用合法替代。离线约束下任务保留未执行，可分析已有授权存档而不声称重新访问。

网页存档（如 Wayback Machine）的历史快照可用来还原官网的产品线、价格、团队、定位和渠道如何变化，是创业公司战略转折的低成本证据。登记快照网址与快照时间；快照日期只说明当时页面如此，不是事件日期，存档缺页也不代表当时页面不存在。

品牌目标的追溯路径（商标、备案、条款与收款方、店铺资质、产品标签与备案、特许经营、集团披露）见[从品牌到公司](../brand-to-company.md)；各渠道入口见中外来源目录。

官网对产品功能、定位、团队、营销和历史的说明可以帮助完整解释公司，但其发布主体仍是公司；Logo墙、合作新闻或营销截图不能证明当前付费客户、营收或营销ROI。重要声明继续寻找独立形成的证据；媒体转述同一公司口径不新增独立认证。

## 真实视觉素材

按解释用途选择公司Logo、官网界面、真实产品或门店图，而不是仅用抽象装饰。记录实际来源页和文件地址、权利人/授权或合理引用依据、允许的受众/用途、素材日期与主体/地区、必要署名及裁切/标注范围。若记录在独立素材清单，正文图注仍须让读者知道展示了什么、来自哪里；用证据ID连接具体页面事实。

公开可见不等于允许任意复制和再发布。未获得可用权利依据或无法确认真伪的素材保持未知，选择合法替代或明确标为分析示意。不能生成假的企业标识、人物、产品或门店照片当成企业实物；真实图片也不能用作销售规模、产能、店网或经营效果的替代证据。
