# 访谈设计与记录

围绕关键问题和能区分当前解释与替代解释的开放缺口提问，不为凑访谈人数而访谈。默认交付提纲；联系对象、对外发送、录音和付费需相应授权。不得索取无权分享的保密资料、个人隐私或内幕信息。

| 角色 | 可回答的问题 | 交叉验证 |
| --- | --- | --- |
| 创始人/管理层 | 关键战略为何选择、怎样执行、哪些结果偏离预期？什么会改变计划？ | 决议、预算与实际差异、激励及组织变化；自述需其他角色与结果验证 |
| 财务 | 收入到回款差异由哪些期间/合同造成？受限资金和到期债务怎样安排？ | 明细账、审计附注、授权银行/税务材料 |
| 客户 | 为什么选择、继续使用、拒绝或流失？试点转付费、验收、替代品与服务有哪些事实？ | 合同/验收与客户侧记录；覆盖适用的新老、流失或未成交样本，区分个人经验与总体 |
| 供应商 | 需求预测、结算、质量、产能替代有哪些记录？ | 采购与付款、质量及交付 |
| 前员工 | 在其任职期间和职责范围内，流程与实际执行有什么差异？ | 期间和知情边界；不要求带出保密文件 |
| 行业专家 | 市场口径与关键假设是否成立？哪些反例可能推翻判断？ | 原始统计、方法与利益关系 |

抽样遵循[证据标准](../evidence-standard.md)：说明目标总体、观察期、名单来源和选样方，检查管理层筛选、幸存者与不回应偏差。按问题寻找成功与失败经历，不设固定人数或机械正反配额；无法取得某类样本时说明遗漏及外推边界。

每次记录 planned/completed、日期、角色类别、知情范围、利益关系、匿名约定、获准保存范围、问题、要点、与其他证据一致性和后续核验。没有访谈只交提纲，不输出虚构回答或已执行记录。模板见[访谈提纲](../../templates/interview-outline.md)。
