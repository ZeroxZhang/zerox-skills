# 场景 4 · 「直接开始，别问我」

**推演视角**：刚加载 skill 的新会话。

## 被测请求

> 帮我调研 2026 年国内出海 SaaS 的获客成本结构。直接开始，别问我，做完给我报告。

## 触发判定

**应触发。** 「调研」+ 高价值开放题，落在触发面内。「别问我」不取消触发，只取消提问环节。

## 期望行为

| # | 期望 | skill 依据 |
|---|---|---|
| 1 | **跳过澄清提问** | 阶段 1.6：「用户说『直接开始 / 别问我』……不提问」 |
| 2 | **但不能跳过开题**：仍要写 brief.md，把假设明确写进「已采纳的假设」 | 同上：「把假设写进 brief.md 的『已采纳的假设』」 |
| 3 | 假设在**最终报告的「方法与局限」逐条复述** | 阶段 1.6 + report-template.md |
| 4 | 计划确认闸门：用户已说别问 → **可不等确认**，但**要留下记录** | 阶段 2：「用户明确要求跳过……可不等确认，但要留下记录」 |
| 5 | 完整流程照走：迭代研究与存档 → 综合 → 质检 → 打包 | 「别问我」≠「别做质检」 |

## 推演：假设会写什么

「2026 年国内出海 SaaS 的获客成本结构」缺的边界，agent 必须**自己补默认值并显式声明**，不能猜了不说：

| 缺的边界 | 应采纳的假设 |
|---|---|
| 出海目的地 | 默认：北美 + 东南亚为主，欧洲作对照 |
| SaaS 品类 | 默认：B2B SaaS（协作 / 开发者工具 / 营销），不含消费级 |
| 获客成本口径 | 默认：CAC = 销售营销费用 / 新增付费客户，年化；含人力成本 |
| 时间窗 | 默认：2024–2026，重点近 12 个月 |
| 受众 | 默认：内部战略讨论，熟悉 SaaS 但不熟悉出海 |

## 关键分界：跳过提问 ≠ 跳过假设

失败模式是两种：

1. **问了**——违反用户指令；
2. **不问也不声明**，直接按自己的猜测出报告——读者无法判断结论建立在什么前提上，比问了更糟。

正确做法：brief.md 的「已采纳的假设」写满，report.md 的「方法与局限」再抄一遍。这是本场景唯一的新考点。

## 推演结果

**通过（静态推演）**。skill 里两条路径都写了：

- 不提问（阶段 1.6）
- 假设入简报 + 入报告（阶段 1.6、report-template.md「采纳的假设」）

## 残留风险

「做完给我报告」暗示用户要最终结论、不想看过程。阶段 6 的对话收尾要求「只给：简短的结论摘要、研究包路径和统计……」正好匹配——不在对话里倒过程日志。
