## 成功标准

读完之后，用户能够：

1. 说清三家在 input / output / 缓存 / 长上下文四项上的计价结构差异（不只是单价差异）
2. 知道哪些数字可以直接比、哪些必须换算、哪些根本不可比
3. 用统一口径做预算测算，并知道测算的假设边界
