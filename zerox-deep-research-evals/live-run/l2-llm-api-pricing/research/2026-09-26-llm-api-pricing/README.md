## 如何核验一条结论

以报告关键结论 1（「缓存不可直接比」）为例：

1. `report.md`「关键结论」第 1 条尾部引用号 `[1][2][4][5][7][9]`
2. 翻到文末「参考来源」`[4]` 那一行 → 来源 ID `A005` → 存档 `raw/sources/A005-gemini-api-pricing.md`
3. 打开快照，按 `notes/A-pricing.md` 的 E-005 定位「某模型的 Context caching price 行」找到原文
4. 对照 E-005 的「逐字摘录」——`| Context caching price | Not available | $0.20, prompts<= 200k tokens$0.40, prompts > 200k$4.50 / 1,000,000 tokens per hour (storage price) |`
   摘录是原文；下面的「解读」才是加工（指出这是按小时存储费，与另两家机制不同）

`check_package.py` 会自动做第 4 步的比对（归一化空白与全半角标点后在快照里找子串），任何凭空补写的摘录都会被报错。

## 完整性校验

```bash
shasum -a 256 -c manifest-sha256.txt   # macOS
sha256sum -c manifest-sha256.txt       # Linux
```

清单列出研究包内除它本身以外的所有文件，每行 `SHA-256 值 + 两个空格 + 相对路径`。校验失败说明文件被改动或缺失。生成命令：`python scripts/check_package.py <研究包> --write-manifest`。
