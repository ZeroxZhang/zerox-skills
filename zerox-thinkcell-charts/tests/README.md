# 测试
- `data/`：19 个推荐用数据集，覆盖 CSV、TSV、Markdown 表、空格对齐文本、JSON 和 Excel；形态包括时间序列、宽表、起止桥、带小计的利润表、构成、调研量表、同比、目标、区间、敏感性、甘特、漏斗、正负、Mekko、散点、两层分类长表、离群值、量 + 率。
- `specs/`：14 个校验用例，包括瀑布不平、百分比不加和 100、Mekko 缺宽度、甘特缺日期、类别过多且名字过长、长度不一致、下限大于上限、缺目标值、系列数不对、数字里混了文字、类型未知、堆叠瀑布不平、饼图块数过多，以及 1 个正常用例。
- 运行：`python tests/run_tests.py`。检查推荐首选/备选是否合理、草稿能否渲染、校验结论是否正确、61 个示例全部判为“能做”、渲染前自动拦截和 `--force` 是否生效。
